# Гильдия (D21) — все механики, офлайн-эмуляция → онлайн

Статус: спека под встраивание («на будущее» — код за флагом, как D16).
Опора: `core/game_manager.gd` (паттерн арены с бот-соперниками),
`data/boss_hunt_data.gd` (D19 — гильд-босс это недельный рейд-вариант
охотничьих боссов), `data/lab_data.gd` (валюты), D16 (косметика),
`core/progression.gd` (сезон/СП — паттерн циклов).

## 0. Главная архитектурная идея: дневник событий

Гильдия — единственная система проекта, которая ЦЕЛИКОМ переезжает в
онлайн. Поэтому с первого дня все значимые действия пишутся как события
(append-only лог в сейве):

```
{ "t": "damage",  "member": "ты",   "boss": "kostolom", "week": 12, "amount": 142300 }
{ "t": "contrib", "member": "ты",   "res": "bio", "amount": 50000 }
{ "t": "war_win", "member": "Стервятник", "wave": 34 }
```

Офлайн: симулятор читает лог и дорисовывает действия ботов (детерминировано
по `guild_id + неделя`). Онлайн: тот же лог шлётся на сервер, сервер —
авторитет. Интерфейс (`Guild.state()`, `Guild.contrib()`, `Guild.boss_damage()`)
не меняется — меняется только источник чужих событий. Анти-чит онлайн-этапа:
сервер валидирует забеги (отчёты `result` уже структурированы).

## 1. Состав и жизнь гильдии

| Параметр | Значение | Ручка |
|---|---|---|
| Размер | до 30 членов | GUILD_CAP |
| Старт | офлайн: выбор из 3 NPC-гильдий («Заря», «Пепел», «Дозор») ИЛИ основать свою (29 ботов-«рекрутов» добираются за 2 недели по 3-5/день — имитация роста) | BOT_JOIN_RATE |
| Ранги | Голова (ты) → Правая рука → Обыватели; боты имеют «силу» и «активность» | — |
| Боты | 29 профилей: имя из генератора (прецедент арены), сила 0.4–1.6× твоей, активность (доля дней с вкладом) 30–90% | SIM_SPREAD |

Офлайн-честность: боты НЕ повторяют твои действия зеркально — их вклад
клюет по неделе (seed = guild_id + номер недели), чтобы гонка вклада
ощущалась, но была достижима для активного игрока (топ-3 реально занять).

## 2. Вклад, казна, уровень гильдии

- **Вклад** (личные очки): забег — биомасса/1000; ОХОТА — Искры×10;
  арена-победа +50; ежедневный гильд-квест (§5) +100. Кап 2 000/день.
- **Казна** (общий ресурс): вклад биомассой (кнопка «В КАЗНУ», паками
  10К/50К/250К). Казна тратится на уровень гильдии (§3) и открывает
  гильд-магазина ассортимент.
- **Уровень гильдии 1–10**: цена уровня = 100К × уровень^1.4 из казны
  (+ требование вклада суммарного). Перки: +2%/уровень к биомассе забегов
  (кап +20%), уровень 5 — +1 Искра в воскресной ОХОТЕ, уровень 10 —
  открывает «Эхо» третьей пачки раньше на цикл (связка D20).
  Перки НЕ касаются PvP-силы напрямую (арена честнее).

## 3. Гильд-босс (еженедельный рейд)

- Понедельник 00:00 — босс недели = один из шести ОХОТЫ (D19, ротация
  seed'ом), **масштаб HP ×60 от охотничьего** и grows с уровнем гильдии.
- Бой как в ОХОТЕ (свои мутанты, бюджет), но урона по боссу хватает на
  ЗАБЕГ: в конце забега (любого исхода) в лог пишется `damage` = нанесённый
  боссу урон за забег. Лимит: 3 захода в день (анти-фарм).
- Офлайн-симулятор: каждый бот-член за неделю наносит 2–8% пула по своей
  активности; к Вс босс ДОЛЖЕН умирать на 88–97% пула гильдии (боты не
  добивают последние проценты — их добираешь ты, «решающий вклад»).
- Награда в Пн (по вкладу за неделю, проценты от нанесённого):
  топ-10% — Искры 15 + 5 круток + гильд-жетоны 300; 10–40% — Искры 10 +
  3 крутки + 150; остальные — Искры 5 + 100; ноль вклада — ноль.
- Ручки: BOSS_HP_MULT 60, SIM_FLOOR 88, WEEKLY_CAP.

## 4. Гильд-война (каждые 2 недели, чётные недели сезона)

- Соперник — NPC-гильдия (сила ±20% к твоей, seed от недели).
- Формат «Оборона Бункера», 3 дня (Пт–Вс): каждый член проводит оборонные
  забеги (обычная выживание/кампания), score члена = волны выживания;
  score гильдии = сумма топ-20 членов. Соперник симулируется кривой к
  финалу (напрежение: к Вс соперник отстаёт/лидирует ±15%).
- Итог Пн: победа — военный сундук в казне (крутки 5+5, Искры 10,
  гильд-жетоны всем по вкладу, эксклюзивная рамка «Защитник» топ-5);
  поражение — утешительные жетоны.
- Офлайн-честность: твой личный score капится 35% от нужного порога —
  один не вытянет, но и без тебя не проиграть (боты дают 70–85% порога).

## 5. Гильд-магазин и доска

- **Гильд-жетоны** — заработок вкладом/боссом/войной (никогда за деньги —
  граница D16). Ассортимент: косметика «Гильд-серия» (рамка/титул/флаг
  с символом гильдии), Искры 10/250жет, корма звёзд, слот «резерв» пачки?
  (нет — сила не продаётся даже за заработанное: только косметика + Искры
  + корма). Обновление ассортиментa — сезонно.
- **Доска**: офлайн — бот-сообщения (поздравления с боссом, итоги войны,
  «пугач-мемы» из генератора, seed-недели); вкладки: события/объявления
  Головы (заготовленные шаблоны). Онлайн — настоящий чат (Этап 3).
- Ежедневный гильд-квест (один на всех, из пула: «наберём 500 000 био»,
  «10 побед ОХОТЫ», «3 войны-обороны») — +100 вклада каждому выполнившему.

## 6. Данные и код

```gdscript
# data/guild_data.gd — константы гильдии (спека D21)
const GUILD_CAP: int = 30
const BOT_JOIN_RATE: int = 4             # рекрутов в день при основании
const CONTRIB_DAILY_CAP: int = 2000
const LEVEL_COST_BASE: float = 100000.0  # x level^1.4
const PERK_BIO_PER_LEVEL: float = 0.02   # кап 20%
const BOSS_HP_MULT: float = 60.0
const SIM_BOSS_FLOOR: float = 0.88       # боты добивают до 88-97%
const WAR_PERIOD_WEEKS: int = 2
const WAR_DAYS: int = 3                  # Пт-Вс
const SELF_SCORE_CAP: float = 0.35
const SHOP_GUILD_TOKENS := {...}         # косметика/Искры/корма
```

- `core/guild.gd`: состояние (профиль, члены, казна, уровень, лог),
  API `contrib()/boss_damage()/war_score()/shop_buy()`, симулятор ботов
  (`simulate_week(seed)`), доска-генератор.
- `save_data`: `guild: Dictionary` (весь стейт; миграция — гильдии нет =
  оффер вступления при 3+ пройденных забегах).
- UI: `ui/guild/guild_overlay.gd` (вкладки), кнопка «ГИЛЬДИЯ» в нижнем
  ряду лабы; бейдж «неделя босса: 64%» рядом с кнопкой.
- Локализация: `guild.*` (~40 ключей) — отдельным блоком при встраивании.

## 7. Этапы и онлайновый переход

| Этап | Что | Когда |
|---|---|---|
| 1 | офлайн-гильдия целиком (эмуляция) | по этой спеке |
| 2 | тонировка: боты-имена из «реальных» паттернов, войны против гильдий других сохранений (обмен файлами? опция) | послеfeedback |
| 3 | онлайн: сервер-авторитет, реальные члены, общий HP босса в реальном времени, чат; лог событий = payload API; Play Games Services / свой лёгкий бэкенд | отдельная спека |

Что НЕ проектировать сейчас: realtime-кооп бой, торговля между игроками
(инфляция+дюпы), cross-device мерж сейвов — всё это Этап 3+.

## 8. Чек-лист приёмки (Этап 1)

1. Вступление: оффер после 3 забегов; выбор из 3 гильдий или основать свою;
   боты добираются по 3-5/день.
2. Вклад: забег/ОХОТА/квест пишутся в лог, кап дня работает, казна растёт.
3. Уровень: куплен за казну — перк биомассы виден в итогах (+2%/ур.).
4. Гильд-босс: неделя = босс из ротации ОХОТЫ ×60 HP; твои 3 захода/день
   пишут урон; в Пн босс мёртв на 88–97% пула, награды по вкладу, ты в
   топе если играл.
5. Война (чётная неделя): Пт–Вс обороны, Пн итог; при 1-2 забегах в день
   гильдия выигрывает на малых уровнях и борется на больших.
6. Магазин: жетоны только заработком; косметика «Гильд-серия» видна в
   профиле и на штандарте.
7. Доска: сообщения ботов меняются по неделям (seed), упомянают твои
   подвиги (топ-вклад недели).
8. Оффлайн: гильдия полностью работает без сети.
