# Мобильный UX — как встраивать

**Что это:** тач-адаптация HUD забега: укрупнение кнопок постановки (сейчас
74×46 — меньше пальца) через категории-аккордеон с автосворачиванием,
призрак-превью с подтверждением вместо мгновенной установки (десктоп не
меняется), safe-area под вырезы, пороги тапа.

**Зачем:** HUD верстался под 1100px десктоп; на телефоне (420dpi) палец
≈ 126 физ.px, кнопки аномалий вдвое меньше — мажут; установка «в один тап»
без превью на телефоне роняет аномалию не туда и жжёт энергию.

**Как встраивать (кратко):**
1. `ui/hud/hud_mobile.gd` — все ручки (размерная сетка, пороги, safe-area).
2. HUD в `_touch_mode`: панели аномалий/мутантов → аккордеон категорий
   (4+2 таба, крупные кнопки), автосворачивание в бою через IDLE-таймер.
3. `zone_controller` + `game_camera`: активная кисть → тап показывает
   ПРИЗРАК (кольцо + имя + цена), палец-двигает, ✓ ставит / ✗ отменяет
   (панель подтверждения у большого пальца). Десктоп — как было.
4. Safe-area: `DisplayServer.get_display_safe_area()` → маржины шапки/дока.

**Трогает:** ui/hud/hud.gd, hud.tscn (минимально), zones/zone_controller.gd
(_on_ground_tapped → призрак), scripts/game_camera.gd (hover-сигнал при
кисти), core/signals.gd (+ground_hovered). НЕ трогает: логику стоимости,
миникарту (обязательна), свайп-слои панелей (готово).
