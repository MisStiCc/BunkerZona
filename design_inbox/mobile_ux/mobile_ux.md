# Мобильный UX — HUD и тап-постановка (D8, актуализация)

Статус: спека под встраивание. Опора: `ui/hud/hud.gd` (`_touch_mode`,
`_toggle_placement`, панели), `ui/hud/hud.tscn` (кнопки 74×46, сетка 4×N,
AnomalyPanel слева 326×332, MutantPanel справа 494, Minimap правый-низ,
Start/Emission — низ-центр), `zones/zone_controller.gd` (`_pending_placement`,
`_on_ground_tapped` — ставит сразу), `scripts/game_camera.gd` (пан/пинч/тап,
TOUCH_SLOP 14, TAP_MAX_TIME 0.35), project.godot (1920×1080 canvas_items/
expand, sensor_landscape). Свайп-слои SwipeHelper и полноэкранность уже есть
— не трогаем.

## 1. Факты: почему мажут пальцем

Базовое окно 1080 высотой; на телефоне в ландшафте (1080 физ.) scale ≈ 1,
т.е. кнопка 74×46 ≈ 74×46 физ.px. Подушка пальца 8–9 мм на 400–420 dpi ≈
126–142 px. Тап-цель меньше пальца в ~2 раза по высоте — отсюда промахи и
«не туда поставил». Отсюда размерная сетка ниже (расчёт под scale≈1).

## 2. Размерная сетка (тач-режим; десктоп НЕ меняется)

| Элемент | Сейчас | Тач | Ручка |
|---|---|---|---|
| Кнопка аномалии/мутанта | 74×46 | **112×72**, шрифт 13→16 | BTN_W/BTN_H |
| Таб категории-аккордеона | — | 112×64 | TAB_H |
| Кнопка СТАРТ/ВЫБРОС | ~140×40 | 220×88 | BIG_H |
| ✓ подтверждения постановки | — | 132×96, зона 176 | CONFIRM_W/H |
| Панель постановки (развёрнут.) | 326×332 | ширина 4×112+поли=486 | PANEL_W |

16 аномалий × 112px в ряд не влезают → **аккордеон категорий** (это и есть
«укрупнять/группировать» из задания):

- Аномалии, 4 категории: ТЕПЛО (жарка/пар/комета/жг.пух), ЭЛЕКТРО (электра/
  тесла), ГРАВИ (воронка/лифт/карусель/телепорт/время), ХИМИЯ+ФОН (кислота/
  холодец/газочка/кисель/радиация). Табы — крупные, под ними ряд кнопок
  категории (макс 5 в ряд — влезает в 486+ px).
- Мутанты, 2 категории: ОТРЯД (пёс/плоть/снорк/псевдопёс/зомби),
  ЭЛИТА (контролёр/полтер/кровосос/гигант/химера + варианты ростера из
  лаутаута). Существующий порядок и гейтинг коллекции (disabled+тултип)
  сохраняются.
- Категория запоминается (последняя использованная открывается при входе).

## 3. Сворачивание панелей в бою

- Фаза набора (до СТАРТ): панели развёрнуты — игрок собирает лаутаут
  крупными кнопками (набор = тап по кнопке, уже реализовано `_loadout_tap`).
- В бою: панель СВОРАЧИВАЕТСЯ в «док-заголовок» (одна кнопка 112×56 с
  категорией) автоматически через IDLE_COLLAPSE сек без постановок;
  разворачивается тапом по доку. Установка из свернутого = тап по доку →
  тап по кнопке (2 тапа — цена укрупнения).
- НЕ прячем: миникарту (обязательна, ориентир волн), полосу энергии/биомассы
  и строку волны (это чтение, не тап-цели — размер не меняется).
- Кнопка ВЫБРОС: остаётся постоянной, укрупняется (BIG_H), сдвигается от
  края под safe-area.

## 4. Призрак-превью постановки (главное изменение флоу)

Сейчас: тап по земле = мгновенная установка (`_on_ground_tapped` →
create_anomaly / spawn_mutant). На телефоне это потерянная энергия при
маже. Новый флоу (ТОЛЬКО `_touch_mode`, десктоп — без изменений):

1. Выбор кисти (кнопка категории → кнопка вида) — как сейчас
   (`_toggle_placement`, подсветка кнопки).
2. Тап по земле → **призрак**: кольцо на земле (радиус ≈ габарит аномалии
   2.5 м / мутанта 1.5 м) + Label3D «ИМЯ · цена» + цвет: зелёный = хватает
   ресурса, красный = нет. НИЧЕГО не списывается.
3. Палец двигается по экрану (touch motion) → призрак едет по земле
   (ray → рельеф, как `_get_spawn_position_from_camera`, но из позиции
   пальца). Новый сигнал `Signals.ground_hovered(world_position)` из
   game_camera — эмитить ТОЛЬКО при активной кисти (иначе не мешает камере).
4. Панель подтверждения (низ-право, над досягаемостью большого пальца):
   ✓ 132×96 «ПОСТАВИТЬ · цена» / ✗ «ОТМЕНА». ✓ → установка в точку призрака
   (энергия/биомасса списываются здесь, провал = тряска панели и красный
   призрак), ✗ или повторный тап по кнопке кисти → отмена. Быстрый флоу для
   опытных: тап по СВОЕМУ призраку = подтверждение.
5. После установки кисть СОХРАНЯЕТСЯ (цепочки постановок), отмена кисти —
   ✗ или выбор другой кнопки.

Совместимость с камерой: при активной кисти game_camera НЕ трактует
однопальцевый драг как пан (это уже почти так — кисть ставит тапом; нужно
явно: `_pending_placement != ""` → drag двигает призрак, а не карту;
двойной тап «центр на монолит» при кисти отключить). Пинч-зум работает
всегда.

## 5. Safe-area и пороги

- Safe-area: `DisplayServer.get_display_safe_area()` относительно
  `get_screen_usable_rect` → маржины. Применение: шапка ресурсов
  (top-margin) и нижний док/StartPanel (bottom-margin). Значения по
  умолчанию 0 (обычные экраны), на вырезанных — движок даёт реальные
  границы. Ничего не считаем сами, только применяем с ручкой-флагом.
- Пороги тапа (game_camera): TOUCH_SLOP 14 → **18** (цели крупнее —
  разрешим чуть ленивее пальцы), TAP_MAX_TIME 0.35 → **0.42** (тяжёлый
  тап на крупной кнопке дольше). Ручками в один файл (см. §6), game_camera
  читает из HudMobile.

## 6. Ручки-константы — `ui/hud/hud_mobile.gd` (новый файл)

```gdscript
# ui/hud/hud_mobile.gd
extends RefCounted
class_name HudMobile

## Тач-адаптация HUD забега (спека D8, design_inbox/mobile_ux).
## Десктоп эти ручки не читает (только _touch_mode).

# Размерная сетка (виртуальные px при базе 1080; scale на телефоне ~1)
const BTN_W: int = 112             # кнопка вида; тесно в категории -> 104
const BTN_H: int = 72              # минимум по пальцу 420dpi (~126px с площадкой
                                   # допуска: 72px кнопка + slop 18 = промах мимо редок)
const TAB_H: int = 64              # таб категории
const BIG_H: int = 88              # СТАРТ/ВЫБРОС
const CONFIRM_W: int = 132         # ✓ постановки
const CONFIRM_H: int = 96
const PANEL_W: int = 486           # развёрнутая панель постановки (4 кнопки)

# Сворачивание в бою
const IDLE_COLLAPSE: float = 6.0   # сек без постановок -> панель в док; 4.0 - агрессивно

# Призрак-превью
const GHOST_RING_ANOMALY: float = 2.5   # радиус кольца, м
const GHOST_RING_MUTANT: float = 1.5
const GHOST_CONFIRM_BY_TAP: bool = true # тап по своему призраку = поставить

# Пороги тапа (читает game_camera)
const TOUCH_SLOP: float = 18.0
const TAP_MAX_TIME: float = 0.42

# Safe-area
const SAFE_AREA_APPLY: bool = true  # False - игнорировать вырезы (отладка)
```

Перебор: «промахи остались» → BTN_H 72→80 и шрифт кнопок 16→18;
«цепко» → IDLE_COLLAPSE 6→10; «двойной тап по призраку ложный» →
GHOST_CONFIRM_BY_TAP false.

## 7. Совместимость (что трогаем)

| Файл | Правка |
|---|---|
| `ui/hud/hud_mobile.gd` | новый, константы §6 |
| `ui/hud/hud.gd` | в `_touch_mode`: пересборка панелей постановки в аккордеон + док, панель подтверждения, автосворачивание (таймер), размеры из HudMobile |
| `ui/hud/hud.tscn` | по максимуму кодом; допустимо только сдвиг Start/Emission под маржины |
| `zones/zone_controller.gd` | `_on_ground_tapped` → в тач-режиме показывает призрак (ghost-нод + валидность цены), установка по `confirm_placement()`; десктоп-ветка без изменений |
| `scripts/game_camera.gd` | `Signals.ground_hovered` при активной кисти; slop/время из HudMobile; двойной тап при кисти off |
| `core/signals.gd` | +`signal ground_hovered(world_position: Vector3)` |

НЕ трогаем: стоимости/гейтинг (используются как есть), миникарту, свайп-слои
панелей лаборатории, десктопный флоу (клик = установка), RVO/навигацию.

## 8. Чек-лист приёмки

1. Телефон/тач-эмуляция: кнопки категорий крупные, из категории «ГРАВИ»
   ставится «Лифт» без промахов 10/10 попыток.
2. Кисть → тап по земле: появился призрак с ценой; палец едет — призрак
   едет; ✓ ставит, энергия списалась; ✗ отменяет без списаний.
3. Красный призрак при нехватке энергии; ✓ на красном — тряска, нет ошибки.
4. В бою панель сама свернулась в док через ~6 с; тап по доку разворачивает.
5. Десктоп: клики по кнопкам ставят сразу (как раньше), призрак не появляется.
6. Экран с вырезом (эмуляция): шапка и док не под вырезом.
7. Пинч-зум при активной кисти работает; пан карты одним пальцем при кисти
   отключён (палец двигает призрак), без кисти — пан работает.
