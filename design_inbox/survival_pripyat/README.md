# Выживание на карте Припяти — как встраивать

**Что это:** геометрия выживания под большую карту: вместо кольца 70–120 м
(рассчитано на арену 150 м, на Припяти падает на здания) — **спавн-врата**
в 4 районных точках вокруг центра Припяти; волновая эскалация и награды —
как на процедурной карте (осознанно), растёт только число активных врат.

**Зачем:** сейчас выживание на Припяти технически работает (Монолит на
route[0] — центр города), но сталкеры спавнятся кольцом 70–120 м — на
плотной застройке центра это «из ниоткуда» и застревания; большая карта
никак не используется.

**Как встраивать (кратко):**
1. `SurvivalData`: константа `SPAWN_GATES` (4 точки lat/lon §2) +
   `gates_for_wave(wave)` (1→2→3→4 по волнам §3).
2. `spawn_manager`: ветка «врата» — `_get_spawn_position` на Припяти+
   выживании берёт точку врат (мировые координаты через
   `latlon_to_world` + `get_terrain_height`) с джиттером 15 м вместо
   случайного угла кольца; фолбэк прежний.
3. `zone_controller._initialize_run` (выживание): передать в спавн-менеджер
   флаг `gate_mode = true` (карта == pripyat).
4. Миникарта: врата — жёлтые треугольники (угол прихода волны читается
   заранее — честное предупреждение).

**Трогает:** data/survival_data.gd, managers/spawn_manager.gd,
zones/zone_controller.gd (5 строк), ui/hud (миникарта — точки). НЕ трогает:
эскалацию/награды/выбросы 33/43/53, кампанию/башню на Припяти.

**Почему награды НЕ растут:** большая карта = сталкеры идут дольше (раннее
предупреждение миникартой), но застройка даёт chokepoints — узкие улицы
усиливают аномалии. Баланс сходится сам; размазывать формулы не нужно.
