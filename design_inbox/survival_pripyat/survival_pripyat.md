# Выживание на карте Припяти — спавн-врата и вилки волн (D9)

Статус: спека под встраивание. Опора: `managers/spawn_manager.gd`
(`_get_spawn_position`: кольцо 70–120 м + рейкаст вниз, фолбэк 75 м,
`MIN_SPAWN_DISTANCE_BETWEEN_STALKERS`), `data/survival_data.gd`
(эскалация 8+0.7×(N−1) до 28, MILESTONES, blowout 33/43/53),
`terrain/pripyat_map_3d.gd` (`latlon_to_world`, `get_terrain_height`,
`MONOLITH_ROUTE`, вода/лес полигонами), `zones/zone_controller.gd`
(выживание: Монолит на `monolith_position_for_level(1)` = центр Припяти,
51.4050/30.0560).

## 1. Принципы

1. **Только геометрия.** Эскалация, награды, вехи, выбросы, фаза легенды —
   ровно как на процедурной карте: один баланс выживания на обеих картах,
   иначе двойная поддержка навсегда.
2. **Сталкеры приходят ИЗ города.** Врата в районе-ориентирах (стадион,
   автостанция, парк, выезд) — на дорогах, не в стенах домов: координаты
   проверены по слоям OSM (roads поблизости, не water).
3. **Монолит стоит в центре** (route[0], площадь у ДК): плотная застройка =
   chokepoints, это и есть фишка Припяти. НЕ переносить на стадион/угол.
4. **Честность:** активные врата волны видны на миникарте до старта волны
   (в передышке), сталкеры не «телепортируются за спину».

## 2. Спавн-врата (lat, lon; от Монолита в центре)

| id | Точка | lat/lon | Дист. от Монолита | Направление |
|---|---|---|---|---|
| gate_sw | Автостанция | 51.4025, 30.0530 | ~300 м | юго-запад |
| gate_e | Стадион | 51.4047, 30.0615 | ~380 м | восток |
| gate_n | Северный парк | 51.4080, 30.0600 | ~470 м | север |
| gate_far | Выезд из города | 51.4055, 30.0730 | ~1100 м | восток-дальний |

Все четыре — из `MONOLITH_ROUTE` (уже проверены как проходимые), врата =
точка ± джиттер 15 м + рейкаст на рельеф (как сейчас). Расстояния в 3–9 раз
больше аренного кольца — ходьба по улицам с обходами даёт ещё ~1.5–2×
времени: сталкеры приходят партиями, а не стеной. `gate_far` подключается
последним (волны 16+) — дальний фланг как событие.

Порядок активных врат детерминирован по волне: `(wave * 7) % активные`
— сторона захода меняется, но предсказуема в передышке (миникарта).

## 3. Вилки волн 10 / 20 / 30

| Волна | Врат | Сталкеров на волну (vs процедурная) | Прочее |
|---|---|---|---|
| 1–5 | 1 | как процедурная (8→10) | обучение раскладке |
| 6–15 | 2 | как процедурная (11→17) | две стороны — камера вертится |
| 10 | 2 | 14 (как формула) | milestone-награда обычная |
| 16–30 | 3 | формула +1 (компенсация ходьбы: 18→28) | 20-я: 22 (21+1) |
| 31+ | 4 | формула +1 до потолка 29 | фаза легенды как есть |

+1 сталкер с 16-й волны — единственное отличие эскалации: дольше ходьба =
растянутая волна, игрок успевает; плотность боя не должна падать. Потолок
28 → 29 (`MAX_COUNT_PER_WAVE` клампить именно для gate-режима, процедурную
не трогать).

## 4. Готовый блок констант

```gdscript
# data/survival_data.gd — выживание на Припяти (спека D9)
# Спавн-врата вокруг центра Припяти (lat/lon; точки MONOLITH_ROUTE, см.
# design_inbox/survival_pripyat/survival_pripyat.md §2). Используются
# ТОЛЬКО на карте "pripyat" в выживании: вместо кольца 70-120 м.
const SPAWN_GATES := [
	{"id": "gate_sw",  "lat": 51.4025, "lon": 30.0530},
	{"id": "gate_e",   "lat": 51.4047, "lon": 30.0615},
	{"id": "gate_n",   "lat": 51.4080, "lon": 30.0600},
	{"id": "gate_far", "lat": 51.4055, "lon": 30.0730},
]
const GATE_JITTER: float = 15.0            # м разброса вокруг врат
const GATES_COUNT_BY_WAVE: Array[int] = [1, 2, 3, 4]
const GATES_WAVE_TIERS: Array[int] = [1, 6, 16, 31]  # с какой волны N врат
const GATE_BONUS_COUNT: int = 1            # +1 сталкер с 16-й (компенсация ходьбы)
const GATE_MIN_WAVE: int = 16

## Число активных врат на волне (1..4)
static func gates_for_wave(wave: int) -> int:
	var n := 1
	for i in GATES_WAVE_TIERS.size():
		if wave >= GATES_WAVE_TIERS[i]:
			n = GATES_COUNT_BY_WAVE[i]
	return n

## Индекс первой активной враты на волне (детерминированный сдвиг старта)
static func gates_start_index(wave: int) -> int:
	return (wave * 7) % SPAWN_GATES.size()
```

Вставка в `spawn_manager._get_spawn_position()` (ветка до кольца):

```gdscript
# Врата Припяти (выживание): точка врат + джиттер, дальше общий рейкаст
if gate_mode and gate_points.size() > 0:
	var gates := _active_gates(current_wave)  # по SurvivalData.gates_for_wave
	var g: Vector3 = gates[randi() % gates.size()]
	var angle := randf() * TAU
	var dist := randf() * SurvivalData.GATE_JITTER
	var pos := g + Vector3(cos(angle) * dist, 100.0, sin(angle) * dist)
	# далее существующий рейкаст вниз и проверка _last_spawn_positions
```

(`gate_mode` ставит zone_controller в выживании на Припяти;
`gate_points` — мировые координаты врат, считает zone_controller через
`latlon_to_world` + `get_terrain_height` при старте забега и передаёт
списком.)

## 5. Миникарта и подача

- В передышке: HUD-строка «Волна N: сталкеры с [СВ] и [В]» + жёлтые
  треугольники врат на миникарте (только активные). Точки врат есть до
  волны — прогноз честный.
- После спавна врата гаснут (обычные точки сталкеров на миникарте видны и
  так).
- Плашка первой волны на Припяти: «Город живёт своей жизнью: сталкеры
  придут с улиц» (однократно, `show_event_note`).

## 6. Ручки перебора

- «Слишком долго идут» → GATE_JITTER 15→10 и врата ближе: gate_sw
  51.4032/30.0540 (~230 м); радикально — GATES_WAVE_TIERS вторая 6→4.
- «Стена с трёх сторон на 30+» → GATES_COUNT_BY_WAVE кап 3.
- «На 16+ пусто» → GATE_BONUS_COUNT 1→2 (или wave_bonus без изменений
  оставить — плотность не критична).
- Кемпинг врат (аномалии на точке) — это ВАЛИДНАЯ тактика; если убивает
  разнообразие: джиттер 15→35 (врата «размываются» в сектор).

## 7. Чек-лист приёмки

1. Выживание на Припяти, волна 1: сталкеры приходят с юго-запада
   (автостанция) по улице, а не спавнятся рядом с Монолитом.
2. Волна 6: два направления; треугольники врат на миникарте до волны.
3. Волна 16: три врата, count = формула +1; 31+: четыре, потолок 29.
4. Кампания/башня на Припяти: спавн кольцом как раньше (gate_mode false).
5. Процедурная карта: всё без изменений (ветка не активируется).
6. Сталкеры не застревают в зданиях по пути от врат (навмеш Припяти
   дорожный; если залипание — точку врат сдвинуть на дорогу, lat/lon
   в константе).
7. Вехи/выбросы/фаза легенды — работают как на процедурной (не задеты).
