# Онбординг новичка — как встраивать

**Что это:** интерактивные подсказки первых 15 минут: сценарий шагов
(лаба → пачка → ВЫЛАЗКА → аномалия → мутант → СТАРТ → 3 волны → итоги/гача)
с подсветкой нужной кнопки и мягкими подсказками Голоса Зоны. Не модальные
попапы на весь экран, пропуск для опытных (флаг onboarding_done), состояние
в сейве.

**Зачем:** новичок падает в лабу с 20+ кнопками; канон («ГОЛОС ЗОНЫ»,
брифинг) есть, но не ведёт за руку. D25-кодекс объясняет правила чтением,
онбординг — проведением за руку.

**Как встраивать (кратко):**
1. Новый `ui/onboarding/onboarding.gd` (CanvasLayer слой 15): сценарий —
   список шагов {текст, целевой узел/путь, сигнал завершения}; подсветка
   = рамка вокруг узла (Panel с дыркой через 4 ColorRect), стрелка сверху.
2. Триггеры шагов — существующие сигналы (Signals.wave_started и пр.) +
   опрос состояний (пачка заполнена, аномалия поставлена).
3. Флаги: `save.onboarding_done: bool`, `onboarding_step: String` —
   продолжение с середины после перезапуска.
4. Ассеты: `assets/ui/onboarding/` (портрет наставника — уже встроены).
5. Кнопка «ПОВТОРИТЬ ОБУЧЕНИЕ» в настройках.

**Трогает:** новый ui-файл, lab_controller (спавн на первом запуске),
save_data (+2 поля), Loc. НЕ трогает: логику режимов, баланс, HUD боя.
