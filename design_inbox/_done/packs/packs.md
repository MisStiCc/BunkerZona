# Пачки мутантов, роли и Эхо Монолита (D20)

Опора: `data/lab_data.gd` (loadout 9+9), `data/gacha_data.gd` (пулы,
варианты v0.30 как прецедент ре-колора), `ui/hud/hud.gd` (фаза набора,
`_loadout_tap`), `zones/zone_controller.gd` (фаза подготовки, spawn),
`entities/mutants/base_mutant.gd` (статы/звёзды/Прорыв), D19 (босс как
полигон ролей), D18 (Прорыв — поздние пачки сильные).

## 2. Роли (тег + новая механика аур)

Роль = метка на карточке (цвет+пиктограмма) и пассивная аура. Ауры —
новый компонент `components/aura_component.gd`: радиус, тик 0.5 с,
действие на союзников-мутантов; стаки от разных видов суммируются с
капом (ручка AURA_STACK_CAP 2).

`data/mutant_roles_data.gd`, карточки красятся меткой роли.

Гача/коллекция: новые виды входят в пулы (uncommon/rare по цене), гейт
кольцами — сбор «полного состава пачки» растянут; дубли — копии/Прорывы
как у всех.

## 3. Эхо Монолита (многорубежная оборона)

- В фазе подготовки: кнопка «ЭХО» на каждый открытый доп. рубеж; ставится
  в точку как аномалия (не ближе 60 м к Монолиту и другим Эхо), лимит =
  число открытых пачек − 1.
- Пачка привязывается к рубежу (панель мутантов переключается активным
  рубежом; тап у чужого рубежа спавнит чужую пачку — запрещено).
- Сталкеры выбирают ближайший рубеж; волновой пул:
  `count × (1 + 0.5 × (рубежи − 1))` — больше врагов, но и больше огневых
  точек; распределяются поровну по рубежам с джиттером.
- Поражение: ВСЕ рубежи пали (пал рубеж → его пачка отступает к соседнему,
  может спавниться там — осада).
- Награда: `×(1 + 0.25 × (рубежи − 1))` к боевому доходу; кампания — без
  рубежей до цикла 3 (уровни живут как были; рубежи — башня? НЕТ: Эхо
  доступно во всех режимах при открытых пачках; баланс волн уже ×1.5).
- Выживание на Припяти: Эхо в центральных точках (прецедент врат D9).
- Выброс бьёт по всем рубежам одинаково (правила прежние).

```gdscript

const ROLES := {"zombie": Role.DMG, "dog_mutant": Role.DMG, ...,

	"zaveden": Role.BUFF, "vikhor": Role.BUFF, "shorokh": Role.BUFF,
	"leden": Role.CONTROL, "guden": Role.CONTROL}

	"mohovik": {"radius": 8.0, "heal_pct": 0.03},
	"tsveten": {"radius": 10.0, "pulse": {"heal_pct": 0.12, "targets": 2, "cd": 6.0}},
	"zhivitsa": {"radius": 0.0, "beam": {"heal_pct": 0.25, "cd": 10.0}},
	"zaveden": {"radius": 10.0, "dmg_pct": 0.15},
	"vikhor": {"radius": 10.0, "speed_pct": 0.20},
	"shorokh": {"radius": 10.0, "atk_speed_pct": 0.15},
	"leden": {},   # не аура - эффект атаки
	"guden": {"radius": 6.0, "fear_cd": 8.0, "fear_time": 1.5},
}
const PACK_SIZE: int = 9
const PACK_UNLOCK_CYCLES: Array[int] = [3, 5, 7]
const FRONT_WAVE_MULT: float = 0.5     # за доп. рубеж

```

- `components/aura_component.gd`: привязан к мутанту, тик 0.5 с, ищет
  союзников-мутантов (группа "mutants") в радиусе, применяет модификаторы
  с капом стаков; хил-пульсы/лучи — по кулдауну.
- `lab_data`: `packs`, `active_pack`; `loadout` = packs[0] для совместимости
  (миграция: старый loadout → packs[0], старые сейвы без потерь).
- HUD: вкладки пачек; `zone_controller`: массив рубежей `fronts: Array[Vector3]`,
  привязка спавнов, деление волн, game-over по последнему рубежу.

## 5. Ручки перебора

«Хил имбалансный» → AURA_STACK_CAP 2→1 и реген 3%→2%; «Эхо слишком легко»
→ FRONT_WAVE_MULT 0.5→0.8; «новых видов мало для 3 пачек» → гейты понижать
(кольца) раньше, чем добавлять виды; «дубликаты душат» → виды новых семей
в rarity_weights rare-сегмента +0.5.

## 6. Чек-лист приёмки

1. Цикл 3: доступна пачка 2 и одно Эхо; вид из пачки 1 нельзя взять в 2-ю
   (перенос с подтверждением).
2. Эхо ставится, сталкеры делятся по рубежам, волн больше на 50%, награда
   ×1.25; пал один рубеж — пачка отступает, игра продолжается.
3. Новые виды: гача выдаёт по гейтам кольцами; ауры видны (частицы+цифры
   хила), стаки капятся.
4. Роли на карточках (пиктограммы), в кодексе (D15) страница «роли».
5. Охота (D19) с хилером против Костолома проходит ровнее, чем спам урона
   (проверка смысла ролей).
6. Старый сейв: loadout → пачка 1, всё живо; режимы без пачек (цикл <3)
   не изменились.
