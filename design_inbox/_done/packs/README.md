# Пачки мутантов и роли — как встраивать

**Что это:** ростер мутантов расширяется поддерживающими видами (хилы/
бафы/контроль), набор переходит на «пачки» — независимые группы по 9
(вид не может быть в двух пачках); на поздних циклах NG+ забег получает
дополнительные рубежи обороны («Эхо Монолита») — по пачке на рубеж.

**Зачем:** тактическая глубина: составы «урон/танк/хил/баф» вместо одного
универсального набора; многорубежная оборона на большой карте — ответ на
растущие циклы NG+; новые виды = новая коллекция (гача/ферма/Прорывы).

**Как встраивать (кратко):**
1. `data/mutant_roles_data.gd` (роли текущих 27 видов + 8 новых, §3).
2. 8 новых видов на re-колорах существующих моделей (прецедент вариантов
   v0.30): 3 хила, 3 бафа, 2 контроля — у каждого НОВАЯ пассивная
   способность (ауры) — реальный код в base_mutant.
3. Пачки: `lab_data.pack assignments` + UI-вкладки в фазе набора;
   запрет дубликатов между пачками.
4. Эхо Монолита: ставится в фазе подготовки, пачка привязана к рубежу;
   сталкеры делятся, волновой пул ×1.5/рубеж, награда ×1.25/рубеж.

**Трогает:** lab_data (пачки/распаковка), spawn_manager (ауры/роли),
base_mutant (аурные способности), zone_controller (рубежи), UI набора,
гача/ферма (новые виды в пулах — гейт кампанией). НЕ трогает: баланс
аномалий, церемонии, сейв-слоты.
