| Состояние | Y-поведение | Кто управляет |

## 3. Готовый блок констант + правки

```gdscript
# entities/mutants/base_mutant.gd — левитация (спека D10)
@export var hover_height: float = 0.0     # есть; > 0 = летающий
@export var hover_bob_amplitude: float = 0.25  # м качания; 0 = парить ровно
@export var hover_bob_speed: float = 2.2       # рад/с (полтергейст: цикл ~2.9 с)
@export var hover_strength: float = 2.5        # коэф. регулятора (текущий *2.5)
@export var hover_max_speed: float = 2.5       # м/с кламп вертикали (текущий)
# Подавление hover грав-аномалией: аномалия ставит мутанту
# set_meta("hover_suppressed", true), снимает по выходу из зоны;
# страховка - таймер: подавление живёт не дольше HOVER_SUPPRESS_MAX.
const HOVER_SUPPRESS_MAX: float = 1.5         # сек
const DEATH_FALL_SPEED: float = 3.0           # м/с кап спуска трупа
```

Правка hover-ветки (base_mutant._physics_process):

```gdscript
if hover_height > 0.0 and current_state != State.DEAD:
        if get_meta("hover_suppressed", false):
                pass  # аномалия рулит Y сама; страховка снимет мету по таймеру
        else:
                var bob := sin(Time.get_ticks_msec() / 1000.0 * hover_bob_speed) \
                        * hover_bob_amplitude
                var target_y := _ground_below_y() + hover_height + bob
                velocity.y = clampf((target_y - global_position.y) * hover_strength,
                        -hover_max_speed, hover_max_speed)
elif current_state != State.DEAD and not is_on_floor():
        velocity.y -= gravity * delta
```

Правка смерти: в DEAD-ветку (сейчас ранний `return`) — перед return
один раз осадить труп: `velocity.y = -DEATH_FALL_SPEED` + `move_and_slide()`
до касания пола (флаг `_corpse_settled`), hover не применять. Труп ложится
на землю, дальше существующая логика (клип смерти/queue_free).

Правка полтергейста: удалить `_float()`, `flight_height`, `float_offset`
(весь блок poltergeist.gd:58-67 и вызов), качание теперь в базе;
`hover_height = 1.6` остаётся. `_physics_process` полтергейста сохраняет
только невидимость/телекинез.

## 4. Грав-аномалии (правила встречи)

- **Воронка (gravity_vortex)**: тянет по XZ к центру; hover вернёт Y сам —
  конфликтов нет, подавление НЕ нужно (воронка не рулит Y).
- **Лифт (gravity_lift)**: подбрасывает по Y — ставит мутанту
  `set_meta("hover_suppressed", true)` на время воздействия (или до
  HOVER_SUPPRESS_MAX); мутант взлетает по физике лифта, после выхода
  hover мягко вернёт (регулятор с клампом сам даёт плавный спуск).
- Сталкеры-крышелазы уже лечатся спасением на навмеш (v3) — мутантам
  это не нужно: hover сам возвращает на высоту над рельефом.

## 5. Ручки перебора

- Качание «дёрганое» → hover_bob_amplitude 0.25→0.15 или hover_speed 2.2→1.6.
- «Висит бревном» над ямой/обрывом → hover_strength 2.5→3.5 (быстрее
  догоняет рельеф; кламп не даёт рывка).
- Лифт закидывает слишком высоко → это ручка самой аномалии, не hover.
- Труп падает слишком быстро → DEATH_FALL_SPEED 3.0→1.5 (медленное
  «оседание дыма» — атмосферно).

## 6. Чек-лист приёмки

1. Полтергейст патрулирует: плавное качание ±0.25 м видно (не «ровный столб»).
2. Преследует сталкера по ломаному рельефу/через канаву — высота держится,
   кламп не даёт рывков.
3. Смерть: труп опускается на землю (не висит), дальше таймер как у всех.
4. Лифт: мутант взлетает по аномалии, после выхода плавно возвращается
   на 1.6 м.
5. Воронка: тянет по земле, полтергейст не «отрывается» странно.
6. Остальные мутанты (hover_height = 0): поведение без изменений.
7. Невидимость/телекинез/статы — без изменений.
