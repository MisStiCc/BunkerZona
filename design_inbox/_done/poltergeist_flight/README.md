# Левитация полтергейста — как встраивать

**Что это:** доводка уже реализованного парения (hover_height 1.6 + рейкаст
рельефа в base_mutant): устранение конфликта двойного управления высотой
(синус-качание перекрывается hover-регулятором), спуск трупа при смерти,
правила встречи с гравитационными аномалиями. Все константы — ручки.

**Зачем:** полтергейст парит, но качание мёртвое (полтергейст `_float`
пишет velocity.y, потом super перезаписывает), ветка flight_height 5.0 —
мёртвый код, труп умирает в воздухе и висит на 1.6 м.

**Как встраивать (кратко):**
1. `base_mutant`: в hover-ветку добавить `hover_bob_amplitude` (синус от
   `Time.get_ticks_msec`) — качание живёт в БАЗЕ, не в наследнике.
2. `poltergeist`: удалить `_float`/`flight_height` (мёртвый код), оставить
   только `hover_height = 1.6` + ручки качания.
3. Смерть: при DEAD hover игнорировать → труп плавно оседает (гравитация,
   скорость капится) — 3 строки в base.
4. Грав-аномалии: воронка/лифт временно заглушают hover (флаг
   `hover_suppressed`, ставят аномалии, снимает base по таймеру 1 с).

**Трогает:** entities/mutants/base_mutant.gd (hover-ветка + смерть),
entities/mutants/poltergeist.gd (чистка _float). НЕ трогает: FSM, телекинез,
невидимость, гейм-дизайн цен/статов.
