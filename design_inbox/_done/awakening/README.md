# Прорыв мутантов (5★ → 10★) — как встраивать

**Что это:** вторая ступень прокачки. Мутант с 5★ может ПРОРВАТЬСЯ: звёзды
окрашиваются в неоново-фиолетовый, и его можно прокачать ещё до 10★;
каждый пробуждённый шаг даёт больший прирост силы, чем обычная звезда.

**Зачем:** прокачка упирается в потолок 5★ — ветеранам коллекции некуда
расти; Прорыв даёт долгосрочную цель, привязанную к ежедневному боссу
(ресурс «Искры Пробуждения», спека D19).

**Как встраивать (кратко):**
1. `data/lab_data.gd`: `awaken_stars: Dictionary` (вид → 0..5), константы
   AWAKEN_*; `MAX_STARS` остаётся 5 (обычный рецепт), пробуждённые шаги
   считаются отдельно (итог 6–10★).
2. Рецепт Прорыва (5★→6★): Искры Пробуждения 3 + биомасса 5 000 × цикл NG+.
   Шаги 6→7→8→9→10 — обычный рецепт звёзд с расширенной таблицей стоимостей
   (§3). Кнопка «ПРОРЫВ» на ферме у мутанта 5★.
3. Формула силы: `stat_mult = 2.0 × AWAKEN_STEP ^ (awaken_stars)`
   (AWAKEN_STEP 1.20 → 10★ = ×4.98 к базовым статам; обычные 5★ = ×2.0).
4. Визуал: неон-фиолет `Color(0.70, 0.40, 1.00)` — звёзды в строках фермы/
   галереи/гачи, кайма карточки; на модели — лёгкая фиолетовая эмиссия
   (клон материала, как у артефактов).

**Трогает:** data/lab_data.gd (ресурс+константы), data/gacha_data.gd
(расширение STAR_FEED_COST), ui/lab (ферма: кнопка ПРОРЫВ, цвет звёзд),
core/game_manager.apply_star_recipe (шаги 6–10), spawn_manager (передача
awaken-бонуса мутанту). НЕ трогает: баланс врагов (завязан на NG+ циклы),
сейв-структуру (новый словарь с миграцией = пусто).
