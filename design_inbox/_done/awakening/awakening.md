# Прорыв мутантов (D18)

Опора: `data/lab_data.gd` (MAX_STARS 5, `mutant_stars`, рецепт/стоимости),
`data/gacha_data.gd` (STAR_FEED_COST {1:2,2:4,3:6,4:8}, FODDER_VALUE),
`core/game_manager.gd` (`get_star_requirements`, `apply_star_recipe`,
`get_star_stat_mult` — сейчас 1+(N−1)×0.25), `ui/lab/lab_controller.gd`
(ферма/звёзды), `managers/spawn_manager.gd` (звёзды мутанту при спавне).
Ресурс «Искры Пробуждения» вводится спекой D19 (ежедневный босс).

## 1. Правила

| Параметр | Значение | Ручка |
|---|---|---|
| Обычный потолок | 5★ (не меняется, рецепт прежний) | — |
| Прорыв | 5★ → 6★: Искры 3 + биомасса 5 000 × цикл NG+ | AWAKEN_COST_SPARKS 3, AWAKEN_COST_BIO 5000 |
| Шаги 6→10 | обычный рецепт звёзд, таблица дороже (§3) | STAR_FEED_COST_EXT |
| Сила пробуждённого шага | ×1.20 за шаг сверх 5★ | AWAKEN_STEP 1.20 |
| Итог 10★ | ×4.98 от базы (против ×2.0 у 5★) | следствие |
| Визуал | неон-фиолет Color(0.70, 0.40, 1.00): звёзды, кайма карточки, лёгкая эмиссия модели | AWAKEN_COLOR |
| Отображение | 5 золотых + 5 фиолетовых звёзд (строки «★★★★★⬤⬤⬤⬤⬤» с цветом) | — |

Балансовая логика: 10★ достижим только через ~недели ежедневного босса
(Искры 3 за первый килл/день) + копии из гачи — длинная цель, не чип.
Враги масштабируются циклами NG+ (×1.15→) — Прорыв это «успевать за Зону»,
а не вечный чит.

## 2. Расширение стоимостей шагов 6→10 (обычный рецепт: копии N+1 цели)

| Шаг | Звёздный корм (очков) | Простые корма |
|---|---|---|
| 5→6 | после Прорыва (Искры) | — |
| 6→7 | 10 | 10 |
| 7→8 | 12 | 12 |
| 8→9 | 14 | 14 |
| 9→10 | 16 | 16 |

`STAR_FEED_COST_EXT := {6: 10, 7: 12, 8: 14, 9: 16}` — get_star_feed_cost
смотрит сначала EXT, затем базовую таблицу. Копии цели: N+1 как раньше.

## 3. Данные и код-правки

```gdscript
# data/lab_data.gd
const AWAKEN_MAX: int = 10
const AWAKEN_COLOR := Color(0.70, 0.40, 1.00)   # неон-фиолет
const AWAKEN_STEP: float = 1.20                  # множитель за шаг сверх 5★
const AWAKEN_COST_SPARKS: int = 3                # Искры за сам Прорыв
const AWAKEN_COST_BIO: float = 5000.0            # x цикл NG+
@export var awaken_stars: Dictionary = {}        # вид -> 0..5
@export var awaken_sparks: int = 0               # Искры Пробуждения
# (миграция: поля отсутствуют -> 0/пусто, super.reset() очищает)
```

- `get_star_stat_mult(stars, awaken)`: `1 + (5-1)×0.25` за обычные +
  `AWAKEN_STEP ^ awaken` за пробуждённые (5★+awaken=0 → ×2.0 как было).
- `apply_star_recipe`: шаги ≥6 списывают Искры? НЕТ — Искры только за сам
  Прорыв (5→6); шаги 6→10 — копии/корма как раньше. Отдельный
  `apply_awaken(target)` с гвардом «ровно 5★».
- `spawn_manager`: мутанту при спавне передаются и awaken-звёзды
  (статы через общий get_star_stat_mult).
- UI фермы: строка вида — цвет звёзд (золото/фиолет), кнопка «ПРОРЫВ»
  (видна только при 5★), счётчик Искр в шапке фермы.
- Гача/галерея: кайма карточки фиолетовая при awaken>0.
- Дисплей звёзд: `LabData.stars_text(stars, awaken)` — дорисовка фиолетовых.

## 4. Краевые случаи

- Прорыв доступен и без 5★? НЕТ — гвард. Кнопка скрыта до 5★.
- Утилизация пробуждённого дубликата (корм той же звёздности): очки как у
  5★-корма (5) — awakening не переносится кормом (только целью).
- Арена/сезон: пробуждённые легальны (это PvE-прогресс; честность арены
  закрыта сезонным сбросом — прецедент D16).
- Старые сейвы: полей нет → 0; ничего не ломается.
- Дисплей в компактных строках фермы: «★★★★★» золотом + «+N» фиолетом
  (место экономим).

## 5. Чек-лист приёмки

1. Мутант 5★: кнопка ПРОРЫВ; после — 6★ фиолетовой звездой, статы ×2.4.
2. Шаги 6→10 работают расширенной таблицей; 10★ = ×4.98.
3. Искры списываются только за Прорыв; повторный Прорыв заблокирован.
4. В бою пробуждённый заметно крепче (визуально: фиолетовая эмиссия).
5. Старый сейв без полей: всё как было, ошибок нет.
