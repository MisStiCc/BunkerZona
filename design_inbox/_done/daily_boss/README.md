# Ежедневный босс — как встраивать

**Что это:** режим «ОХОТА»: без Монолита — игрок расставляет мутантов,
те сами идут валить босса; босс отвечает автоатакой и скиллами. 6 боссов
на неделю: Пн–Чт — по паре (состав пары зависит от чётности даты), Пт —
один, Сб — один, Вс — все шесть. С босса падает «Искра Пробуждения» —
ресурс Прорыва (D18).

**Зачем:** ежедневный повод зайти + единственный источник ресурса
Прорыва → ритм «каждый день охота, копишь Искры, делаешь Прорыв».

**Как встраивать (кратко):**
1. `data/boss_hunt_data.gd` (6 боссов: статы/скиллы/награды/расписание —
   блок §3), `lab_data.awaken_sparks` (введён D18).
2. Новые `entities/bosses/` (6 сцен: ре-колор существующих моделей +
   скрипт босса: автоатака + 2–3 скилла по кулдаунам).
3. Новый `run_kind = "hunt"` в zone_controller: без Монолита/волн/выбросов,
   босс идёт к краю карты («уходит из Зоны») — дошёл = поражение; таймер 3 мин.
4. Кнопка «ОХОТА» в лаборатории + расписание на неделю в кодексе (D15).

**Трогает:** новые data/boss файлы, zone_controller (ветка hunt),
save_data (ежедневные отметки), lab UI. НЕ трогает: баланс трёх режимов,
церемонии, гачу.
