## 2. Принципы

1. **Прямые SKU, без донат-валюты.** Покупка = конкретный продукт (пак
   круток, пропуск, косметика). Меньше политик стора, честнее цены,
   проще восстановление. Донат-валюта — ручка на вырост (Этап 3).
2. **Сила продаётся, арена предупреждается.** Крутки = сила; арена
   (лидерборд волн) обновляется каждый сезон → естественный catch-up.
   В описании магазина честная плашка «влияет на прогресс». Никогда не
   продаём: энергию напрямую, победы, уровни кампании, отключение
   радиации, таймеры (список §7 — граница не для торга).
3. **Шансы гачи публикуются** (политика Google для лутбоксов): в UI гачи
   кнопка «Шансы» → проценты из `rarity_weights(level)` + веса видов.
   Это и без монетизации полезно.
4. **Офлайн-игра, онлайн-покупки.** Покупки требуют сети; владение
   кэшируется в сейве; восстановление — кнопкой (queryPurchases).
5. **Всё содержимое оплаченного должно быть достижимо бесплатно** —
   платное ускоряет/украшает, не эксклюзивно-силовое (кроме «Эксклюзив
   на выбор» — см. §5, осознанное исключение по решению владельца).

## 4. Пропуск сезона (премиум-ветка трека)

Трек уже есть: 30 ступеней, цикл, сундуки, ЧЯ на 10/20/30. Пропуск = вторая
строка наград на КАЖДОЙ ступени (премиум-колонка), доступная с покупкой
`pass_sN` (N = текущий cycle). Содержимое премиум-колонки (ручки, на цикл):

| Ступени | Премиум-награда |
|---|---|
| 1–9 | чередование: 2 крутки мутантов / 2 аномалийных / рамка сезонная (на 5-й) |
| 10 | +аватар сезона и 4 крутки мутантов (на ЧЯ-ступени не дублируем ящик) |
| 11–19 | чередование кормов: звёздный корм / 3 крутки / биомасса 20 000 |
| 20 | титул сезона + 5 аномалийных |
| 21–29 | чередование: 3 крутки / рамка / биомасса 30 000 |
| 30 | **эксклюзивная косметика сезона** (рамка+аватар+титул комплектом) + 10 круток |

Экономика: покупка окупается ценностью содержимого ~×3 (стандарт F2P);
силовая ценность премиум-ветки = крутки/корма, НЕ прямые мутанты.
Задним числом (купил в середине цикла) — премиум-награды уже пройденных
ступеней выдаются разом при активации (кнопка «Забрать всё»).

## 5. Честность арены

Арена = лидерборд волн. Покупки силы смещают топ → меры:
- сезонный сброс борда уже есть — catch-up встроен;
- в карточке соперника плашка «поддержавший» (титул/рамка видны и так);
- НЕ продаём: биомассу напрямую в бой (стартовые отряды), множители статов,
  доп. выбросы. Крутки — косвенная сила через RNG, это осознанная граница
  (решение владельца, «магазин силы» выбран);
- ручка перебора: если топ-100 станет полностью платным — ввести
  «честный зачёт» (отдельный борд для аккаунтов без покупок силы),
  константа-флаг в store_data.

`managers/billing_manager.gd` (новый, группа "billing"):
- плагин **GodotGooglePlayBilling** (официальный, AssetLib); в export-пресете
  Android включить плагин; на ПК/в редакторе биллинг недоступен —
  `ENABLED and store_available`;
- поток: `startConnection()` → `queryProducts(PRODUCTS.keys())` → витрина
  (цены из стора, не из нашей таблицы — таблица = фолбэк для оффлайн-UI);
- покупка: `purchaseProduct(id)` → purchase token → **acknowledge в 3 дня
  (требование Google)** → начислить payload → записать в сейв
  (`save_data.owned: Dictionary {sku: token}` для nc; для consumable —
  только факт начисления + лог токена);
- восстановление: `queryPurchases()` — nc видны всегда, consumable после
  расходования — нет (стандарт Play): поэтому **владение пропуском и
  косметикой/удобствами не теряется**, а паки круток восстанавливать
  честно нечем — плашка в UI «расходники восстановлению не подлежат»;
- кэш офлайн: купил в сети → начислено и сохранено → играет офлайн
  сколько хочет; следующее подключение — queryPurchases сверка.
- ВАЖНО без сервера: токены доверяем Play; серверная валидация — Этап 3
  (лёгкий бэкенд + Play Developer API), ручка.

UI магазина: вкладка «МАГАЗИН» в лаборатории (рядом с базаром; на ПК и при
`ENABLED = false` вкладка скрыта). Экраны: витрина (карточки SKU с ценами
стора), «Пропуск» (вилки премиум-колонки поверх панели трека), «Шансы»
(публикация `rarity_weights` + веса видов — также кнопка в самой гаче).

Премиум-ветка трека: в `progression` к выдаче награды ступени добавить
ветку `if pass_active(cycle): выдать PASS_PREMIUM/чередование`; в UI трека
— вторая строка с золотой рамкой, до покупки — замок «открыть за 299₽».

`save_data`: +`owned: Dictionary`, +`pass_cycle: int` (миграция — пусто).

## 7. Никогда не продаём (граница, константа FORBIDDEN)

Энергию напрямую; победу/поражение забега; уровни и кольца кампании;
отключение радиационного фона; таймеры волн/передышек; множители статов;
готовые стартовые отряды в бой; что-либо, ломающее запреты юраудита §1.

## 8. Цены-якоря и воронка (черновые, ручки)

- Якоря 99/149/299/499₽; пропуск 299₽ = «стоит как 10 круток, даёт в 3 раза
  больше ценностью» — главный конверсионный аргумент.
- Воронка (черновая оценка, СНГ F2P): доля платящих 2–4%, конверсия на
  стартовый пак 99₽ — основной вход; пропуск — 60–70% выручки (стандарт),
  паки силы — остальное. Не завышать частоту «ограниченных предложений»:
  не чаще 1 активного оффера одновременно.
- Первый запуск магазина: стартовый пак подсвечен 72 часа с момента
  первого входа (не таймер-давилка, просто пометка «новичковый»).

## 9. Чек-лист приёмки (когда флаг включён)

1. `ENABLED = true` только в Android-сборке с биллингом; на ПК вкладки нет.
2. Покупка пака круток: списание → начисление сразу → токен в сейве →
   повторный запуск не дублирует.
3. Пропуск: премиум-награды ступеней до покупки с замком; после — «Забрать
   всё» выдаёт разом; новый цикл снова требует `pass_sN+1`.
4. Восстановление покупок: nc возвращаются, расходники — плашка-честность.
5. «Шансы» показывают проценты, сумма = 100%.
6. Слоты 12 применяются в фазе набора (обе панели), старые наборы 9/9 живы.
7. Отключение сети: магазин показывает кэш и «нет соединения», покупки
   недоступны, игра работает.
8. Старые сейвы: owned пусто, миграция без ошибок.
