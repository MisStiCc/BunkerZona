# Монетизация — как встраивать

**Что это:** полная система донатов под Android (Google Play Billing):
Пропуск сезона (премиум-ветка трека), магазин силы (крутки/эксклюзивы),
косметика (рамки/аватары/титулы/флаги/эффекты), удобства (слоты набора).
Прямые SKU без промежуточной донат-валюты, якоря 49–499₽.

**Зачем:** запрос владельца. ВАЖНО: по решению владельца монетизация
включается ТОЛЬКО после деговнизации (Этап 0, см. §1) — всё строится за
флагом `monetization_enabled = false`, контент и бренд не трогаем.

**Как встраивать (кратко):**
1. Этап 0 (юр, ВЛАДЕЛЕЦ): деговнизация → потом включение флага.
2. Этап 1 (код): `data/store_data.gd` (SKU/цены/содержимое — блок §6),
   `managers/billing_manager.gd` (обёртка GodotGooglePlayBilling: запрос
   продуктов, покупка, acknowledge, восстановление, кэш офлайн),
   UI-магазин в лаборатории (вкладка рядом с базаром), премиум-ветка трека.
3. Этап 2 (вырост): серверная валидация чеков (Play Developer API) — до
   неё покупки доверяем Play + локальный кэш.

**Трогает:** новые data/manager/ui файлы, progression (премиум-ветка),
save_data (owned/pass). НЕ трогает: баланс свободного геймплея, сейвы
забегов, старые сейвы (миграция = нулевые покупки).
