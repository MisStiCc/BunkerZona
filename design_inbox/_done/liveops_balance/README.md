# Баланс мини-игр live-ops — как встраивать

**Что это:** сведение экономики шести мини-игр к одной кривой: эталонная
партия → 10–12 осколков у КАЖДОЙ игры (сейчас разброс ×4.5), вехи ивента
с порогами по игре (сейчас закрываются одной партией Жатвы), дневной кап
осколков против фарма финала.

**Зачем:** курсы shards_per_score разъехались ×4.5 (Цепь даёт в 4.5 раза
меньше осколков за минуту, чем Взлом), вехи 200–2000 очков закрываются
одной партией Жатвы — вехи/магазин не работают как долгосрочная цель.

**Как встраивать (кратко):**
1. `data/events_data.gd`: блок §4 — PAR-эталоны (score/shards за партию),
   shards_for из PAR, вехи ×milestone_mult по ивенту, дневной кап.
2. Ивент-хаб: плашка капа «осколки за день: N/120».
3. Ничего в самих играх не правится — только кривая в data.

**Трогает:** data/events_data.gd, ui/events/event_hub.gd (кап/плашка).
НЕ трогает: код игр, гачу, пропуск.
