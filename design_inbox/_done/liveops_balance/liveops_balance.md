# Баланс шести мини-игр live-ops (D27)

Опора: код партий `ui/events/game_*.gd` (формулы очков сняты с кода
01.11.2026), `data/events_data.gd` (shards_per_score, MILESTONE_SCORES,
SHOP), вехи хаба (`event_hub._fill_milestones`).

## 1. Факты: формулы очков (снято с кода)

| Игра | Источник очков | Типичная партия новичка | Время |
|---|---|---|---|
| ЖАТВА | клетка ×10 × комбо(1.5+) × ярость, 30 ходов | 3 000–6 000 (хороший 10 000) | 4–6 мин |
| УЛЕЙ | киллы 10/20/35/150 + будка 100×5 + комнаты 200/1 + 500 | 1 200–1 800 | 4–5 мин |
| ЛАБИРИНТ | килл 10+5×волна, 8 волн (6–22 врагов) + 500 | 1 200–2 500 | 5–7 мин |
| ЦЕПЬ | уровень ×100 + сек ×5, до 40 | 300–700 за заход 4–5 мин | 4–5 мин |
| ВЗЛОМ | сейф 500−40×попытки (≤3 ×2), 5+1 сейфов | 1 500–2 500 | 4–6 мин |
| БОЛТЫ | уровень ×150 + бюджет ×50 + 50/хит + 100 золотой | 900–1 800 | 4–6 мин |

## 2. Факты: текущие курсы → осколки за эталонную партию

shards_per_score: Жатва 0.01 · Улей 1/150 · Лабиринт 1/80 · Цепь 1/300 ·
Взлом 1/40 · Болты 1/200.

| Игра | Очки | Осколков сейчас | Должно быть |
|---|---|---|---|
| ЖАТВА | 5 000 | **50** | 12 |
| УЛЕЙ | 1 500 | 10 | 12 |
| ЛАБИРИНТ | 1 800 | **22** | 12 |
| ЦЕПЬ | 600 | **2** | 12 |
| ВЗЛОМ | 2 000 | **50** | 12 |
| БОЛТЫ | 1 400 | 7 | 12 |

Разброс ×25 между Цепью и Взломом за равное время. Плюс **вехи ивента**
(пороги 200–2000 очков) закрываются ОДНОЙ партией Жатвы/Улея/Взлома —
10 наград (46 круток + косметика) за час.

## 3. Решение: единая кривая через PAR-эталоны

Каждая игра получает эталон: {PAR_SCORE — очки хорошей, не идеальной
партии; PAR_SHARDS — осколков за неё (10–12)}. shards_for = score ×
PAR_SHARDS / PAR_SCORE. Дальнейшая балансировка — правкой одного PAR,
курс пересчитывается сам.

## 4. Вехи: пороги по ивенту (milestone_mult)

Вехи должны тянуться на весь ивент (2 недели активной игры ≈ 15–25
партий). Порог = PAR_SCORE × множитель ивента:

| Веха | Множ. | ЖАТВА (PAR 5000) | УЛЕЙ (PAR 1500) | ЦЕПЬ (PAR 600) |
|---|---|---|---|---|
| 1–3 | ×1/2/3 партий | 2 500/5 000/7 500 | 750/1 500/2 250 | 300/600/900 |
| 4–6 | ×5/7/9 | ... | ... | ... |
| 7–10 | ×11/13/15/17/20 | | | |

Итого вехи = 20 партий на ивент — две недели по 1–2 партии в день.

```gdscript
# data/events_data.gd — единая кривая (спека D27)
# PAR: очки хорошей (не идеальной) партии и осколков за неё.
# shards = score * PAR_SHARDS / PAR_SCORE. Курс правится ТОЛЬКО тут.
const PAR := {
	"zharva":     {"score": 5000.0,  "shards": 12.0},
	"uley":       {"score": 1500.0,  "shards": 12.0},
	"labyrinth":  {"score": 1800.0,  "shards": 12.0},
	"chain":      {"score": 600.0,   "shards": 12.0},
	"vault":      {"score": 2000.0,  "shards": 12.0},
	"bolts":      {"score": 1400.0,  "shards": 12.0},
	"finale":     {"score": 5000.0,  "shards": 12.0},
}
# Множитель порогов вех по ивенту (вехи = PAR_SCORE × множитель)
const MILESTONE_MULT := {
	"zharva": 1.0, "uley": 0.3, "labyrinth": 0.36, "chain": 0.12,
	"vault": 0.4, "bolts": 0.28, "finale": 1.0,
}
# Дневной кап осколков (анти-фарм финала): 120 осколков/день
const DAILY_SHARD_CAP: int = 120
```

Вехи: thresholds_i = round(MILESTONE_SCORES[i] × MILESTONE_MULT[event])
(Жатва 200–2000 как было; Улей 60–600; Цепь 24–240 — целые числа
по игре).

## 5. Финал полугодия: анти-фарм

Все игры разом + распродажа = фармили бы осколки круглосуточно. Граница:
- **DAILY_SHARD_CAP 120/день** (≈10 партий) — кап на начисление,
  счётчик в event_state {shard_day, shards_today}; плашка в хабе
  «осколки за день: N/120».
- Распродажа ×0.7 остаётся (траты дешевле, не заработок).
- Вехи финала ×1.0 от PAR каждой игры — те же пороги, что в обычном
  слоте (не удваиваются).

## 6. Целевые метрики (сводка, D27-задание)

| Метрика | Цель | Как достигается |
|---|---|---|
| Длина партии | 3–5 мин | уже так (таблица §1) |
| Победа новичка | со 2–3 попытки | Лабиринт/Улей/Болты — капы врагов; Жатва/Цепь/Взлом — без «fail» вовсе (счёт-прогресс) |
| Осколков за партию | 10–12 у всех | PAR-кривая |
| Осколков за ивент-неделю | 100–160 + вехи-крутки | 10–14 партий × PAR |
| Магазин | рамка за ~1.5 недели, крутка 1–2 раза/нед | цены магазина не трогать |
| Вехи | 20 партий на ивент | milestone_mult |

## 7. Чек-лист приёмки

1. Партия каждой игры с очками ≈PAR даёт 10–12 осколков (±1 на округлении).
2. Вехи ивента: первая — за 1–2 партии, десятая — за ~20 партий.
3. Никакая игра не даёт >120 осколков в день (кап логается в хабе).
4. Финал: кап работает, распродажа ×0.7 на цены, вехи без удвоения.
5. Код игр не тронут — вся правка в data/events_data.gd + плашка капа.
