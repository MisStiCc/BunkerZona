# Редизайн UI-оболочки — как встраивать

> Контекст: задание D5 закрыто владельцем очереди (реализовано этапами
> 10-13: тема «БУНКЕР»). Этот док — ХВОСТ D5, без которого не обойтись:
> встраивание арт-пака lab_ui (ждал именно D5) и навигация панелей
> (27 ручных `visible = false`). Основному агенту: брать при встраивании
> `inbox/lab_ui/`.

**Что это:** консолидация оболочки лаборатории/меню после уже применённой темы
«БУНКЕР» (v4): единый реестр панелей вместо 27 ручных `visible = false`,
нижний таб-бар из 5 групп, хлебные крошки + ESC-стек, встраивание арт-пака
`inbox/lab_ui/` (фоны 2K, nine-patch рамки, иконки станций), правила
читаемости. Один источник стиля — BunkerUI,UiTheme — делегат, lab_ui-кнопки
не используются (у BunkerUI свои 3D-кнопки).

**Зачем:** панели открываются взаимоисключающим кодом в 12+ обработчиках,
навигация неочевидна (8+ панелей, кнопки в разных местах), три системы
стиля конфликтуют, а готовый арт лежит невстроенным.

**Как встраивать (кратко):**
1. `lab_controller`: реестр `PANELS` (§3) + `_open_panel(id)`/`_close_top()`
   c ESC-стеком — заменить ручные `visible` в обработчиках.
2. Таб-бар нижней строки (5 групп, §2) кодом в `VBox`; станции остаются
   в шапке, иконки — из `inbox/lab_ui` (§4).
3. Фоны: `lab_background_2k.png` → lab.tscn, `menu_background_2k.png` →
   main_menu.tscn (за контентом, §4); панели непрозрачные поверх.
4. Константы-ручки — блок §7 в `ui/bunker/bunker_theme.gd` (расширение),
   НЕ в UiTheme (он уже не главный).

**Трогает:** lab_controller (навигация/таб-бар), lab.tscn/main_menu.tscn
(только фоновая подложка), bunker_theme.gd (константы + StyleBoxTexture).
НЕ трогает: логику панелей, сейвы, станции, HUD забега.
