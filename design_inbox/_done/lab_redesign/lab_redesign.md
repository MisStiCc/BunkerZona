# Редизайн UI-оболочки — лаборатория, меню, панели (D5)

Статус: спека под встраивание. Опора: `ui/bunker/bunker_theme.gd`
(BunkerUI — уже применён к меню/лаборатории/гаче, коммиты «БУНКЕР-тема»),
`ui/ui_theme.gd` (UiTheme), `ui/lab/lab_controller.gd` (~5900 строк,
27 ручных `_panel.visible = false`), `ui/main_menu/main_menu.gd`,
арт-пак `inbox/lab_ui/` (доставлен, CC0, генератор `gen_lab_ui.py`).

## 0. Что уже сделано и НЕ переделывается

Тема «БУНКЕР» варианта 4 стоит на всех трёх экранах: палитра (STEEL/GREEN/
HAZARD), шрифты (Russo One / Oswald / JetBrains Mono), стальные панели,
3D-кнопки, хазард-полосы, рамки-контуры, SwipeHelper для свайп-скроллов,
непрозрачные панели (жалоба на просвет закрыта). Эта спека НЕ редизайнит
стиль — она чинит НАВИГАЦИЮ, встраивает АРТ и закрепляет ПРАВИЛА.

## 1. Принципы

1. **Один источник стиля — BunkerUI.** UiTheme остаётся только как
   theme-хук для PopupPanel (делегирует BunkerUI.panel_box). Арт lab_ui —
   материалы ДЛЯ BunkerUI (фоны, nine-patch, иконки), не параллельная тема.
2. **Панель = запись в реестре.** Никаких ручных `visible = false` в
   обработчиках: открытие/закрытие идёт через `_open_panel(id)` /
   `_close_top_panel()` — единая точка, ESC-стек, хлебные крошки.
3. **Экран один — лаборатория.** Меню и сцены гачи — отдельные сцены (как
   есть). Все панели лаборатории — оверлеи внутри неё, NOTHING не меняет
   сцену (сегодня так и есть — фиксируем).
4. **Модальные поверх панелей.** Малые диалоги (детали карты, подтверждения,
   календарь) — свой z-слой, закрываются поверх стека, в реестр не входят.
5. **Минимум .tscn:** правки только «фоновая подложка» в lab.tscn и
   main_menu.tscn (по одному TextureRect). Остальное — кодом.

## 2. Карта экранов

### Лаборатория (главный экран, всё внутри одной сцены)
```
┌─ ШАПКА ────────────────────────────────────────────────┐
│ ЛАБОРАТОРИЯ ▸ [хлебная крошка открытой панели]          │
│ Биомасса/крутки/деньги · селектор режима (3) · карта 🗺 │
│ [СТАНЦИЯ АНОМАЛИЙ] [СТАНЦИЯ МУТАНТОВ] [СТАНЦИЯ МОНОЛИТА]│ ← иконки lab_ui
│ СТАРТ ЗАБЕГА (крупная 3D-кнопка, справа)                │
├─ ПОЛЁТНАЯ ЗОНА (статистика/инфо уровня/брифинг) ────────┤
│              … фон-арт бункера (2K, центр затемнён) …   │
├─ ТАБ-БАР (5 групп, всегда виден) ──────────────────────┤
│ [ПРОКАЧКА] [КОЛЛЕКЦИЯ] [ЭКОНОМИКА] [ОТРЯДЫ] [СИСТЕМА]  │
└─────────────────────────────────────────────────────────┘
```
- Шапка сжимается до 158 px (уже так, «компактный верхний блок»).
- Панель группы — оверлей full-rect (рамка + крошка + ESC), внутри свои
  табы, где их много (магазин: уже есть; ферма: карточки/алтарь/утилизация;
  гача: мутанты/артефакты; галерея: мутанты/артефакты/сеты).

### Главное меню
Схема узлов не меняется: обложка + колонка кнопок + настройки/слоты
(оверлеи, как есть). Меняется фон: `menu_background_2k.png` вместо
сплошной заливки; обложка-SVG остаётся логотипом сверху. Кнопки —
BunkerUI (уже применены).

### Сцены гачи/профиля (ui/gacha, ui/profile)
Отдельные сцены с apply_bunker — не трогаем (это D6-сосед, а не оболочка).

## 3. Реестр панелей и группы таб-бара

Таб-бар (5 групп, нижняя строка, всегда видим; активная — GREEN-подсветка):

| Группа | Панели внутри (текущие имена в lab_controller) |
|---|---|
| ПРОКАЧКА | апгрейд-диалог станции (anomaly/mutant/monolith: `up_panel`) |
| КОЛЛЕКЦИЯ | галерея (`gallery_panel`), гача (`gacha_panel`), звёзды (`star_panel`), ферма (`farm_panel` + `_farm_altar_panel`) |
| ЭКОНОМИКА | магазин (`shop_panel`), хранилище артефактов (стекущий overlay) |
| ОТРЯДЫ | арена (`arena_panel`), оборона (`defense_panel`), врата ярусов (`gates_panel`), задачи (`tasks_ui` — уже виджет, добавить сюда открытым списком) |
| СИСТЕМА | настройки (экран `settings_screen` остаётся), сейв/слоты, язык |

Реестр — const-словарь в lab_controller (ручки в §7):

```gdscript
# id -> {panel: имя var, group, title_key, closable}
const PANELS := {
	"upgrade":  {"var": "up_panel",      "group": "progress", "title": "lab.upgrades"},
	"gallery":  {"var": "gallery_panel", "group": "collect",  "title": "lab.gallery"},
	"gacha":    {"var": "gacha_panel",   "group": "collect",  "title": "lab.gacha"},
	"stars":    {"var": "star_panel",    "group": "collect",  "title": "stars.title"},
	"farm":     {"var": "farm_panel",    "group": "collect",  "title": "lab.farm"},
	"shop":     {"var": "shop_panel",    "group": "economy",  "title": "lab.shop"},
	"storage":  {"var": "storage_panel", "group": "economy",  "title": "lab.storage"},
	"arena":    {"var": "arena_panel",   "group": "squads",   "title": "lab.arena"},
	"defense":  {"var": "defense_panel", "group": "squads",   "title": "lab.defense"},
	"gates":    {"var": "gates_panel",   "group": "squads",   "title": "lab.gates"},
	"tasks":    {"var": "tasks_panel",   "group": "squads",   "title": "lab.tasks"},
}
```

Поведение `_open_panel(id)`: погасить панель своей группы (или все, если
группа «collect» конфликтует — сегодня панели гасят друг друга вручную,
оставляем взаимоисключение ВНУТРИ группы, между группами — тоже: на экране
одна панель), положить id в стек, обновить крошку, `ui_click`.
`_close_top_panel()`: снять верх стека (кнопка «НАЗАД» у панели + ESC).
Старые обработчики (`_on_stars_pressed` и пр.) сводятся к одному вызову.
Малые диалоги (`detail_panel`, календарь, подтверждения) — слой выше,
вне реестра, закрываются первыми.

## 5. Читаемость (правила и проверки)

- Фон панели: альфа ≥ 0.96 (непрозрачность уже есть — держать).
- Контраст текста к фону панели: основной ≥ 4.5:1. Расчёт по текущей
  палитре: TEXT (#cfe0cf) к STEEL (#0d130c) ≈ 12:1 ✓; TEXT_DIM (#8fa38c)
  ≈ 6:1 ✓; TEXT_FAINT (#587059) ≈ 3.3:1 — ТОЛЬКО для декора ≥18 px
  (штампы/подписи пластин), НЕ для читаемого текста.
- Максимум текста в панели: контент выше 60% высоты — в свайп-скролл
  (SwipeHelper уже есть; «ПРОДОЛЖИТЬ» у итогов — образец поведения).
- Активная панель: рамка GREEN + хазард-полоска в её шапке; активный таб —
  заливка BTN_GREEN, неактивный — STEEL.Hover всех кнопок — уже есть.
- Крошка `ЛАБОРАТОРИЯ ▸ МАГАЗИН` — font_mono 15px, TEXT_DIM.

## 7. Ручки-константы (готовый блок в BunkerUI)

```gdscript
# ==== ОБОЛОЧКА v2 (спека D5, design_inbox/lab_redesign) ====
# Навигация
const NAV_TAB_H: int = 64            # высота таб-бара; тесно на мобиле -> 56
const NAV_TAB_FONT: int = 20         # шрифт табов
const NAV_CRUMB_FONT: int = 15       # хлебная крошка
const NAV_ACTIVE_TAB_BG := BTN_GREEN # активный таб; неактивный - STEEL
const NAV_PANEL_BORDER := GREEN      # рамка активной панели
# Панели
const PANEL_FRAME_PATH := "res://assets/ui/lab/panel_frame_9patch.png"
const PANEL_FRAME_MIN: Vector2 = Vector2(96, 96)  # >= 2 клетки nine-patch
const PANEL_BIG_SHARE: float = 0.6   # панель "большая" (рамка-арт), если >= 60% экрана
const PANEL_PAD: int = 12            # внутренние поля панелей
const PANEL_GAP: int = 10            # межэлементные отступы
# Читаемость (правила, см. §5): PANEL_BG_ALPHA >= 0.96,
# основной текст >= 4.5:1, TEXT_FAINT - только >= 18px
const PANEL_BG_ALPHA: float = 0.96
const ICON_STATION_SIZE: int = 48    # иконки станций в шапке (44-56)
```

Перебор: «таб-бар съедает высоту» → NAV_TAB_H 64→56 и сжать полётную зону;
«рамки-арт пестрят» → panel_frame только для арены/галереи (PANEL_BIG_SHARE
0.6→0.75); «фоны отвлекают» → у фона modulate 1.0→0.85.

## 8. Чек-лист приёмки

1. Каждый таб открывает свою группу; на экране максимум одна панель;
   повторный клик по табу — закрыть.
2. ESC/«НАЗАД» закрывает верхнюю панель (модалку — раньше панели);
   крошка показывает «ЛАБОРАТОРИЯ ▸ <панель>».
3. Ни одного нового ручного `visible = false` между панелями (только
   внутри логики одной панели).
4. Фоны 2K на лаборатории и меню; текст читается поверх (контраст §5);
   на 1280×720 и 2560×1440 без обрезов критичных зон.
5. Большие панели — рамка-арт с золотыми уголками, малые — steel;
   станции с иконками; ничего не мигает при переключении.
6. Мобильный портрет: таб-бар 5 кнопок влезает (или 56 px), панели
   свайп-скроллятся (уже SwipeHelper).
7. Регресс: старые кнопки (магазин/ферма/гача/звёзды из шапки/низов)
   открывают те же панели через реестр — путей-дублей нет.
