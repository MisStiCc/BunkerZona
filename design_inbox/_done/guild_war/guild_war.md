# Война гильдий — офлайн-эмуляция (D23)

Опора: `core/guild_sys.gd` (`guild_state`, `ensure_week` — точка объявления,
чат `add_chat`, жетоны), `data/guild_data.gd` (BOT_NAMES, токен-курсы),
оборона арены (`lab._build_defense_ui`, defense отряд, забег выживания с
`arena_run_kind == "defense"`), звук `guild_war.ogg` (зарегистрирован),
прецедент арены: бот-соперники по seed.

## 1. Правила войны

| Параметр | Значение | Ручка (GuildData) |
|---|---|---|
| Период | 1 неделя (совпадает с неделей гильд-босса, `week_key`) | — |
| Объявление | `ensure_week` на новой неделе: соперник — бот-гильдия (имя из генератора seed'ом недели), сила = `player_power × rand(0.8..1.25)` seed'ом | WAR_POWER_SPREAD |
| Бой | оборонный забег с флагом войны (обычная оборона арены, отряд тот же); попытки: 2 в неделю (war_attempts) | WAR_ATTEMPTS 2 |
| Счёт игрока | лучшая из попыток: волны пережитые (`waves_survived`) | — |
| Счёт соперника | симуляция в момент КАЖДОЙ попытки игрока: `enemy_score = enemy_power × curve(week_day)` — обновляется, чтобы соперник «отзывался» на твой результат (перебил — они дотягивают ближе к порогу; осознанная драма) | WAR_ENEMY_FIGHT 0.92 |
| Порог победы | `enemy_score` | — |
| Победа | жетоны: `100 + 20×уровень гильдии` В КАЗНУ (guild treasury) + по 30 жетонов лично; флаг войны «⚔ держим рубеж» в шапке гильдии до следующей недели; рамка «Защитник» при 3+ победах подряд (косметика D16-слота) | WAR_WIN_TOKENS |
| Поражение | 30 жетонов утешения; чат соперника глумится (seed) | — |
| Ничья (равно) | трактуется как победа «по воле Зоны» (проще объяснить) | — |

Балансовая логика: enemy_power около 0.8–1.25× player_power → на низких
уровнях гильдии победы частые (обучение), к 10-му уровню — борьба;
доигрывание обеих попыток почти гарантирует победу активным.

## 2. Поток данных (дневник — переход в онлайн бесплатно)

```gdscript
# guild_state += war: Dictionary
war = {
	"week": week_key(),
	"enemy": "Гильдия «Стальной Клык»",   # генератор имён, seed недели
	"power": 1450,                        # сила соперника (для симуляции)
	"my_score": 0, "enemy_score": 0,      # лучшая попытка / симуляция
	"attempts": 0,                        # из WAR_ATTEMPTS
	"state": "open",                      # open | won | lost (по итогам недели)
}
# Лог (add_chat_dict) события: объявление (Пн), каждая попытка, итог (Пн след.)
```

- `ensure_week`: если war.week != week_key → прошлая война резолвится
  финально (если open — по последнему счёту), создаётся новая, чат:
  «⚔ ВОЙНА: нас вызвала <имя>. Оборона Бункера — дважды за неделю!» +
  звук `guild_war` (звать из UI при открытии гильдии, не из статики).
- `report_war_score(waves)`: attempts+1, my_score = max(old, waves);
  enemy_score = симуляция; если attempts >= WAR_ATTEMPTS → state
  resolved по счёту (won/lost), выплаты, чат-итог. Звук `guild_war`
  на итоговом баннере.
- `zone_controller/game_manager`: оборонный забег с
  `params["war_defense"] = true` → в `_collect_run_result`/
  `process_run_result` при флаге — `GuildSys.report_war_score(waves)`
  (вместо/вместе с арена-учётом: флаг war не двигает сезон СП — это
  разные лиги; ручка).

## 3. UI (гильд-оверлей)

- Шапка гильдии: при open-войне — флаг «⚔ vs <имя> · счёт {м}-{э}»
  (золотой при my>enemy, серый иначе); после победы — «⚔ ПОБЕДА» до Пн.
- Вкладка войны (или блок в Обзоре): карточка соперника (имя, сила,
  их счёт), мои попытки (осталось), кнопка «В БОЙ» → старт обороны с
  флагом (переиспользует выбор отряда арены: если отряд пуст — подсказка).
- Итог войны: поп-плашка при входе в гильдию («⚔ ПОБЕДА 41–34: +120
  жетонов в казну»), звук.

## 4. Симуляция соперника (честность офлайна)

- `power` фиксирован на неделю (seed недели) — игрок видит противника
  равного и планирует прокачку отряда.
- `enemy_score` при первой попытке = `power × 0.55`; при второй —
  `max(первый, my_score × WAR_ENEMY_FIGHT + power × 0.10)` — соперник
  всегда чуть позади твоей лучшей попытки (90–100%): выигрываешь
  благодаря второй попытке — драма «доиграл-дотянул». Ручка: WAR_ENEMY_FIGHT
  0.92 → 1.02 для хардкора.
- Никогда не обнуляет счёт игрока (лучшее остаётся).

## 5. Чек-лист приёмки

1. Новая неделя: чат «⚔ ВОЙНА vs …», баннер в шапке, звук при открытии
   гильдии.
2. Оборонный забег с флагом: итог пишет счёт, соперник «отвечает»;
   две попытки — резолюция: победа → жетоны в казну + флаг до Пн.
3. Проигрыш недели: утешение, глум-строка в чате.
4. Сезонный счёт СП арены не задет; гильд-босс работает параллельно.
5. Старые сейвы: war отсутствует → создаётся на следующей неделе.
6. Дневник: все события войны в chat-логе (Этап 3 заменит симулятор
   сервером, API тот же).
