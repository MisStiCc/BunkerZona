# Война гильдий (офлайн) — как встраивать

**Что это:** недельный пвп-ритуал без сервера: в начале недели гильдия
объявляет войну боту-соседу; бой — оборона Бункера своим оборонным
отрядом арены (существующий режим), счёт = пережитые волны у обеих сторон
(соперник симулируется его «силой»); победа — жетоны в казну и флаг войны
в шапке гильдии до следующей недели. Звук `guild_war.ogg` наконец звучит.

**Зачем:** гильдия (D21) без войны — казна без стока, чат без драмы; война
даёт недельную гонку и смысл качать оборонный отряд.

**Как встраивать (кратко):**
1. `core/guild_sys.gd`: war-подсловарь в `guild_state` + `ensure_week`
   объявляет войну (детерминировано seed'ом недели), `resolve_war()`
   после оборонного забега.
2. `game_manager`/zone_controller: флаг `war_defense` в run_params
   оборонного забега → по итогам `GuildSys.report_war_score(waves)`.
3. UI: баннер войны в шапке гильдии (соперник/счёт/кнопка «В БОЙ»),
   итоговая плашка; звук `guild_war` на объявлении и на итогах.

**Трогает:** core/guild_sys.gd, data/guild_data.gd (константы), lab
гильд-оверлей (баннер), zone_controller/game_manager (проброс score).
НЕ трогает: гильд-босса, экономику жетонов рейда, баланс обороны арены.
