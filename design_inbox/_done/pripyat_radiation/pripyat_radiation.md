# Радиация Припяти — цена близости к Саркофагу

Статус: спека под встраивание. Опора: `terrain/pripyat_map_3d.gd`
(`MONOLITH_ROUTE`, `monolith_position_for_level`), `zones/zone_controller.gd`
(энергия/аномалии/итоги), `managers/resource_manager.gd` (реген),
`components/health_component.gd` (`take_damage`), `zones/monolith/monolith.gd`
(свет). Все числа — «ручки» в блоке констант §7 (новый `data/radiation_data.gd`).

---

## 1. Суть и принципы

На Припяти Монолит перемещается к Саркофагу по ярусам (точка — от уровня
кампании / этажа башни: `tier = (level−1)/10 + 1`). Чем ближе ярус к
Саркофагу — тем выше радиационный фон. Фон — не декорация, а **двусторонняя
экономика**:

- **Зона платит**: реген энергии падает, аномалии дорожают.
- **Сталкеры платят**: пассивный дрейф HP у всех живых; мастера в экзоскелетах
  почти иммунны — поздние ярусы («22/58/20» к Сердцу Зоны) получают нарратив
  «до Саркофага доходят только мастера».
- **Премия**: награда за забег растёт с фоном — риск оплачивается.

Принципы:

- **Только Припять.** Процедурная Зона — фона нет, HUD-индикатор не показывается.
- **Выживание не задето:** Монолит выживания на Припяти стоит на ярусе 1
  (`zone_controller.gd:348` — точка старта маршрута, центр города) — всегда
  чистая зона. Это осознанно: выживание уже эскалирует волнами.
- **Зона — по расстоянию, не по номеру яруса.** Границы зон считаются от
  фактического расстояния «позиция Монолита → точка Саркофага». Маршрут в
  STATUS помечен как приблизительный — если точки уточнят, зоны переедут
  сами, без правки баланса.
- **Один источник правды по эффектам:** `data/radiation_data.gd`, все
  множители читаются из него (правило «баланс в data/»).

## 2. Границы зон (по расстоянию до Саркофага)

Точка Саркофага = `monolith_position_for_level(100)` (последняя точка
`MONOLITH_ROUTE`, [51.3890, 30.0996]). Расстояния по текущим координатам
маршрута (пересчёт: 1° lat ≈ 111.3 км, 1° lon на 51.4° ≈ 69.5 км):

| Зона | id | Дистанция, м | Ярусы сейчас | Фон, мкЗв/ч (для HUD) |
|---|---|---|---|---|
| Чистая зона | `clean` | > 2600 | 1–4 (центр 3512, стадион 3171, автостанция 3567, парк 3465) | 40 |
| Слабый фон | `low` | 1500–2600 | 5–7 (выезд 2606, промзона 1925, Янов 2019) | 300 |
| Сильный фон | `high` | 400–1500 | 8 (подъезд ЧАЭС 952) | 1200 |
| Смертельный фон | `lethal` | < 400 | 9–10 (машзал 184, Саркофаг 0) | 7500 |

В терминах кампании/башни (по текущему маршруту): главы/этажи 1–40 — чистая,
41–70 — слабый фон, 71–80 — сильный, 81–100 — смертельный. Ярус 3
(автостанция) чуть дальше яруса 2 (стадиона) — маршрут змейкой, зона всё
равно одна и та же по полосе; полосы подобраны так, чтобы текущий маршрут
не «мигал» зонами внутри яруса.

Границы — ручки `ZONE_BANDS` (§7): уточнение точек маршрута или желание
сдвинуть премии меняет только таблицу.

## 3. Эффекты фона

| Параметр | `clean` | `low` | `high` | `lethal` |
|---|---:|---:|---:|---:|
| Реген энергии | ×1.0 | ×0.9 | ×0.8 | ×0.65 |
| Стоимость аномалий | ×1.0 | ×1.10 | ×1.25 | ×1.40 |
| Дрейф HP новичка/ветерана | 0 | −0.3/с | −0.8/с | −1.5/с |
| Дрейф HP мастера (экзоскелет) | 0 | −0.1/с | −0.3/с | −0.5/с |
| Премия к награде забега | ×1.0 | ×1.10 | ×1.25 | ×1.50 |
| Постэффект «мрачность» | ×1.0 | ×1.05 | ×1.1 | ×1.2 |
| Цвет света Монолита | белый | тускло-зелёный | зелёный | ярко-зелёный |

Кого не трогаем: **мутантов** (дети Зоны, иммунитет), **артефакты-приманки**
(сами фонят, им не привыкать), **выброс** (правила не меняются, 1000 энергии
и сброс биомассы до 30% как раньше).

Балансовая логика связки (почему именно так):

- **Реген ×0.65 + аномалии ×1.4** в смертельной зоне — заметная боль:
  ставить аномалии «пачками» больше не выходит, каждая позиция должна
  работать. Проверка чувств: жарка 50 → 70 энергии, воронка 150 → 210;
  реген 1/с (базовый) → 0.65/с. Полный щит из 6 воронок вокруг Монолита
  дорожает с 900 до 1260 энергии — дольше копится почти на весь выброс.
- **Дрейф HP** — встроенная помощь: новичок (80 HP) в смертельной зоне тает
  за ~53 с, ветеран (150) за ~100 с, мастер (250 при −0.5/с) — за 500 с.
  Волна поздней кампании идёт 1.5–2.5 мин — толпа новичков редеет сама,
  мастера почти не замечают. Это ровно компенсирует подорожание обороны.
- **Премия ×1.5** в смертельной зоне применяется к награде забега целиком
  (боевой доход + бонус уровня; реплей с его ×0.3 умножается поверх —
  фармить красную зону реплеем выгодно, но она и сложнейшая в игре).
  Перебор по инфляции — ручка `REWARD_MULT` или флаг «умножать только
  бонус уровня» (§7).

## 4. Правила применения

1. **Определение зоны** — один раз на старте забега (`_setup` ветка Припяти,
   сразу после `mono.global_position = pm.monolith_position_for_level(...)`):
   `zone = RadiationData.get_zone_by_distance(mono.global_position.
   distance_to(pm.monolith_position_for_level(100)))`. Результат хранится
   в ZoneController (`var radiation_zone: String`).
2. **Реген**: умножить `resource_manager.energy_regen_rate` на множитель
   зоны, **базовое значение сохранить** до применения (переменная
   `_base_energy_regen`) — откат не нужен (зона живёт весь забег), но
   база не должна потеряться при повторном применении.
3. **Цены аномалий**: в `zone_controller.create_anomaly` умножить `cost`
   на множитель зоны ПЕРЕД `spend_energy(cost)` — одно место, HUD-баланс
   энергии виден сразу. Возврат при удалении аномалии (если есть) —
   умножать на тот же множитель, чтобы не появился фарм «поставил-снёс».
4. **Дрейф HP**: таймер `RAD_TICK_INTERVAL` 1.0 с в ZoneController; для
   каждого живого сталкера (`spawn_manager.active_stalkers`) —
   `health.take_damage(rate * (мастер? MASTER_FACTOR : 1.0), null)`.
   Источник `null` — чтобы FSM/память не искали «виновника» и не ломили
   в сторону аномалии. Тик идёт и в передышке (сталкеров почти нет —
   дешёво), и во время выброса (выброс всё равно убивает всех).
5. **Премия**: в `_collect_run_result` — `reward *= RadiationData.
   REWARD_MULT[zone]` (после всех существующих надбавок). Башня получает
   её автоматически: `tower_data.get_floor_rewards` вызывается в
   `_apply_tower_result` от этажа — проще всего домножить там `biomass`
   тем же множителем (этажи 81–100 = смертельная зона, если карта Припять).
   Мод проверки: `run_params.get("map") == "pripyat"` — на процедурной
   карте премии нет нигде.
6. **Постэффект**: множитель зоны поверх текущего (Припять уже ×1.25);
   суммарный кап 1.6 (согласовано со спекой survival_lategame — «ночь»
   и фон делят один кап).

## 5. Подача игроку (HUD и не только)

- **Индикатор** — слева от полосы энергии в HUD (рядом `EnergyValue`):
  «☢ 40 мкЗв/ч» цветом зоны (зелёный/жёлтый/оранжевый/красный +
  «ЧИСТАЯ/СЛАБЫЙ/СИЛЬНЫЙ/СМЕРТЕЛЬНЫЙ» в тултипе). На процедурной карте
  индикатор скрыт.
- **Плашка на старте забега** (Припять, зона ≠ clean): `show_event_note`
  с полным раскладом, честно и сразу:
  «☢ СИЛЬНЫЙ ФОН (1200 мкЗв/ч): реген ×0.8 · аномалии +25% · сталкеры
  тают · награда ×1.25». Игрок знает правила ДО первого клика.
- **Монолит**: `point_light.color` уползает в зелёный по зоне (у Монолита
  есть пульсация света — цвет ложится на неё бесплатно), `Label3D`
  («Монолит, уровень N») получает строку «☢ 1200 мкЗв/ч».
- **Лаборатория**: в тултипе уровня/этажа на Припяти — бейдж зоны
  («☢ слабый фон · награда ×1.1») — решение «куда идти» принимается
  до забега (инфострока селектора уже показывает главу — добавить бейдж
  рядом).
- Числа в мкЗв/ч — только косметика HUD (константа на зону), механика
  работает от множителей.

## 6. Согласование с существующими системами

| Система | Взаимодействие |
|---|---|
| Кампания (главы 5–10) | основной потребитель: статы врагов там уже ×1.24–1.62, фон добавляет характер, а не тупую сложность |
| Башня (этажи 41+) | те же зоны по ярусам; на звёзды не влияет (`rich`/`hunter` считаются от боевой статистики, не от награды) |
| Выживание | Монолит на ярусе 1 → всегда clean; никаких пересечений с фазой легенды |
| survival_lategame (модификатор «ночь») | общий кап постэффекта 1.6; «ночь» ×1.4 на красной зоне Припяти → 1.25×1.4=1.75 → капится в 1.6 |
| survival_lategame (ЭМ-туман) | перемножаются: реген ×0.5(туман)×0.65(фон) — осознанно больно; если перебор — ручка `MAX_TOTAL_REGEN_MULT` 0.35 (§7) |
| Лаборатория (прокачка регена) | множитель фона применяется ПОВЕРХ прокачки (умножение, не перезапись) — апгрейды не обесцениваются |
| Выброс | без изменений; в красной зоне выброс по-прежнему главный инструмент (энергия копится медленнее — планомерней) |
| Сейвы | ничего нового: зона вычисляется на лету от позиции Монолита |

## 7. Константы — `data/radiation_data.gd` (готовый блок)

```gdscript
# data/radiation_data.gd
extends RefCounted
class_name RadiationData

## Радиационный фон Припяти: зоны по расстоянию Монолит -> Саркофаг.
## Действует ТОЛЬКО на карте Припяти (выживание - ярус 1 - всегда clean).
## Все множители - поверх существующих систем (умножение, не замена).

# Границы зон по дистанции до точки Саркофага, м. Подобраны под текущий
# MONOLITH_ROUTE (ярусы 1-4 дальше 2600 м; 5-7 - 1500-2600; 8 - 952;
# 9-10 - ближе 400). Уточнение маршрута точками карты зоны не ломает.
const ZONE_BANDS := [
	{"id": "lethal", "max_dist": 400.0,  "bg": 7500.0, "title_ru": "СМЕРТЕЛЬНЫЙ ФОН", "title_en": "LETHAL BACKGROUND"},
	{"id": "high",   "max_dist": 1500.0, "bg": 1200.0, "title_ru": "СИЛЬНЫЙ ФОН",     "title_en": "HIGH BACKGROUND"},
	{"id": "low",    "max_dist": 2600.0, "bg": 300.0,  "title_ru": "СЛАБЫЙ ФОН",      "title_en": "LOW BACKGROUND"},
	{"id": "clean",  "max_dist": 1.0e9,  "bg": 40.0,   "title_ru": "ЧИСТАЯ ЗОНА",     "title_en": "CLEAN ZONE"},
]

# Эффекты по id зоны. bg - число для HUD (мкЗв/ч), механика - на множителях.
const ZONE_EFFECTS := {
	"clean":  {"regen_mult": 1.0,  "anomaly_cost_mult": 1.0,  "drain_hp": 0.0,
		"drain_hp_master": 0.0,  "reward_mult": 1.0,  "postfx_mult": 1.0},
	"low":    {"regen_mult": 0.9,  "anomaly_cost_mult": 1.10, "drain_hp": 0.3,
		"drain_hp_master": 0.1,  "reward_mult": 1.10, "postfx_mult": 1.05},
	"high":   {"regen_mult": 0.8,  "anomaly_cost_mult": 1.25, "drain_hp": 0.8,
		"drain_hp_master": 0.3,  "reward_mult": 1.25, "postfx_mult": 1.10},
	"lethal": {"regen_mult": 0.65, "anomaly_cost_mult": 1.40, "drain_hp": 1.5,
		"drain_hp_master": 0.5,  "reward_mult": 1.50, "postfx_mult": 1.20},
}

# Тик дрейфа HP сталкеров
const RAD_TICK_INTERVAL: float = 1.0   # раз в секунду; крупнее - рывками, мельче - даром процессор
# Пол общий для всех тиков (сталкер не умирает от фона быстрее, чем за N сек):
const RAD_EXECUTION_FLOOR: float = 0.0 # 0 = фон добивает; 5.0 = фон оставляет 5 HP (мягкий вариант)

# Капы согласования с другими системами
const POSTFX_TOTAL_CAP: float = 1.6        # общий кап «мрачности» (ночь + фон + карта)
const MAX_TOTAL_REGEN_MULT: float = 0.35   # реген: туман x фон не глубже этого (0.5x0.65=0.325 - впритык, ок)

# Ручки перебора:
# - поздняя кампания стала невыносимой -> drain_hp -30% и anomaly_cost_mult -0.05 во всех зонах
# - инфляция наград -> reward_mult в high/lethal: 1.25/1.5 -> 1.15/1.3
#   (или флаг BONUS_ONLY: премия только к бонусу уровня, не к боевому доходу)
# - наоборот, фону не хватает веса -> lethal: regen 0.6, cost 1.5, drain 2.0

## Зона по расстоянию до Саркофага (метры)
static func get_zone_by_distance(dist: float) -> String:
	for band in ZONE_BANDS:
		if dist <= float(band["max_dist"]):
			return band["id"]
	return "clean"


## Эффекты зоны (словарь из ZONE_EFFECTS; clean - если id неизвестен)
static func get_effects(zone_id: String) -> Dictionary:
	return ZONE_EFFECTS.get(zone_id, ZONE_EFFECTS["clean"])


## Данные зоны для HUD (фон мкЗв/ч + название), по id
static func get_zone_info(zone_id: String) -> Dictionary:
	for band in ZONE_BANDS:
		if band["id"] == zone_id:
			return band
	return ZONE_BANDS[ZONE_BANDS.size() - 1]


## Зона по уровню кампании/этажу башни без карты (fallback, если позиция
## ещё не известна): ярус = (level-1)/10 + 1, ярусы 1-4 clean, 5-7 low,
## 8 high, 9-10 lethal. Дублирует полосы - второстепенный путь.
static func get_zone_for_level(level: int) -> String:
	var tier: int = clampi((level - 1) / 10 + 1, 1, 10)
	if tier <= 4:
		return "clean"
	if tier <= 7:
		return "low"
	if tier == 8:
		return "high"
	return "lethal"
```

## 9. Риски и краевые случаи

- **Порядок применения регена:** базу `energy_regen_rate` сохранить до
  умножения; применение ровно один раз за забег (защита от повторного
  `_setup`) — иначе множитель перемножится сам на себя.
- **Возврат цены при удалении аномалии** (если механика возврата есть) —
  умножать на тот же множитель; иначе появится бесплатный цикл
  «поставил/снёс». Проверить при встраивании, есть ли возврат вообще
  (в `anomaly_manager` возврата не найдено — если его нет, пункт снят).
- **Тик по мёртвым/улетевшим:** брать сталкеров только из
  `spawn_manager.active_stalkers`, чужие узлы не трогать; `take_damage`
  сам разрулит смерть (`died` сигнал уже связан с наградой за убийство —
  смерть от фона НЕ должна платить биомассу за килл; источник `null`
  помечаем и в `on_stalker_died` не начисляем добычу — ручка
  `RAD_KILL_REWARD: false`).
- **Караван-боссы (каждый 10-й уровень кампании)** — тоже в зоне фона:
  караван на 90-м уровне тает сам? Да — он из тех же сталкеров, это
  честно работает на «до Саркофага доходит только мастеровый караван».
  Если босс-уровни станут слишком лёгкими — ручка: `drain_hp` не действует
  на флаг `is_boss` (столбец добавить в ZONE_EFFECTS не нужно, ветка в тике).
- **Производительность:** тик 1 с по ≤30 сталкерам — копейки; постэффект
  и свет — уже существующие узлы.
- **Выживание+Припять:** Монолит на ярусе 1 → clean, индикатор показывает
  «ЧИСТАЯ ЗОНА» (не прятать — фон объясняет, почему эффектов нет).

## 10. Чек-лист приёмки

1. Кампания на Припяти, уровень 1–40: индикатор «☢ 40 мкЗв/ч», эффекта нет.
2. Уровень 41 (ярус 5): плашка «СЛАБЫЙ ФОН», реген ×0.9 (замер по таймеру),
   жарка стоит 55 энергии, новички начали подтаивать, награда ×1.1 в итогах.
3. Уровень 81 и 100 (ярусы 9–10): «СМЕРТЕЛЬНЫЙ ФОН», воронка 210 энергии,
