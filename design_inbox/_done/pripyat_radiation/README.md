# Радиация Припяти — как встраивать

**Что это:** механика «радиационного фона» на карте Припяти: чем ближе ярус
Монолита к Саркофагу, тем выше фон. 4 зоны по расстоянию до точки Саркофага
(координаты — последняя точка `MONOLITH_ROUTE`): чистая / слабый / сильный /
смертельный фон. Фон бьёт **по всем**: Зоне — реген энергии ×0.9…×0.65 и
дороже аномалии (+10…+40%), сталкерам — пассивный дрейф HP (мастера почти
иммунны: «до Саркофага доходят только мастера»), и это окупается премией к
награде ×1.1…×1.5.

**Зачем:** главы 5+ кампании на Припяти сейчас отличаются от процедурной
Зоны только декорациями. Фон — цена и премиия близости к Саркофагу: поздняя
кампания получает свой характер, решение «идти выше по ярусам» — вес.

**Как встраивать (кратко):**
1. Новый `data/radiation_data.gd` (константы + `get_zone_by_distance()` /
   `get_zone_for_level()` — блок в спеке готов). Зона считается по
   расстоянию позиция Монолита → `monolith_position_for_level(100)`.
2. `zones/zone_controller.gd`: на старте забега на Припяти определить зону,
   применить множители: `resource_manager.energy_regen_rate` (сохранив
   базу), стоимость в `create_anomaly` (умножить перед `spend_energy`),
   тик 1 с — `health_component.take_damage(rate)` всем живым сталкерам
   (мастерам ×MASTER_FACTOR, мутанты иммунны), премию — в
   `_collect_run_result` (reward × множитель зоны).
3. HUD: индикатор «☢ N мкЗв/ч» у полосы энергии (цвет зоны) + плашка
   `show_event_note` на старте забега со всеми эффектами зоны.
4. Диегетика: цвет `point_light` Монолита уходит в зелёный, постэффект
   темнее (в красной зоне ×1.2, кап 1.6 — согласовано с survival_lategame).

**Трогает:** `data/` (новый файл), `zones/zone_controller.gd`,
`ui/hud/hud.gd`, точечно `zones/monolith/monolith.gd` (цвет света), тултип
уровня в лаборатории. Процедурная Зона и выживание (Монолит на ярусе 1) —
фона нет, ничего не меняется.
