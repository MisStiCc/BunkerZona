# Календарь ОХОТЫ и портреты боссов — как встраивать

**Что это:** недельный календарь ОХОТЫ (кнопка рядом с «ОХОТА» в
лаборатории): 6 боссов по дням с портретами, статами, скиллами и наградой;
сегодняшний день подсвечен. Те же портреты — в Гильд-босс табе и на
баннере старта охоты. Данные уже есть: `BossHuntData.BOSSES` +
`get_today_bosses()`; портреты придут из задачи 36 (слоты заложить).

**Зачем:** ОХОТА — ежедневный ритуал (D19), но игрок видит только
сегодняшнего босса: нет планирования «завтра Хромец — к утру коплю
быстрых». Календарь = предвкушение + возвраты.

**Как встраивать (кратко):**
1. Новый `ui/lab/hunt_calendar.gd` (оверлей кодом, слой 9, стиль codex):
   7 строк-дней (Пн–Вс) × боссы дня; сегодняшний день — рамка зелёная
   «СЕГОДНЯ»; портрет 96×96 `ui/cards/bosses/<id>.png` (нет файла —
   силуэт-заглушка с буквой, как карты гачи).
2. Кнопка «КАЛЕНДАРЬ» рядом с кнопкой ОХОТА (lab_controller); в Гильд-босс
   табе и баннере охоты — портрет текущего босса (`_boss_portrait(id)`).
3. Локали `huntcal.*` (блок готов).

**Трогает:** новый ui-файл, lab_controller (кнопка + 2 портрета),
BossHuntData (+описания скиллов словами), Loc. НЕ трогает: логику ОХОТЫ,
гильдию, баланс.
