# Календарь ОХОТЫ и портреты боссов (D22)

Опора: `data/boss_hunt_data.gd` (`BOSSES`: name_ru/name_en, hp_x, speed,
sparks, model, skills[{id, cd, dmg, r}]; `WEEK_SCHEDULE` чёт/нечёт;
`get_today_bosses(date)`), `ui/lab/lab_controller.gd` (кнопки нижнего ряда,
баннер «Сегодня в Зоне: {n}» — ключ hunt.today), гильд-оверлей (босс-таб),
`ui/cards/` (паттерн карт), SwipeHelper, `BunkerUI`.

## 1. Экран календаря (`ui/lab/hunt_calendar.gd`)

```
┌─ ОХОТА НЕДЕЛИ ──────────────────────── [x] ─┐
│ ПОНЕДЕЛЬНИК ────────────────────────────    │
│ [портрет] КОСТОЛОМ      HP ×40 · медленный  │
│           ⚒ Землетряс · Искры 3   [СЕГОДНЯ] │
│ [портрет] СТОЛП ГРОЗЫ   HP ×28 · стоит      │
│           ⚡ Разряд · Щит · Искры 4          │
│ ВТОРНИК ────────────────────────────────    │
│ ... (6 строк-дней, Вс — шесть боссов)       │
│                    [ В ОХОТУ ]               │
└─────────────────────────────────────────────┘
```
- Панель по центру (ширина clamp 380–560), строки дней в
  ScrollContainer (SwipeHelper.attach, как в кодексе).
- СТРОКА ДНЯ: заголовок дня (моно, TEXT_DIM) → карточки боссов дня:
  портрет 96×96 + имя (Russo One, цвет по боссу) + строка статов
  «HP ×40 · скорость 1.1 · Искры 3» + скиллы словами (§3).
- **Сегодня**: рамка GREEN 3px + плашка «СЕГОДНЯ» (GREEN); прошедшие дни
  недели затемнены ×0.55; будущие — обычные. Чёт/нечёт даты берём из
  `Time.get_date_dict_from_system()` → `get_today_bosses` и для всех 7
  дней (симуляция даты ±N дней от сегодня).
- Кнопка «В ОХОТУ» внизу — закрывает календарь и жмёт существующий
  обработчик старта ОХОТЫ (только если сегодняшние боссы есть).
- Портрет: `ui/cards/bosses/<id>.png` при наличии (задача 36); нет файла
  → Panel-заглушка с первой буквой имени (паттерн карточек гачи).

## 2. Портреты в трёх местах

| Место | Что | Точка |
|---|---|---|
| Баннер старта охоты | портрет босса 128×128 слева от «Сегодня в Зоне: …» | lab_controller, где show_event_note с hunt.today |
| Гильд-босс таб | портрет гибрида (базовый босс недели) 96×96 | guild overlay, босс-вкладка |
| Календарь | 96×96 у каждой строки | этот экран |

Хелпер `hunt_calendar.portrait(id, size) -> Control` — один на все места.

## 3. Скиллы словами (BossHuntData + Loc)

Каждому skill.id — короткое слово (не механика!): quake «толчок по
площади», blink «мигает от толпы», dot_zone «облако-истощение», summon
«зовёт мелочь», stun_nearest «оглушает ближайшего», vampiric «лечится
вашей болью», dash «бросок», shield «щит от дальнего», backstab «удар в
спину», hop_regen «отскок с лечением», mark «метит цель». Блок Loc
`huntcal.skill_<id>` (ru/en), рендер: иконка-глиф (emoji) + слово.

## 5. Точки встраивания

| Файл | Правка |
|---|---|
| `ui/lab/hunt_calendar.gd` | новый: `class_name HuntCalendar`, `open()/close()`, рендер §1, хелпер `portrait(id, size)` |
| `ui/lab/lab_controller.gd` | кнопка «КАЛЕНДАРЬ» рядом с кнопкой ОХОТА (нижний ряд); портрет в баннере hunt.today; кнопка «В ОХОТУ» → существующий `_on_hunt_pressed` |
| гильд-оверлей | портрет базового босса недели в босс-табе |
| `data/boss_hunt_data.gd` | +`get_week_days(date) -> Array` (7 дней: weekday → боссы; чёт/нечёт по дате дня) |
| `core/localization.gd` | блок §4 |

## 6. Ручки перебора

«Календарь слишком высок» → строка дня компактнее (портрет 72), scroll;
«путаются дни» → подсветить завтрашний день жёлтой рамкой «ЗАВТРА»;
«портретов нет и не нужны» → заглушки-буквы остаются навсегда, слоты
не блокируют.

## 7. Чек-лист приёмки

1. Кнопка «КАЛЕНДАРЬ» открывает неделю; сегодняшний день зелёный с
   плашкой, остальные по расписанию чёт/нечёт.
2. Портреты: при файлах задачи 36 — арт; без — буквы; всё читаемо.
3. «В ОХОТУ» стартует сегодняшнюю охоту (существующий поток).
4. Баннер охоты и гильд-босс таб показывают портрет.
5. ru/en полные; свайп скролла на мобиле; ESC/[x] закрывают.
