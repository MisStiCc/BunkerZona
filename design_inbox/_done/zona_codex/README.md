# Кодекс Зоны — как встраивать

**Что это:** экран-справка «КОДЕКС ЗОНЫ» — 5 статичных страниц (Ресурсы ·
Аномалии и артефакты · Мутанты и звёзды · Выброс и радиация · Режимы и
сезон) в оверлее лаборатории, в стиле уже существующих панелей. Кнопки
входа: в лаборатории (рядом с настройками) и «?» в главном меню.

**Зачем:** игра не объясняет своих правил — энергия/биомасса, «аномалия
ставится перед камерой», выброс за 1000, зоны радиации Припяти, циклы NG+.
Старая спека интерактивного туториала закрыта как избыточная; Кодекс
закрывает ту же потребность в ~200 строк кода без вмешательства в геймплей.

**Как встраивать (кратко):**
1. Новый `ui/lab/codex_overlay.gd` (CanvasLayer слой 9, оверлей кодом по
   образцу gallery/detail: shade + panel + табы страниц + текст).
2. Тексты — ключи `codex.*` в Loc (блок готов в спеке); иконки —
   `ui/cards/` + `assets/ui/lab/station_*.png`.
3. Кнопки входа: лаборатория (кнопка «КОДЕКС» в нижний ряд), меню
   (маленькая «?» возле штампа версии).
4. Данные страниц — статический контент в самом оверлее (не data-файл:
   это текст, не баланс).

**Трогает:** новый ui-файл, lab_controller (кнопка), main_menu (кнопка ?),
Loc. НЕ трогает: геймплей, сейвы, баланс, HUD боя.
