# Кодекс Зоны (D15)

Статус: спека под встраивание. Опора: `ui/lab/lab_controller.gd`
(образцы оверлеев: gallery_panel, detail_panel; нижний ряд кнопок
`VBox/BottomButtons`), `ui/main_menu/main_menu.gd` (штамп версии, кнопки),
`BunkerUI` (стили кнопок/панелей, шрифты), `Loc` (ключи, формат
`{плейсхолдеры}`), иконки `ui/cards/` и `assets/ui/lab/station_*.png`.

## 1. Структура экрана

```
┌─ КОДЕКС ЗОНЫ ─────────────────────────── [x] ─┐
│ [РЕСУРСЫ][АНОМАЛИИ][МУТАНТЫ][ВЫБРОС][РЕЖИМЫ]  │  ← табы-кнопки
│                                                │
│  (текст страницы: заголовки-абзацы, 9–13 px,   │
│   иконки 48 px в строках-примерах)             │
│                                                │
│                [ НАЗАД ]                        │
└─────────────────────────────────────────────────┘
```
Оверлей поверх лаборатории: shade 0.6 + панель 640×520 по центру
(якоря 0.5), `mouse_filter = STOP`. Таб — toggle-кнопки в ButtonGroup
(как фильтры галереи). Страница = VBox в ScrollContainer (текст может
не влезать на мобиле). Скип: [x], НАЗАД, клик по shade, ESC.

## 2. Содержание страниц (тезисы — развернуть в Loc-блоке §4)

1. **РЕСУРСЫ** — энергия (ставит аномалии, копится сама, 1000 = ВЫБРОС),
   биомасса (спавнит мутантов, сдаётся в лабораторию), крутки
   (мутанты/артефакты — гача), СП (сезон: базар, обменник, трек наград).
2. **АНОМАЛИИ И АРТЕФАКТЫ** — аномалия ставится в точку перед камерой
   (тап-постановка на телефоне: кисть → тап → призрак → ✓); каждая
   аномалия открывается своим артефактом (галерея покажет замок и чем
   открывается); убитый сталкер-носитель роняет артефакт — трофей в
   хранилище; сеты артефактов (2+ одного элемента) усиливают аномалию.
3. **МУТАНТЫ И ЗВЁЗДЫ** — мутант стоит биомассу и живёт до конца забега;
   ферма: дубли из гачи → копии; звезда = копии цели + 1 корм той же
   звёздности + простые (2/4/6/8); ★×N = множитель статов; утилизация
   копий → очки → 6 очков = крутка артефактов.
4. **ВЫБРОС И РАДИАЦИЯ** — ВЫБРОС за 1000 энергии выжигает всех сталкеров
   (главный инструмент), на выживании бывают бесплатные на 33/43/53-й
   волнах; на Припяти фон радиации растёт к Саркофагу (см. HUD «☢»):
   Зоне дороже аномалии и медленнее реген, сталкеры тают, но награда ×1.1–1.5.
5. **РЕЖИМЫ И СЕЗОН** — кампания: 100 колец, после — NG+ (циклы: враги
   и награды растут); башня: 100 этажей, звёзды 1–3, Прорывы ×5-е и
   Хранители ×10-е; выживание: 30+ волн = победа; сезон: трек 30 ступеней,
   закрытие = награда и цикл сундуков +25%; базар — всё за СП.

## 3. Точки встраивания

| Файл | Правка |
|---|---|
| `ui/lab/codex_overlay.gd` | новый: `class_name CodexOverlay`, `open()`, страницы списком пар [заголовок, абзац]; иконки-примеры по ключу (опционально: нет файла — без иконки) |
| `ui/lab/lab_controller.gd` | кнопка «КОДЕКС» в `VBox/BottomButtons` (рядом с ГАЛЕРЕЯ) → `CodexOverlay.new().open()`; стили BunkerUI |
| `ui/main_menu/main_menu.gd` | кнопка «?» 40×40 возле VersionStamp → тот же оверлей (можно без лабы — оверлей самодостаточен, add_child на корень меню) |
| `core/localization.gd` | ключи §4 |

Табы страниц и тексты — локализованы (ru/en). На узких экранах панель
60% ширины (clamp 340..640).

## 5. Ручки и перебор

- Панель: ширина `clampf(vp.x * 0.55, 340, 640)`, высота 0.7·vp — на
  телефоне текст мельчает → шрифт абзацев 12→13 и панель во всю ширину.
- «Слишком длинно читают» → сократить абзацы §2 до одной строки (блоки
  Loc правятся без кода).
- Иконки-примеры (опция): строка «⚡ Энергия» с TextureRect 48px слева;
  нет файла — строка без иконки. Не блокер первой версии — можно вообще
  без иконок, только текст.

## 6. Чек-лист приёмки

1. Кнопки «КОДЕКС» (лаба) и «?» (меню) открывают оверлей; ESC/[x]/фон
   закрывают; в меню работает без лаборатории.
2. 5 вкладок переключаются, тексты ru/en полные (ни одного сырого ключа).
3. Скролл длинных страниц работает (свайп на мобиле — SwipeHelper.attach,
   как в галерее).
4. Геймплей, сейвы, баланс не задеты; оверлей поверх всех панелей лабы.
