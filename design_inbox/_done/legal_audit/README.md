# Юридический аудит — как встраивать

**Что это:** полный аудит правовых рисков (товарные знаки, авторские права,
лицензии ассетов) на дату 27.10.2026. Цель — «можно в релиз завтра». Всё,
что исправлялось кодом/доками, исправлено; остаточные пункты — решения
владельца вне репозитория, чек-лист §4.

**Как встраивать:** правки уже применены (см. §3). Основному агенту —
ничего; владельцу — выполнить чек-лист §4 при публикации.

**Трогает:** export_presets.cfg, core/localization.gd, ui/main_menu/
main_menu.gd, README.md, fonts/ (OFL-тексты + CREDITS), git-индекс
(keystore). НЕ трогает: игровой код, ассеты.
