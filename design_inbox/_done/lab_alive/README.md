# «ЗОНА ЖИВЁТ» — idle-жизнь лаборатории — как встраивать

**Что это:** косметический слой жизни лаборатории между забегами: тень
сталкера на карте пути, мигание ламп при выбросе «в мире», звуки бункера
по циклу дня (гул вентиляции, далёкий гром, скрип), дыхание фонового
арта. 0 влияния на механику. Цель — экран, который хочется разглядывать.

**Как встраивать (кратко):**
1. Новый `ui/lab/lab_alive.gd` (Node, слой под контентом): таймер-цикл
   ambient-событий (30–90 с случайно), каждое — звук из существующего
   пака + лёгкий визуал.
2. Источники: звуки wind_open/geiger/thunder_far (assets/audio/sfx),
   джорни-арт, погодные флаги дня.
3. Мобилка: только звуки, без миганий (battery).

**Трогает:** новый ui-файл + lab_controller (спавн). НЕ трогает: механику,
HUD боя, баланс.
