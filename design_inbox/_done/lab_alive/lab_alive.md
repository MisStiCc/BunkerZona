# «ЗОНА ЖИВЁТ» — idle-жизнь лаборатории (D29)

Опора: звуки `assets/audio/sfx/` (wind_open_01, geiger_loop, thunder_far_01,
night_insects_01, rain_medium_01 — эмбиент-лупы уже есть и играются),
`ui/lab/journey_map.gd` (топо-карта), день/ночь (`DayNightData`),
`atmosphere/postfx_layer.gd` (мигание уже настраивается), `BunkerUI`
(стиль), джорни-арт пака.

## 1. Витринки (события фона)

| Событие | Период | Что происходит | Ассет |
|---|---|---|---|
| Тень на карте пути | 40–90 с | силуэт сталкера пробегает по топо-карте между вехами (8 с) | sprite + journey_map |
| Дальний гром | 60–120 с | thunder_far_01 + вспышка ламп 0.2 с | звук уже есть |
| Гул вентиляции | луп | wind_open_01 уже играет — добавить редкий «скрип металла» (sound) | существующий пак |
| Дозиметр тикает | при карте пути у Саркофага (циклы 2+) | geiger_loop громче на 10 с | звук |
| Ночные насекомые | ночь (DayNight) | night_insects_01 вместо ветра | уже есть |
| Дыхание фона | луп | menu_background_2k/лаба — синус яркости ±3%, 20 с | код |
| Мутант пробегает | 50–100 с | силуэт вида из коллекции (иконка) слева направо по низу | ui/cards |

Все события — **декорация**: ноль влияния на энергию/биомассу/задачи.

## 2. Техчасть

```gdscript
# ui/lab/lab_alive.gd (Node)
## Таймер следующего события: 30–90 с (randf), очередь не копится.
## Событие = [звук, визуал?] по таблице; ночь/день переключают набор.
## Мобилка: is_touchscreen_available() → только звуки (без миганий).
const AMBIENT_PERIOD := [30.0, 90.0]
const SHADOW_RUN_LEN := 8.0
```

- Спавн из `lab_controller._ready` (Node под контентом, слой -1).
- Пул событий зависит от времени суток (день: тень/гул; ночь: насекомые/
  гром реже) и карты (Припять: геигер у Саркофага громче).
- Все текстуры — из встроенных паков (джорни-арт, иконки); ничего нового
  подготовщику не нужно.

## 3. Ручки

- «Достаёт» → AMBIENT_PERIOD 30-90 → 60-150; «хочется чаще» → 20-60.
- Мигание ламп: только в лабе, никогда в бою (HUD забега без событий).
- Батареи мобилки: звуки без визуала — уже по умолчанию.

## 4. Чек-лист приёмки

1. Лаба простаивает 5 минут — 3–6 фоновых событий, ни одного повтора
   подряд.
2. Ночь: насекомые вместо ветра; гром реже.
3. Бой: ни одного фонового события (слой живёт только в лабе).
4. Механика/задачи/валюты не задеты (дифф только новый файл + спавн).
5. Мобилка: без миганий, звуки тише на 20%.
