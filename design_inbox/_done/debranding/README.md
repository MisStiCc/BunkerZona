# Деговнизация — как встраивать

**Что это:** замена всех отображаемых имён, ассоциируемых с вселенной
S.T.A.L.K.E.R., на оригинальные (таблица 27 мутантов + глава «Тёмная
долина»), нейтральный дисклеймер, карта зачистки текстов. ПРЕДПОСЫЛКА
включения монетизации (Этап 0 спеки D16).

**Зачем:** платный продукт на узнаваемых именах чужой вселенной — прямой
претензионный риск (юраудит §5). Внутренние id (`snork_mutant` и т.п.) НЕ
меняются — игроку они не видны, сейвы и код целы; правится только слой
отображения.

**Как встраивать (кратко):**
1. Владелец утверждает 5 имён семей (§2, основная колонка или альтернативы).
2. Код-агент: правит `DISPLAY_NAMES`/`DISPLAY_NAMES_EN` (gacha_data/Loc),
   инлайн-строки (SHOP_MUTANTS/SEASON_SHOP/synergy/брифинги/сюжет), главу
   «Тёмная долина» (campaign+tower+ceremony), дисклеймер.
3. Проверка §6: grep-паттерны дают 0 вхождений в пользовательских текстах.

**Трогает:** gacha_data (имена/строки магазинов), Loc (mu.*, brf.*, story,
дисклеймер), synergy_data (описания), campaign_data/tower_data (глава),
story.gd. НЕ трогает: id, код-логику, модели, сейвы.
