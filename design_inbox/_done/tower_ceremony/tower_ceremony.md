# Церемония «Этаж пройден» — спецификация (Башня Монолита)

Статус: спека под встраивание. Ассеты — задания 4-5 из `COMMANDS.md`
(`inbox/mode_ui/`, `inbox/tower_transition/`), файлы по именам оттуда.
Все цифры — «ручки» в блоке констант §8 (предлагается `data/ceremony_data.gd`).

---

## 1. Суть и принципы

Один переиспользуемый оверлей **CeremonyOverlay** (`ui/hud/ceremony_overlay.gd`,
новый): CanvasLayer со слоем 10 (выше HUD и постэффекта-«мрачности», который
висит слоем 1 под HUD — см. FEATURES §2 «Атмосфера»). Строится кодом по образцу
`star_panel`/`tower_panel` (правило проекта: UI панелей — кодом, без .tscn).
Запускается из `finish_run` вместо фиксированной паузы, сам ждёт конца.

Принципы:

- **Всё в данных.** Тайминги/количества/звуки — константы `data/ceremony_data.gd`.
  Оверлей — только исполнитель последовательности шагов.
- **Фолбэк-безопасность** (как со звуками в `sound_manager.gd`): нет файла
  арта → текстовая/цветная заглушка с тем же таймингом; нет 3D-моделей →
  чисто 2D-переход (глиф + затемнение). Церемония не может «сломать» выход
  из забега.
- **Скип одним действием** — любой клик/тап/Enter/Space: гасим частицы,
  затемнение 0.3 с, выход в лабораторию. Повторные прохождения этажей —
  основной сценарий Башни, затянутая церемония убьёт режим.
- **Режимная машина.** Сейчас реализуем вариант `tower`; архитектура шагов
  (список этапов с таймингами) должна позволить потом посадить туда же
  кампанию (`banner_ring_captured`) и выживание (`banner_record`) — это
  отдельные задания, в этой спеке НЕ реализуются.

Код встраивания в `finish_run` (вместо строки 1001):

```gdscript
# Церемония башни вместо мёртвой паузы; остальные режимы - как раньше
if run_params.get("run_mode", "") == "tower":
	var ceremony := CeremonyOverlay.new()
	add_child(ceremony)
	await ceremony.play(result)
	ceremony.queue_free()
else:
	await get_tree().create_timer(3.0).timeout
get_tree().change_scene_to_file("res://scenes/lab/lab.tscn")
```

`ceremony.play(result)` внутри сама определяет вариант (победа/поражение,
тип этажа, звёзды) и возвращается по концу или скипу.

## 3. Базовая последовательность (обычный этаж, победа)

Хронометраж ниже — для 1 звезды; каждая дополнительная звезда сдвигает
последующие шаги на `STAR_POP_INTERVAL` (0.38 с), три звезды добавляют ещё
`CONFETTI_EXTRA_HOLD` (0.6 с). Абсолютные времена — константы §8.

| t, с | Шаг |
|---:|---|
| 0.00 | Затемнение сцены (ColorRect, альфа 0.55) за `FADE_IN_TIME` 0.35 с; HUD скрыт; музыка уходит в fade |
| 0.35 | Баннер «ЭТАЖ ПРОЙДЕН» (`banner_floor_cleared.png`) влетает сверху за 0.45 с, «слэм»: масштаб-панч 1.15→1.0 |
| 1.50 | Ряд из 3 слотов звёзд проявляется пустым (`star_empty.png`), 0.30 с |
| 1.80 | Поп-звезды по очереди: каждая выстреливает из слота (масштаб 0→1.2→1.0) за 0.28 с, интервал 0.38 с |
| 2.60 | Строка наград (биомасса/крутки) — приглушённая, под баннером |
| 3.30 | Переход: спавн лестницы у Монолита, кат-камера летит и поднимается; баннер меняется на «ЭТАЖ N: ПОДЪЁМ» (`banner_floor_up.png`) |
| 5.60 | Затемнение в чёрный за `FADE_OUT_TIME` 0.5 с |
| 6.10 | Титр на чёрном: «ЭТАЖ N+1» (или «ЯРУС: …» на переходе яруса), держится 0.9 с |
| 7.00 | Смена сцены на лабораторию (существующий вызов) |

**Итоги по длительности:** обычный этаж 1★ ≈ 7.0 с, 2★ ≈ 7.4 с, 3★ ≈ 8.4 с;
Прорыв — тайминги ×0.85; Хранитель ≈ 10.5 с; поражение 2.8 с; этаж 100 ≈ 11 с.
Скип — до ~1.2 с. Сейчас пауза 3 с — церемония осознанно длиннее, но не
дольше 11 с ни в одном варианте.

### Звёзды: раскраска и порядок

Три ассета (`star_gold/silver/empty.png`, 256×256) красим так:

- **gold** — заработано в этом забеге (поп-анимация + звук, слева направо);
- **silver** — уже стояло в сейве сверх заработанного (`stars_before`):
  проявляется тихо, без попа и звука (лёгкий щелчок `ui_hover` 0.35);
- **empty** — не заработано.

Реплей с худшим результатом (например, было 3★, выбил 2★): 2 gold + 1 silver,
под строкой наград приглушённый титул «Рекорд этажа: 3★» — не обесцениваем
попытку, не прячем прогресс. Улучшение рекорда (`stars > stars_before`) —
всегда минимум «уровень праздника 2★» (конфетти-волна), даже если сама
звезда одна новая.

Звук звёзд — лесенка питча на одном сэмпле `upgrade`:
1-я 1.00 → 2-я 1.15 → 3-я 1.30 (третья дублируется тихим `exchange` 0.4).
`play_sound(key, vol, pitch)` уже умеет питч (`sound_manager.gd:204`).

### Конфетти: сколько и откуда

Текстуры `confetti_01..03.png` + `spark_star.png` — 2D-частицы на слое
оверлея (GPUParticles2D). В Godot нельзя случайную текстуру на частицу —
по узлу частиц на текстуру, amount делится списком констант (§8).

- **2★ / улучшение рекорда:** одна волна из верхней кромки экрана — полоса
  шириной 80% центра, направление вниз, лёгкий боковой ветер (turbulence),
  one-shot, 60 частиц (30/20/10 по текстурам).
- **3★:** волна 140 частиц (70/45/25) + два бока-бурста от углов баннера
  (45 частиц, наклон вниз-внутрь) + `spark_star`-твинклы за каждой gold
  (по 6 искр) + лёгкий шейк баннера на третьей звезде.
- **1★ без улучшения рекорда:** конфетти нет вообще — сдержанно.
- **Прорыв:** конфетти минимум «2★-уровня» даже при одной звезде (этаж
  наградный ×1.5 — темп и праздник чуть выше).
- Гравитация 480 px/с², lifetime 2.6-3.0 с, масштаб частиц 0.5-0.9 от
  размера текстуры. Суммарный потолок всех частиц — 200 (слабые машины).

### Переход: лестница / портал, камера, затемнение

- **Обычный этаж** — `tower_staircase.glb` (высота ~4 м): спавн в 6 м от
  Монолита, развёрнут к активной камере. Кат-камера (см. ниже) поднимается
  на высоту лестницы. 2D-подложка баннера подъёма — `glyph_stairs_up.png`.
- **Хранитель и смена яруса (этаж 10/20/…/90)** — `portal_ring.glb`
  (диаметр ~4 м): кольцо в 6 м от Монолита, вращение кодом
  `rotate_y(delta * PORTAL_SPIN_SPEED)` (в glb анимации может не быть),
  искры `spawn_sparks_at()` вокруг. Переход яруса анонсируется титром
  «ЯРУС: <имя>» вместо «ЭТАЖ N+1».
- **Камера** — отдельная Camera3D «кат-камера», НЕ трогаем `game_camera`
  (у него захваченная мышь на ПК и RTS-ветка на мобилке — драка за ввод):
  1. спавн в текущей позе активной камеры, `current = true`;
  2. у `game_camera` отключаем обработку (`set_process(false)`,
     `set_physics_process(false)`) — на время церемонии;
  3. перелёт к базе лестницы/портала за `CAM_TO_TARGET_TIME` 0.6 с;
  4. подъём на `CAM_RISE_HEIGHT` 4 м за `CAM_RISE_TIME` 2.0 с (ease-in-out);
  5. в конце — затемнение, смена сцены (камера умирает со сценой).
- **Затемнение** — фулл-рект ColorRect на слое оверлея: 0.55 альфа на старте,
  1.0 в конце (`FADE_OUT_TIME` 0.5 с). Титр «ЭТАЖ N+1» живёт на чёрном.
- **Фолбэк без 3D-ассетов:** чисто 2D — `glyph_stairs_up.png` всплывает
  по центру экрана + то же затемнение и титр. Никаких требований к glb.

## 4. Вариантность церемонии

### 4.1 Обычный этаж (норма)

Последовательность §3. Баннер `banner_floor_cleared.png`, переход лестницей,
титр «ЭТАЖ N+1».

### 4.2 ▲ Прорыв (каждый 5-й)

- Баннер `banner_break.png` (оранжевая рамка) вместо обычного, строка
  «ПРОРЫВ: награда ×1.5» под заголовком.
- Темп бодрее: все не-звуковые интервалы ×`BREAK_TIME_SCALE` 0.85 —
  «пробежал с разгоном».
- Конфетти минимум 2★-уровня (см. выше). Переход — лестница (ярус не
  меняется), титр обычный «ЭТАЖ N+1».

### 4.3 ☠ Хранитель (каждый 10-й, босс-килл)

Самая длинная и «тяжёлая» церемония:

1. Пре-ролл: баннер `banner_keeper.png` (красная рамка) с именем босса
   (имя яруса из `TowerData.TIERS`), **двойной слэм** (два панча с шейком
   экрана 6 px), рык: `mutant_chimera` vol 0.5 pitch 0.7 + `pulse_warning`
   vol 0.6 pitch 0.65. Держится 1.9 с.
2. Далее стандартная последовательность §3 (баннер «ЭТАЖ ПРОЙДЕН» идёт
   поверх, звёзды, награды ×3 строкой).
3. Переход — **порталом** (сменяется ярус): титр «ЯРУС: <имя следующего>»,
   вокруг портала искры.
4. На 3★ — фонтан из портала (доп. волна конфетти 60 частиц).

Длительность ≈ 10.5 с (пре-ролл + полный праздник).

### 4.4 1★ vs 3★ (уровни праздника) — сводка

| Что | 1★ | 2★ | 3★ |
|---|---|---|---|
| Конфетти | нет | 60 из верха | 140 + бока-бурсты 45 |
| Искры spark_star | нет | за gold | за gold + вокруг баннера |
| Шейк баннера | нет | нет | на 3-й звезде |
| Звук 3-й звезды | — | — | лесенка 1.30 + exchange |
| Держатель титра | 0.9 с | 0.9 с | 1.5 с (`TITLE_HOLD_MAX`) |

Улучшение рекорда при любой новой звезде поднимает колонку минимум до «2★».

### 4.5 Этаж 100 — «БАШНЯ ПОКОРЕНА»

`banner_victory.png` (1280×512): «СЕРДЦЕ ЗОНЫ ПОКОРЕНО». Полный залп
конфетти (максимум потолка 200), титр-список всех 10 ярусов по очереди
(строка «Корни → Трубы → … → Сердце Зоны», проявляется целиком, 1.6 с),
переход порталом. Длительность ≈ 11 с. Сейв-логика не меняется:
`_apply_tower_result` и так не двигает `tower_floor` за `TOTAL_FLOORS` —
повторные прохождения 100-го остаются фармом наград, церемония та же.

### 4.6 Поражение (любой этаж)

- Затемнение сильнее (0.75), баннер `banner_defeat.png`, 2.8 с, без звёзд
  (`evaluate_stars` на поражении = 0 — слоты не показываем вовсе).
- Строка: «+N биомассы (утешение)» — половинная награда уже так устроена
  в `_apply_tower_result`, только показываем.
- Звук: один `pulse_warning` vol 0.45 pitch 0.6, дальше тишина.
- Скип работает. Никаких конфетти и 3D — перехода «нет»: камера стоит,
  затемнение, выход.

## 7. Ввод и скип

- Скип-события: `InputEventScreenTouch` (мобилки), `InputEventMouseButton`
  (любая кнопка), `ui_accept` и `ui_select` (Space/Enter, геймпад).
- По скипу: остановить частицы (`emitting = false`), TitelRect/баннеры скрыть,
  затемнение 0.3 с → `play()` возвращается. Никаких отдельных экранов подтверждения.
- Подсказка «нажмите, чтобы продолжить» — мелкая, внизу, альфа 0.5,
  появляется через 1.5 с от старта (чтобы первый просмотр не дразнил).
- На ПК до старта `play()` — `Input.set_mouse_mode(MOUSE_MODE_VISIBLE)`.
- Тач-события не должны проваливаться в сцену (оверлей — full-rect,
  `mouse_filter = STOP`).

## 8. Константы — `data/ceremony_data.gd` (готовый блок)

```gdscript
# data/ceremony_data.gd
extends RefCounted
class_name CeremonyData

## Церемония окончания этажа Башни: тайминги, количества, звуки.
## Все длительности - секунды. Оверлей-исполнитель: ui/hud/ceremony_overlay.gd.
## Что крутить при переборе - комментарии у каждой группы.
```

## 9. Структура оверлея (для код-агента)

`ui/hud/ceremony_overlay.gd`, `extends CanvasLayer` (layer = `CANVAS_LAYER`).
Собирается в `_ready()` кодом: DimRect → Banner (TextureRect с фолбэком
на Panel+Label) → StarsRow (3 TextureRect) → RewardsLabel → ConfettiHost
(2-3 GPUParticles2D) → TitleRect (на чёрном, поверх FadeRect) → SkipHint.
3D-часть (лестница/портал/кат-камера) — отдельным методом, вся в `try`-стиле
проекта: нет ассета → 2D-фолбэк, ошибки не ломают выход в лабораторию.

`play(result: Dictionary) -> void` (с внутренним сигналом завершения, ждать
чём-то вроде `await ceremony.done`): определяет вариант по
`result.mode == "tower"`, `result.tower_summary` (может отсутствовать при
поражении на нулевом этаже — тогда базовый дефолт), `TowerData.get_floor_type`,
считает «уровень праздника» (stars, stars_before), собирает список шагов
(время → замыкание) и исполняет его с учётом скипа. Все строки — через
`Loc.t` (ключи §6). Звук — через `get_tree().get_first_node_in_group(
"sound_manager")` (правило проекта: не `Engine.get_singleton`).

Пути арта после доставки (перенос из inbox — за основным агентом):
`assets/ui/ceremony/*.png`, `models/tower/*.glb`. Каждый — через
`ResourceLoader.exists()` с фолбэком.

## 10. Что затрагивает / не затрагивает

Затрагивает (правки):
- `zones/zone_controller.gd` — `finish_run`: вызов церемонии вместо таймера,
  скрыть HUD, показать курсор (5-8 строк + ветка).
- `core/localization.gd` — ключи §6.
- Новые файлы: `ui/hud/ceremony_overlay.gd`, `data/ceremony_data.gd`.

Использует как есть (без правок): `managers/sound_manager.gd`,
`managers/particle_manager.gd`, `data/tower_data.gd`, `core/game_manager.gd`
(`_apply_tower_result` уже кладёт всё нужное в `tower_summary`),
`ui/panels/result_panel.gd` + `lab_controller._show_last_run_result`
(подробная сводка в лаборатории остаётся).

Не трогает: сейвы, гачу, награды (цифры этажей не меняются — церемония
только презентует то, что уже начислено).

## 11. Краевые случаи и риски

- **`tower_summary` на месте:** `process_run_result` синхронно мутирует dict
  до await — проверено по коду (`game_manager.gd:904-921`). Но на всякий
  случай оверлей переживает отсутствие ключа (сводка «награды: —»).
- **Захват мыши на ПК:** забыть `MOUSE_MODE_VISIBLE` = нескипуемая
  церемония. Первый запуск — проверить именно это.
- **Двойной вызов `finish_run`** уже защищён `is_run_finished` — не трогаем.
- **Слабые устройства:** потолок `CONFETTI_MAX_TOTAL`, GPUParticles2D дешёвые,
  3D-этюд — два инстанса низкополигональных glb на 3 секунды.
- **Первый запуск без арта** (подготовщик ещё не доставил): текстовые
  заглушки, всё играет по таймингам — церемонию можно встроить ДО доставки
  ассетов и проверить звук/тайминги/скип.
- **Тач-провал:** full-rect `MOUSE_FILTER_STOP`, иначе тап скипа поставит
  аномалию в сцену (ставить уже нельзя, но клик по HUD мигнёт).
- **Этаж 100 повторно:** церемония та же («БАШНЯ ПОКОРЕНА») — осознанно:
  финальный этаж фармят, праздник не мешает скипом.

## 12. Чек-лист приёмки

1. Обычный этаж 1★/2★/3★: баннер → звёзды с лесенкой звука → (2★+)
   конфетти → лестница с камерой → титр → лаборатория. Тайминги §3.
2. Прорыв (например, этаж 25): оранжевый баннер, темп ×0.85, конфетти 60+.
3. Хранитель (этаж 10): пре-ролл с именем босса, рык, портал, «ЯРУС: Трубы».
4. Этаж 100: «БАШНЯ ПОКОРЕНА», список ярусов, залп 200.
5. Поражение: 2.8 с, без звёзд, утешительная строка.
6. Скип: мышь (курсор виден!), тач, Space — везде ~1.2 с до лаборатории.
7. Реплей пройденного: темп ×0.85, silver-звёзды не озвучиваются попом,
   «Рекорд этажа: N★» при худшем результате.
8. Без файлов арта (папки ещё нет): текстовые заглушки, ничего не падает.
9. Музыка: ушла в fade на старте, «lab» заиграл в лаборатории.
10. Панель итогов в лаборатории — по-прежнему поверх, со сводкой круток.
