# Церемония «Этаж пройден» — как встраивать

**Что это:** спека эмоционального финала этажа Башни: баннер → звёзды (gold/
silver/empty) → конфетти → 3D-переход (лестница/портал) → титр «ЭТАЖ N» →
лаборатория. Варианты: обычный этаж / Прорыв / Хранитель / этаж 100 / поражение;
1★ сдержанно, 3★ — максимальный праздник. Всё скипается одним кликом.

**Зачем:** сейчас после победы — мёртвая пауза 3 с (`zone_controller.gd:1001`)
и сухая текстовая сводка в лаборатории. Церемония продаёт основной фэнтези
режима («поднялся на этаж выше») и подчёркивает звёзды — главную валюту реплеев.

**Как встраивать (кратко):**
1. Новый `data/ceremony_data.gd` (константы из спеки, блок готов) и новый
   `ui/hud/ceremony_overlay.gd` (CanvasLayer-оверлей кодом, как star_panel).
2. В `zones/zone_controller.gd` `finish_run()`: для `run_mode == "tower"` вместо
   `await create_timer(3.0)` — `await ceremony.play(result)` (звёзды брать из
   `result["tower_summary"]`, словарь уже_mutated после `process_run_result`).
3. Скрыть HUD, показать курсор на ПК (в забеге mouse captured), музыка —
   `stop_music(1.2)` (лаборатория сама включит "lab").
4. Арт ждём из `inbox/mode_ui/` и `inbox/tower_transition/` (задания 4-5
   COMMANDS.md); **каждый файл опционален** — оверлей падает на текстовые
   заглушки (принцип «заглушки → реальный пак» как в SoundManager).
5. Звук — только существующие ключи (upgrade/exchange/ui_*/anomaly_gravity/
   mutant_chimera), маппинг в таблице §6. Виш-лист новых SFX — в конце доки.

**Трогает:** `zones/zone_controller.gd`, `core/localization.gd`, новые
`data/ceremony_data.gd` + `ui/hud/ceremony_overlay.gd`. НЕ трогает:
`tower_data.gd`, сейвы, панель итогов лаборатории (остаётся сводкой деталей).
