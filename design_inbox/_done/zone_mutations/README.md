# NG+ Мутации Зоны — как встраивать

**Что это:** 15 правил-мутаций, детерминированно привязанных к циклам NG+
(2–3 активных на цикл): условия, меняющие ИГРУ («аномалии стареют»,
«дождь лечит сталкеров», «Монолит регенерирует»), баннер на старте
забега, экран активных мутаций в лабе. Не числа-множители — характер.

**Зачем:** NG+ растит врагов и награды числом — играть в 3-м цикле то же,
что в 1-м. Мутации дают циклам характер («цикл 3 — год дождей») и цели
реплеев под разные отряды.

**Как встраивать (кратко):**
1. Новый `data/zone_mutations_data.gd` (15 правил + таблица активных по
   циклу — блок готов) + `zones/mutation_manager.gd` (применение).
2. Баннер при старте забега (run_popups), экран активных мутаций в лабе
   (вкладка селектора), флаги в мутациях читают системы.
3. Только с цикла 2+ — ранняя кампания не задета.

**Трогает:** новый data/manager, zone_controller (крючки-вызовы), lab
(экран мутаций), save (+mut_state). НЕ трогает: базовый баланс циклов
(числа), раннюю кампанию, церемонии.
