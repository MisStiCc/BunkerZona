# NG+ Мутации Зоны по циклам (D28)

Опора: `core/game_manager.gd` (NG+ циклы: campaign_cycle, гвард
campaign_cycle_100), `run_popups` (баннеры забега), `data/campaign_data.gd`
(get_level_params — точка добавления мутационных модификаторов),
`zones/zone_controller.gd` (сигналы выброса/волн), `Signals`, `Loc`.

## 1. Правила активации

- Мутации активны **с цикла 2+**; ранняя кампания и цикл 1 — чистые.
- На цикл N активны **2–3 мутации**, детерминированно: индексы из
  `(N × 7) % 15` и `(N × 7 + 5) % 15` (+ третья с N ≥ 5: `(N × 11) % 15`;
  коллизии — сдвиг +1). Один и тот же цикл = одна и та же пара —
  «характер цикла», обсуждаемый игроками.
- **Никогда одновременно**: «дождь лечит» + «дождь топит» (антагонисты
  в таблице), «Монолит регенерирует» + «аномалии стареют вдвое быстрее».

Баннер старта: перечислить активные (2–3 строки).

## 3. Данные и код

```gdscript
# data/zone_mutations_data.gd — мутации NG+ (спека D28)
extends RefCounted
class_name ZoneMutations

const ENABLE_FROM_CYCLE: int = 2
const ACTIVE_PER_CYCLE: int = 2          # 3 с цикла 5
const FORBIDDEN_PAIRS := [["rain_heal", "hard_rain"], ["mono_regen", "aging"]]

const RULES := {
	"dual_art":  {"title_ru": "ДВОЙНОЙ КЛАД", ...},
	"aging":     {"title_ru": "СТАРЕЮЩИЕ АНОМАЛИИ", ...},
	"rain_heal": {"title_ru": "БЛАГОСЛОВЕННЫЙ ДОЖДЬ", "enemies_only": true, ...},
	...
}

## Активные мутации цикла (детерминированно, без антагонистичных пар)
static func active_for_cycle(cycle: int) -> Array:
	var n := maxi(int(cycle), 1)
	if n < ENABLE_FROM_CYCLE:
			return []
	var idxs := [(n * 7) % 15, (n * 7 + 5) % 15]
	if n >= 5:
			idxs.append((n * 11) % 15)
	# разворот коллизий +1 (и/или по FORBIDDEN_PAIRS)
	return idxs
```

- `zones/mutation_manager.gd` (Node, группа "mutation_manager"): на старте
  забега с цикла 2+ читает активные, применяет через флаги системам и
  держит `is_active(id)` для точечных проверок (дроп ×2, щит при спавне).
- `get_level_params`: speed_mult ×1.2 при m_sprint (единственная правка
  в числовой баланс — остальное через флаги).
- Баннер: run_popups при старте — «МУТАЦИИ ЦИКЛА N: <названия>».
- Экран в лабе: вкладка селектора «МУТАЦИИ ЦИКЛА» — карточки активных
  (название + описание) + «следующий цикл: <превью>».

## 4. Чек-лист приёмки

1. Цикл 1: ни одной мутации; цикл 2: ровно 2, детерминированные.
2. Баннер старта перечисляет активные; экран в лабе совпадает.
3. dual_art: дроп ×2 подтверждён; m_thorn: смерть мутанта бьёт 20 в 3 м.
4. Антагонистичные пары никогда не совпадают.
5. Ранняя кампания/цикл 1/башня без мутаций (мутации только на циклы
   NG+ в кампании; башня/выживание — без мутаций, они вне циклов).
6. Смена цикла — новый набор; сейвы мигрируют (mut_state пусто).
