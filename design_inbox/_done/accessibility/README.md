# Настройки доступности — как встраивать

**Что это:** четыре тумблера/ползунка в существующих настройках (меню +
лаборатория): масштаб UI, режим дальтоника (редкости читаются формой),
отключение тряски экрана, уменьшение мерцания постэффекта. Всё — клиентские
настройки в `settings.cfg`, на геймплей и баланс не влияют.

**Зачем:** мелкий текст HUD/лаборатории нечитаем части игроков; редкости
различаются только цветом (common серый/uncommon зелёный/rare синий/
legendary золотой); тряска (Хранитель, слэмы) и мерцание (зерно/мерцание
постэффекта) — триггеры дискомфорта.

**Как встраивать (кратко):**
1. `data/accessibility_data.gd` — константы и API чтения/записи настроек.
2. UI настроек: 4 контрола рядом с существующими (музыка/звук/язык/слот).
3. Потребители: BunkerUI/лаборатория (масштаб), cards_util/гача/ферма
   (иконки редкости-формы), ceremony/battle shake (тряска),
   GrimPostfxLayer (мерцание/зерно).

**Трогает:** settings.cfg (4 ключа), ui настроек (обе сцены), 4 точки-потребителя.
НЕ трогает: баланс, сейвы забегов,-layout панелей.
