# Эндгейм: NG+ после 100 колец — как встраивать

**Что это:** финал кампании получает смысл продолжения: церемония «ЗОНА
ПОКОРЕНА» при 100-м кольце и режим NG+ (цикл 2, 3, …) с растущим
множителем врагов и наград; коллекция/прокачка/базар сохраняются.

**Зачем:** сейчас 100-е кольцо ставит `campaign_completed = true` и кампания
просто молчит — самый преданный игрок упирается в «дальше нечего» ровно в
момент максимальной прокачки.

**Как встраивать (кратко):**
1. `CampaignData`: цикл забега (NG+ множители — блок §4), статический
   расчёт параметров уровня от цикла.
2. `game_manager`: поле `campaign_cycle` в сейве; при победе на 100-м —
   цикл +1 (кольца остаются открытыми), церемония.
3. Селектор в лаборатории: строка «ЦИКЛ N · награды ×K» + повторный вход
   в любой уровень из открытых.
4. `ceremony_overlay`: вариант `victory_campaign` (титр + список глав).

**Трогает:** data/campaign_data.gd, core/game_manager.gd, data/save_data.gd
(+1 поле с миграцией), ui/lab (селектор), ceremony_overlay. НЕ трогает:
башню/выживание, гачу, баланс глав внутри цикла.
