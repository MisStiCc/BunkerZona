# Эндгейм: NG+ после 100 колец (D12)

Опора: `core/game_manager.gd` (`_apply_campaign_result`: `campaign_completed`
ставится на 100-м; `current_save_data.campaign_level`), `data/campaign_data.gd`
(`get_level_params(level)`, BOSSES, главы), `data/save_data.gd` (миграция
старых сейвов уже есть), `ui/hud/ceremony_overlay.gd` (вариантность по
`result.mode`), `ui/lab/lab_controller.gd` (селектор режима/уровня).

## 1. Принципы

1. **Прокачка не сбрасывается.** NG+ — это «Зона вернулась сильнее», а не
   новый аккаунт: коллекция, звёзды, трек, базар остаются.
2. **Цикл = один множитель, а не новая таблица.** Все главы переигрываются
   теми же правилами; растёт только «погода Зоны».
3. **Вход свободный.** В цикле 2+ открыт весь уровень 1–100 сразу (кампания
   пройдена) — играем любимые главы с изменённой сложностью.
4. **Финал каждого цикла — та же церемония, громче.**

## 2. Что видит игрок

- Победа на 100-м кольце: церемония «ЗОНА ПОКОРЕНА» (список глав, залп
  конфетти — переиспользование варианта tower-100) + строка «ЦИКЛ N ЗАВЕРШЁН.
  Зона мутирует: враги ×K, награды ×M».
- Селектор кампании: бейдж «ЦИКЛ N», уровень выбирается свободно, каретка
  по главам сохраняется.
- Кнопка СТАРТ подставляет параметры уровня с NG+ множителями.

## 3. Мультипликаторы (ручки, блок §4)

| Цикл | Враги (HP/урон) | Награда (боевой доход) | Комментарий |
|---|---|---|---|
| 1 | ×1.00 | ×1.00 | базовая кампания |
| 2 | ×1.15 | ×1.25 | мягкий вход в NG+ |
| 3 | ×1.30 | ×1.50 | |
| 4 | ×1.45 | ×1.75 | |
| 5+ | ×1.45+0.10×(N−4) | ×1.75+0.20×(N−4) | линейный рост без потолка-«стены» |

Отдельно от статов кампании (глава даёт 1.52–1.65): суммарно цикл 5 на гл. 10
≈ ×2.4–2.6 — соответствует духу «легендарной Зоны», а кривая награды делает
каждый следующий цикл прибыльнее предыдущего (фарм-мотивация).

## 4. Готовый блок

```gdscript
# data/campaign_data.gd — NG+ (спека D12, design_inbox/endgame_ngplus)

## Множители цикла NG+: враги и боевой доход. Цикл 1 = база.
static func cycle_enemy_mult(cycle: int) -> float:
	var n := maxi(int(cycle), 1)
	if n <= 5:
		return [1.0, 1.15, 1.30, 1.45][n - 1]
	return 1.45 + 0.10 * float(n - 4)

static func cycle_reward_mult(cycle: int) -> float:
	var n := maxi(int(cycle), 1)
	if n <= 5:
		return [1.0, 1.25, 1.50, 1.75][n - 1]
	return 1.75 + 0.20 * float(n - 4)
```

Встраивание по точкам:

| Файл | Правка |
|---|---|
| `data/save_data.gd` | +`campaign_cycle: int = 1` (миграция: отсутствует → 1) |
| `core/game_manager.gd` | в `_apply_campaign_result`: при level ≥ 100 → `campaign_cycle += 1` (campaign_completed оставить true — маркер NG+ доступен); в `start_run`/run_params передать `campaign_cycle`; `cycle_reward_mult` — в `_collect_run_result` рядом с replay-бонусом |
| `data/campaign_data.gd` | `get_level_params(level, cycle)` — hp_mult/damage_mult ×`cycle_enemy_mult`; опыт караванов не трогать |
| `zones/zone_controller.gd` | прокинуть цикл в `_initialize_run` (там уже читают campaign_params) |
| `ui/lab/lab_controller.gd` | селектор: бейдж «ЦИКЛ N · враги ×K / награды ×M»; при `campaign_completed` разрешить выбор любого уровня ◀▶ без блокировок |
| `ceremony_overlay.gd` + `Loc` | вариант `victory_campaign`: титр «ЗОНА ПОКОРЕНА», список глав, строка цикла; вызов из `finish_run` при 100-м кольце (аналог tower-ветки) |

## 5. Краевые случаи

- **Миграция сейвов**: у всех старых игроков cycle=1, campaign_completed как
  была — никто не теряет прогресс.
- **Реплеи в NG+**: `campaign_replay`-бонус (×0.3) умножается ПОВЕРХ
  cycle_reward_mult — фарм по любви, не по необходимости.
- **Кольцо 100 повторно в том же цикле**: церемония показывается каждый раз
  (как tower-100 — фарм), цикл +1 ровно один раз: инкремент по факту ПЕРВОЙ
  победы на 100-м в рамках цикла (флаг в сейве `cycle_100_claimed`).
- **Караваны-боссы ×2.5** умножаются на cycle_reward_mult тоже — ок,
  боссы остаются самыми жирными точками дохода.
- **Башня/выживание**: не задеты (свои циклы).

## 6. Чек-лист приёмки

1. Победа на 100-м: церемония, цикл 1→2 в сейве, бейдж в селекторе.
2. Цикл 2, кольцо 1: враги ×1.15 к базе главы (сверить HP первого новичка),
   награда ×1.25 в итогах.
3. Вход на кольцо 55 в цикле 2 без прохождения 1–54.
4. Старый сейв: cycle=1, ничего не сломалось.
5. Кольцо 100 в цикле 2: цикл 2→3, повторная победа в цикле 2 не инкрементит.
