# Церемония закрытия сезона (D13)

Опора: `core/progression.gd` (`track_cycle()`, точка инкремента `:424-427` —
тост «ТРЕК ЗАКРЫТ! Цикл %d: сундуки жирнее на 25%%», буст сундуков уже в
формуле `:350`), `data/lab_data.gd` (`season_points`), `core/game_manager.gd`
(источники СП: арена +5/+10, пережитый выброс +3, обменник), сезонные задачи
и медали, `ui/hud/ceremony_overlay.gd` — образец оверлея, `GachaData` —
награда в крутки.

## 1. Что видит игрок

При закрытии 30-й ступени трека (в момент инкремента cycle) — поверх
лаборатории оверлей:

```
        СЕЗОН N ЗАКРЫТ
  ┌──────────────────────────┐
  │ Набрано СП сезона:  214  │   ← season_points текущего цикла
  │ Вызовы арены: 12 · Обороны: 4 │
  │ Пережито выбросов: 9     │
  │ ЗАКРЫТИЕ СЕЗОНА: +5 круток мутантов, +3 аномалийных  │
  └──────────────────────────┘
   Цикл N+1: сундуки жирнее на 25%
        [ ПРОДОЛЖИТЬ ]
```

Тайминги: титр-слэм 0.5 с → сводка построчно 0.25 с/строка → награда со
звоном → кнопка. Всего ~4 с, скип по клику. Играется ТОЛЬКО в лаборатории
(трек закрывается в ней же), поверх любых панелей, слой 10.

## 2. Сводка сезона: какие числа собирать

Источники — те же, что платят СП; сводка = подсчёт ЗА сезон. Для этого в
`SaveData.prog_track` добавить счётчики-накопители, инкрементируемые рядом
с каждой выдачей СП:

| Поле | Инкремент рядом с |
|---|---|
| `season_sp_arena_ch` / `_def` | game_manager: арена вызов +5 / оборона +10 |
| `season_sp_blowouts` | +3 пережитый выброс |
| `season_sp_exchange` | обменник (артефакты/копии/биомасса) |
| `season_sp_tasks` | сезонные задачи |

При инкременте cycle — сводка показывается, счётчики обнуляются.
СП сами по себе (`season_points`) НЕ обнуляются при закрытии (тратятся
в базаре по желанию) — сводка снимает копию до обнуления накопителей.

## 3. Награда закрытия (ручки)

```gdscript
# data/season_close_data.gd — церемония закрытия сезона (спека D13)
const REWARD_MUTANT_ROLLS: int = 5     # база за закрытие; «сезон залпом не фармят»
const REWARD_ANOMALY_ROLLS: int = 3
# Премия за хороший сезон: порог по СП набранного сезона
const GREAT_SEASON_SP: int = 200       # СП за цикл
const GREAT_BONUS_ROLLS: int = 3       # +3 к обеим круткам
# Тайминги оверлея
const TITLE_SLAM: float = 0.5
const ROW_STEP: float = 0.25
const AUTO_HOLD: float = 4.0
# Перебор: «награда жирная» - 3/2 без премии; «не замечают» - премия от 150 СП
```

Награда идёт через существующие `grant_mutant_rolls`/`grant_anomaly_rolls`
(списки наград в панели итогов подхватят автоматически).

## 4. Точки встраивания

| Файл | Правка |
|---|---|
| `data/season_close_data.gd` | новый, блок §3 |
| `data/save_data.gd` | +5 счётчиков в `prog_track` (миграция: отсутствие = 0) |
| `core/game_manager.gd` | +1 строка инкремента рядом с каждой выдачей СП (4 места) |
| `core/progression.gd` | в точке инкремента cycle: собрать `summary`, эмитить `signal season_closed(summary: Dictionary)`; обнулить накопители |
| `ui/lab/season_close_overlay.gd` | новый: CanvasLayer слой 10, титр/сводка/награда/кнопка, скип; звук — существующие `upgrade`/`reveal_legendary` |
| `ui/lab/lab_controller.gd` | `Prog.season_closed.connect(...)` → спавн оверлея |
| `core/localization.gd` | ключи `season_close.*` (титр, строки сводки, кнопка) |

## 5. Краевые случаи

- **Закрытие при открытой панели гачи/базара**: оверлей поверх всех (слой 10);
  после закрытия — панели как были.
- **Несколько закрытий подряд** (игрок накопил сразу): оверлеи выстраиваются
  в очередь (показ по одному, summary суммируется в очереди).
- **Старые сейвы**: счётчиков нет → 0, сводка с нулями показывается один раз
  и больше не мешает.
- **Первый цикл (N=1→2)**: церемония та же, «Цикл 2: сундуки жирнее».

## 6. Чек-лист приёмки

1. Закрыл 30-ю ступень: церемония поверх лаборатории, сводка = честные числа
   сезона, +5/+3 крутки (при СП ≥ 200 — +3 премия к обеим).
2. Кнопка/клик скипает; крутки начислены ровно один раз (проверка на скипе).
3. Сундукам цикла N+1 применён буст (существующая формула — не сломать).
4. СП не обнулились; накопители обнулились.
5. Два закрытия с интервалом в минуту — два оверлея по очереди.
