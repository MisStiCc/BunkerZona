# Церемония закрытия сезона — как встраивать

**Что это:** сезон (трек наград) получает явный финал: при закрытии 30-й
ступени — полноэкранная церемония «СЕЗОН ЗАКРЫТ» (итоги по СП, счётчик
цикла, награда закрытия), затем цикл +1 с бустом сундуков +25% (уже
существует).

**Зачем:** сейчас закрытие трека тихое (тост «ТРЕК ЗАКРЫТ! Цикл N…»), самый
крупный мета-рубеж игры не празднуется; игрок может вообще не понять, что
сезон кончился и почему сундуки вдруг жирнее.

**Как встраивать (кратко):**
1. `data/season_close_data.gd` (константы: тайминги, награда закрытия,
   пороги «отличного сезона» — блок готов).
2. `core/progression.gd`: при инкременте `track_cycle()` собрать сводку
   сезона (СП, цикл, заявки) и подать сигнал `season_closed(summary)`.
3. `ui/lab/season_close_overlay.gd` (новый, CanvasLayer по образцу
   ceremony_overlay): титр → сводка → награда → «ПРОДОЛЖИТЬ».
4. Награда закрытия в крутки (существующая гача), по циклу.

**Трогает:** core/progression.gd (точка инкремента), новый data+ui файл,
lab_controller (спавн оверлея). НЕ трогает: формулу сундуков (буст 25%
уже есть), СП, базар.
