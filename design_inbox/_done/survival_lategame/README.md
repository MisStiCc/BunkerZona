# Выживание 30+ — «фаза легенды»: как встраивать

**Что это:** дизайн волн 30/40/50+ в выживании: снятие потолков состава (мастера
до 70%, новички исчезают), плавная эскалация статов/скорости/передышки, система
**модификаторов волн** (ЭМ-туман = осадка энергии, Ночь = слепота, Жатва =
риск×2, бесплатный Выброс каждые 10 волн), честные анонсы игроку и лестница
наград за фазы (40/50/60 волн).

**Зачем:** после ~30-й волны эскалация выравнивается (потолки 28/55/30 в
`survival_data.gd`) — поздние волны отличаются только числом, играть становится
неинтересно. Фаза легенды даёт позднему этапу правила, ритм и престиж.

**Как встраивать (кратко):**
1. Основное — `data/survival_data.gd`: переписанная `get_wave_params` (формулы
   ниже 30-й не меняются!), новые константы LEGEND_*/MODIFIERS/MILESTONES —
   блок в спеке готов к вставке.
2. Модификаторы: `zone_controller._on_wave_ended/_on_wave_started` — применить
   эффекты существующих ручек (`resource_manager.energy_regen_rate`,
   `memory_component.set_vision_range`, постэффект-мультипликатор) с возвратом
   по концу волны. Ротация детерминированная, не на событийных (каждая 5-я) и
   не на выбросных волнах.
3. Выброс-волна (33/43/53…): таймер 75 с от старта → `event_manager.
   start_radiation_pulse()` бесплатно; таймер и плашки — по образцу
   `emission_timer_label` в HUD.
4. **Фикс-кран:** `GachaData.milestone_wave_reward(waves>=30)` сейчас возвращает
   набор на ЛЮБОЙ волне ≥30, а зовётся из `_on_wave_ended` каждую волну —
   после 30-й псевдогигант капает ежеволнно. Заменить таблицей MILESTONES
   (10/20/30/40/50 + цикл 60+), guard «%10 == 0».
5. Анонсы: существующий `hud.show_event_note` — в передышке видно, что на
   следующей волне (модификатор/событие/фаза/выброс).

**Трогает:** `data/survival_data.gd`, `data/gacha_data.gd` (milestone),
`zones/zone_controller.gd`, `ui/hud/hud.gd`, точечно `managers/resource_manager.gd`
(возврат регена), `components/memory_component.gd` (set_vision_range есть).
