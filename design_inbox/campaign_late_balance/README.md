# Баланс поздней кампании на Припяти — как встраивать

**Что это:** калибровочный заход для глав 9–10 (кольца 81–100) на карте
Припяти, где радиационный фон (lethal) умножился на финальные статы кампании.
Спека даёт точку контроля (измеряемые метрики) и три сценария-ручки — какой
применять, решает ЗАМЕР, а не глаз.

**Зачем:** сквозной множитель обороны на Припяти в гл. 9–10 = реген ×0.65 /
цена ×1.4 ≈ **0.46×** к темпу постановки аномалий, поверх статов ×1.52–1.65
и миксов 22/58/20. Есть риск, что финал на Припяти злее финала на Зоне
непропорционально; при этом награда ×1.5 компенсирует только деньги,
но не энергию.

**Как встраивать:** сначала ЗАМЕР по §3 (5 забегов на каждой карте), затем
одна ручка из §4. Если метрики в норме — ничего не менять.

**Трогает (по сценарию):** data/radiation_data.gd (одна константа).
НЕ трогает: кампанию, фон как механику, башню.
