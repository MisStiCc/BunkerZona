# Баланс кампании гл. 9–10 × радиационный фон (D11)

Опора: `data/campaign_data.gd` (гл. 9 «Территория Монолита» 81–90: волны 5→6,
сталкеров 17→19, микс 26/56/18, статы 1.52→1.58, скорость до 1.05; гл. 10
«Последний рубеж» 91–100: волны 6, 18→20, 22/58/20, 1.58→1.65, скорость
до 1.10, боссы ×2.5), `data/radiation_data.gd` (lethal: реген ×0.65, аномалии
×1.4, дрейф HP 1.5/с новичок-ветеран и 0.5/с мастер, премия ×1.5),
прокачка энергии/регена/скидки в лаборатории.

## 1. Математика давления (гл. 9–10, Припять = lethal)

| Плечо | Значение |
|---|---|
| Темп обороны (энергия→аномалии) | реген ×0.65 и цена ×1.4 ⇒ **0.46×** от базового |
| Прочность врагов | ×1.52–1.65 + скорость до ×1.10 |
| Дрейф сталкеров | новичок тает за ~53 с, ветеран ~100 с, мастер ~500 с — при миксе 22–26% новичков это чистая прибыль Зоны |
| Компенсация | награда ×1.5 (деньги), крутие вехи — энергии не добавляет |

Вывод: сам дрейф HP на поздней кампании — не проблема (мастеров он не берёт,
новичков добивает). **Единственное узкое место — энергия**: 0.46× темпа против
«шесть волн по 19 сталкеров». Вопрос лишь в том, насколько это фатально для
прокачанного аккаунта (треки энергии/регена компенсируют).

## 2. Почему нельзя чинить «в лоб»

Ослаблять статы кампании — ударит по процедурной карте (там фона нет).
Ослаблять фон глобально — обесценит D3 для глав 5–8. Правильно: одна ручка
внутри radiation_data, применяемая только при результатах замера.

## 3. Точка контроля (замер ДО правок)

На кольце 85 (гл. 9, середина) и 95 (гл. 10), карта Припять, сложность
Ветеран, аккаунт со средним треком энергии (тир 5+3):

1. **Дошло до Монолита** — доля прорвавшихся за забег. Норма ≤ 2–3 за забег.
2. **Поставлено аномалий за волну** — против ~14 на Зоне (тот же аккаунт).
   Норма ≥ 9.
3. **Пульс-темп**: копится ли 1000 энергии быстрее, чем волна (40 с пауза
   + волна). Норма: выброс доступен не реже, чем раз в 2 волны.
4. **Исход**: 5 забегов подряд — победы достижимы без идеальной игры.

Если все четыре в норме — закрываем вопрос (фон честная цена премии ×1.5).

## 4. Сценарии-ручки (применять ровно один, по числу проваленных метрик)

```gdscript
# data/radiation_data.gd — калибровка поздней кампании (спека D11)
# 0-1 проваленных метрик из §3: без правок.

# 2 метрики (обычно "аномалий мало" + "пульс редко") — смягчить только цену:
const ZONE_EFFECTS_LATE_SOFTEN := {
	"lethal": {"regen_mult": 0.65, "anomaly_cost_mult": 1.40, "drain_hp": 1.5,
		"drain_hp_master": 0.5, "reward_mult": 1.50, "postfx_mult": 1.20},
}
# -> anomaly_cost_mult 1.40 -> 1.30 (одна цифра; эффективный темп 0.50x)

# 3+ метрики (неиграбельно) — смягчить реген, НЕ трогая цену/дрейф:
# -> regen_mult 0.65 -> 0.72 (темп 0.51x; энергия идёт, тактика жива)
```

Оба сценария — односимвольные правки в ZONE_EFFECTS["lethal"], комментарии
у констант обновить. Дальше lethal остаётся «смертельным» по духу (дрейф
и премия нетронуты).

## 5. Чек-лист приёмки

1. Замер §3 выполнен до правок, метрики записаны в журнал работ.
2. Применён ровно один сценарий (или ни одного).
3. Кольцо 85/95 на Припяти после правки: проваленные метрики закрыты.
4. Кольца 41–70 (low/high) — поведение не изменилось (ручки только в lethal).
5. Выживание/башня на Припяти — без изменений (у выживания чистая зона,
   башня балансируется отдельно, если нужно).
