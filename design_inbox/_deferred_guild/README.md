# Гильдия — как встраивать

**Что это:** полная система гильдии: состав (30 мест), вклад и казна,
уровни с перками, **Гильд-босс** (недельный рейд по мотивам ОХОТЫ D19),
**Гильд-война** (двухнедельное противостояние гильдий), гильд-магазин
(жетоны), доска сообщений. Сейчас — ОФЛАЙН-эмуляция (бот-состав и
детерминированные соперники, как арена); архитектура — дневник событий,
чтобы переход на онлайн был заменой симулятора сервером.

**Зачем:** социальный крючок удержания (единственный большой отсутствующий
мета-слой), сток для(cosmetic) гильд-косметики D16, применение Прорывов и
пачек (D18/D20) в кооперативном контексте.

**Как встраивать (кратко):**
1. `data/guild_data.gd` (константы/таблицы §6) + `core/guild.gd`
   (состояние, дневник событий, симулятор ботов).
2. UI: кнопка «ГИЛЬДИЯ» в лаборатории, оверлей с вкладками
   (Обзор/Босс/Война/Магазин/Доска/Состав).
3. Онлайновый переход — Этап 3 (§7): тот же дневник уходит на сервер.

**Трогает:** новые data/core/ui файлы, lab_controller (кнопка), Loc.
НЕ трогает: три режима, баланс, сейв-слоты (данные гильдии — в сейве,
экспортируемы для онлайна).
