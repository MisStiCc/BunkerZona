# Сезонный журнал арены (D30)

Опора: rollover сезона `ui/lab/mail_overlay.gd::_ensure_season` (уже
считает место и создаёт письмо), `data/lab_data.gd` (сейв), 
`ui/profile/profile_controller.gd` (панели профиля, паттерн вкладок),
`ProfileData` (медали/аватары).

## 1. Данные

```gdscript
# lab_data.gd
@export var arena_history: Array = []
# элементы (пишет rollover):
# {"season": 9, "place": 3, "waves": 41, "reward": {rolls_mut: 8, sparks: 4}}
```

Rollover дописывает запись ДО создания письма (письмо ссылается на сезон).
Кап истории — 20 записей (старые вылетают).

## 2. UI (профиль)

Блок «СЕЗОНЫ» (после медалей): строки последних 10 сезонов —
«Сезон 9 · 3 МЕСТО · 41 волна · +8 круток» с цветом медали по месту
(1 — золото, 2–3 — серебро, топ-10 — бронза, дальше — серо).
Сверху — лучший результат за всю историю («Лучший сезон: 2 место»).

## 3. Ручки

- HISTORY_CAP 20; показывать 10 последних.
- Цвета мест: константа по месту (1/2-3/4-10/10+).

## 4. Чек-лист

1. Ролловер (эмуляция сменой даты) — запись появилась в журнале и письме.
2. 20+ сезонов — старые вылетают, свежие видны.
3. Старые сейвы без поля — журнал пуст, миграции без ошибок.
