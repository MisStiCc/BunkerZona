# Циклические события (live-ops) — как встраивать

**Что это:** полугодовой календарь временных событий: 26 недель = 13
ивентов по 2 недели, 6 уникальных мини-игр (сильнейшие повторяются).
Единый фреймворк: баннер, хаб события, валюта «Осколки Зоны», магазин
ивента, 10 вех с наградами. Офлайн детерминированно (дата → ивент),
онлайн-этап меняет только лидерборды.

**Зачем:** ритм возвратов (сейчас возвращают только ежедневная ОХОТА и
сезонный трек), витрина для «хайповых» режимов, сток для косметики D16.

**Как встраивать (кратко):**
1. `data/events_data.gd` (расписание 26 недель, ивент-константы, вехи,
   магазин — блоки готовые) + `core/event_manager.gd` (текущий ивент по
   дате, счёт, валюта, вехи — дневник событий, как гильдия).
2. `ui/events/event_hub.gd` — оверлей ивента (баннер, описание, кнопка
   «ИГРАТЬ», вехи, магазин) + 6 сцен мини-игр `ui/events/games/*`.
3. Баннер ивента в главном меню и шапке лаборатории.
4. Арт — задача 37 подготовщика (баннеры/иконки 6 ивентов, тайлы Жатвы).

**Трогает:** новые data/core/ui файлы, main_menu + lab (баннер/кнопка),
Loc. НЕ трогает: три режима, гачу, пропуск, гильдию, баланс.
