# Циклические события live-ops (D24)

Опора: `data/gacha_data.gd` (награды только через существующую гачу),
`data/lab_data.gd` (биомасса), D16 (косметика cos_*), `core/progression.gd`
(паттерн вех/циклов), гильд-оверлей и кодекс (паттерн оверлеев), звуки
пака (reveal_*, ceremony_win, wave_horn), CeremonyData (церемонный
механик), D19-модель химеры (данж).

## 0. Архитектура

- **Календарь детерминированный**: `week_number = дни_с_эпохи / 7 % 26` →
  ивент из таблицы. Без сервера, честно и просто; онлайн-этап добавит
  только лидерборды.
- **Ивент = 2 недели** (13 слотов на полгода; 6 игр: 5 повторяются ×2,
  финал-ивент ×3 — см. расписание §6).
- **Валюта ивента — «Осколки Зоны»** (общая для всех ивентов полугодия,
  сгорает в конце полугодия с финальной распродажей — правило «не копи
  вечно», классика live-ops). НЕ параллельная прогрессия: тратится только
  в ивент-магазине на косметику/крутки/Искры (крутки = существующая гача).
- **Дневник событий**: счёт/вехи/покупки пишутся в лог (гильдийский
  паттерн) — Этап 3 заменяет симулятор лидербордов сервером.
- **Единый интерфейс мини-игр**: `EventGame.start(cfg)` → сигнал
  `finished(score, stats)` → хаб начисляет осколки и вехи. Каждая игра —
  отдельная сцена, общий `ui/events/game_base.gd` (пауза, выход, результат).

## 1. Общий UX-каркас (хаб ивента)

```
┌─ ИВЕНТ: ЖАТВА ─────────────────── до конца: 6д 14ч ─┐
│ [баннер ивента]                                     │
│ «Артефакты созрели — собирай урожай линиями»        │
│ ┌─────────────────┐  ВЕХИ (10)                      │
│ │  ▶ ИГРАТЬ       │  5: 2 крутки  ▓▓▓░░ 120/200     │
│ │  Рекорд: 1 240  │ 10: рамка «Жнец» ...            │
│ └─────────────────┘  МАГАЗИН ИВЕНТА (осколки)       │
└─────────────────────────────────────────────────────┘
```
- Вход: баннер в меню/лабе (пульсирует в первые 2 дня ивента), кнопка
  «ИВЕНТ» в нижнем ряду лабы.
- Вехи: 10 ступеней по счёту за ивент (не валюте!) — свободные, без
  пропуска (пропуск = сезонный, не мешаем).
- Магазин: 6–8 позиций, цены в осколках (§7).
- Звуки: `wave_horn` на старте ивента, `reveal_*` на вехах,
  `ceremony_win` на финальной вехе.
- Мобилка: все оверлеи тач-совместимы (прецедент кодекса/гильдии).

## 2. Мини-игра 1: «ЖАТВА» (match-3)

- **Сетка 7×9**, тайлы = 6 типов аномалий (иконки HUD: жарка/электра/
  кислота/воронка/радиация/телепорт). Свап соседних, матчи 3+,
  каскады, комбо-множитель.
- **Фишка Зоны**: «Выброс-метр» растёт от матчей 4+; на полном — вся
  доска пересобирается, а каждый тайл даёт ×2 за следующий ход
  (риск/награда: не успел собрать — метр сгорает).
- **Особые тайлы**: матчи 4 = «воронка» (собирает линию), 5 = «саркофаг»
  (взрыв 3×3), L/T = «электра» (бьёт крестом).
- **Ход конечен** (30 ходов) → счёт. Осколки = score/100.
- Управление: свайп/клик; эффекты — частицы anomaly_fx текстур.
- Ручки: BOARD_W/H, MOVES 30, COMBO_MULT 1.5, METER_PER_MATCH4 34.

## 3. Мини-игра 2: «УЛЕЙ» — данж за Химеру (action-якорь, хайп)

- **Ты — Химера** (модель/анимации/галоп уже в игре): изометрический
  данж из 5 комнат, в каждой волна сталкеров (новички→мастера, стрелки-
  сторожи), в 5-й — Бункер-командир (мини-босс с щитом).
- **Механика**: WASD/стик — галоп, тап/клик — прыжок-прыжок (АОЕ),
  зажатие — «исступление» (урааа: +скорость, урон, но HP тает). HP
  не восстанавливается между комнатами (рогалик-напряжение), между
  комнатами выбор из 2 благословений Зоны (дпс/реген/доп. прыжок).
- **Убил всех в комнате — дверь открывается**; сталкеры-медики бегут к
  будке вызова — убей, пока не вызвали подкрепление (таймер-давление).
- Счёт: убийства ×10 + комбо без урона ×2 + время. Осколки = score/150.
- Смерть = конец забега (счёт сохраняется). Управление мобилки:
  виртуальный стик + 2 кнопки (прыжок/ярость).
- Ручки: ROOMS 5, WAVES_SCALE, HEAL_NONE, BLESSINGS_POOL 6.
- Технически: переиспользует base_mutant FSM наоборот (игрок-мутант);
  сталкеры — существующие сцены; арена — одна комната процедурной Зоны.

## 4. Мини-игра 3: «ЛАБИРИНТ ВЫБРОСА» (maze-TD)

- **Сетка-лабиринт 12×9** (генерация с гарантированным путём, seed дня
  — у всех одинаковый лабиринт, честный рекорд). Сталкеры идут колонной
  от входа к выходу (по кратчайшему пути, пересчёт после постройки).
- **Ты строишь**: в клетках ставишь аномалии за энергию (жарка 50/
  воронка 120/электра 90/тесла 200 — урезанные версии боевых, эффекты
  те же). Лабиринт НЕ можно перекрывать — только замедлять и жечь.
- **Волны 8**, каждая сильнее; пропустил 5 сталкеров — конец. Счёт =
  убийства × сложность волны. Осколки = score/80.
- Управление: тап/клик по клетке → выбор аномалии из дока (тач-ок).
- Ручки: WAVES 8, ENERGY_START 500, ENERGY_PER_KILL 12, ESCAPE_LIMIT 5.

## 5. Мини-игра 4: «ЦЕПЬ ЭЛЕКТРЫ» (pipes-головоломка)

- **Сетка 6×6–8×8 вращающихся труб** (прямые/углы/тройники) + особые
  тайлы-аномалии: Тесла (генератор), Конденсатор (нужен 2 входа),
  Изолятор (блок). Цель: замкнуть цепь от Теслы к Монолиту до таймера.
- 40 уровней ручной работы (данные — таблица сеток в events_data),
  сложность растёт: таймер 60→25 с, несколько Монолитов, разрывы.
- Счёт: уровень × 100 + остаток времени × 5. Осколки = счёт/300.
- Идеальный палец-паззл: один тап = поворот. Звук электры на замыкании.
- Ручки: LEVELS 40, TIMER_MIN 25.

## 6. Мини-игра 5: «ВЗЛОМ КОТЕЛКА» (Mastermind-логика)

- **Сейф лаборатории**: код из 4 аномалий (6 вариантов, повторы есть).
  Игрок выставляет комбинацию → «Электра» подсвечивает: сколько стоит на
  месте, сколько есть не на месте. 8 попыток.
- Обрамление: каждый сейф — награда на карте Припяти («торговец даёт
  наводку»); 5 сейфов за ивент, шестой — «сейф Котелка» (код из 5).
- Счёт: сейф × 500 − попытки × 40 + бонус безупречным (≤3 попыток ×2).
  Осколки = счёт/40.
- Ручки: CODE_LEN 4 (финал 5), TRIES 8, SAFES 5.

## 7. Мини-игра 6: «БОЛТЫ ГРАВИТОНА» (физика-слэнгшот)

- **Рогатка сталкера-зеваки**: тянешь болт, отпускаешь — он летит по
  параболе; на поле **гравитационные карманы** (воронки — искривляют
  траекторию, лифты — подкидывают, время — замедляет). Цель: поразить
  N мишеней-анималиков за минимальное число бросков.
- 30 уровней: движущиеся мишени, несколько карманов, «золотой болт»
  (бонус за попадание по дуге через 2+ кармана).
- Счёт: уровень ×150 + экономия бросков ×50. Осколки = счёт/200.
- Физика: ProjectSettings 2D-гравитация зонами (Area2D) — дёшево.
- Ручки: LEVELS 30, TARGETS_PER_LEVEL 3–7.

## 9. Вехи и магазин (общие правила)

- Вехи (10, по счёту ивента): 200/400/600/800/1000/1200/1400/1600/1800/2000.
  Награды: крутки мут/ан ×2-3, Искры 5-10, биомасса 20-50К, косметика
  ивента на 5-й и 10-й (рамка + титул «Покоритель <Ивента>»).
- Магазин (осколки): косметика 400–800, крутки 150 (×1)/600 (×5), Искры
  10/250, биомасса 50К/100. Финальные 2 недели — распродажа ×0.7.
- Валюта НЕ покупается за деньги (граница D16: ивент-осколки только
  игровой); пропуск монетизируется отдельно.

```gdscript
# data/events_data.gd — live-ops (спека D24)

	"vault", "bolts", "uley2", "labyrinth2", "chain2", "vault2", "bolts2",
	"finale"]
const MILESTONE_SCORES := [200, 400, 600, 800, 1000, 1200, 1400, 1600, 1800, 2000]

```

- `core/event_manager.gd`: `current_event() -> {id, ends_unix, week_left}`,
  `add_score(n)`, `claim_milestone(i)`, `shop_buy(id)`, `state(save)` —
  хранится в `save.event_state {id, score, claimed:[], shards, best}`.
- `ui/events/event_hub.gd` + `ui/events/games/<id>.gd|tscn`: базовый
  класс EventGame (start/finish), каждая игра ≤ 400 строк.
- Баннер: `ui/events/event_banner.gd` (меню + лаба), клик → хаб.
- Локали: `evt.*` (~35 ключей на ивент-фреймворк + по 6-8 на игру).

## 11. Порядок встраивания (коду)

1. Фреймворк (данные/менеджер/хаб/баннер/вехи/магазин) + ЖАТВА —
   первый ивент проверяет весь конвейер.
2. УЛЕЙ (самый дорогой: геймплей за химеру), потом ЛАБИРИНТ.
3. ЦЕПЬ/ВЗЛОМ/БОЛТЫ — лёгкие паззлы пачкой.
4. Финал-ивент — после всех.

## 12. Чек-лист приёмки (фреймворк + ЖАТВА)

1. Дата внутри окна ивента: баннер в меню/лабе, хаб открыт; вне окна —
   баннера нет, хаб говорит «ивент закончился» (и показывает следующий).
2. Партия Жатвы: счёт → осколки → вехи с наградами в гачу; перезапуск —
   прогресс на месте.
3. Магазин: покупка за осколки; косметика видна в профиле.
4. Конец ивента: осколки сгорают в финале полугодия (плачка заранее —
   «до сгорания: N дней» — честность).
5. Мобилка: свайпы в Жатве, хаб скроллится, ничего не уезжает.
6. Сейвы/гача/пропуск/гильдия не задеты.
