# Аудит безопасности «Бункер: Зона» — как встраивать

**Что это:** аудит поверхностей атаки на дату 01.11.2026 (клиентская
F2P-экономика, Android+ПК, монетизация в dev-эмуляции, онлайн в Этапе 3).
Формат честный: клиент Godot НЕ защищаем от решительного моддера —
защищаем от случайного читера, от утечки секретов и от мобильных
разработочных граблей; настоящая защита — сервер (Этап 3, PlayFab).

**Как встраивать:** П0-пункты чек-листа §5 — обязательны до релиза с
монетизацией; П1 — до выхода в Play; П2/П3 — по мере сил.

**Трогает:** ничего (аудит). Правки по чек-листу — отдельными заходами.
