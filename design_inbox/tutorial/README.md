# Онбординг первого забега — как встраивать

**Что это:** интерактивное обучение прямо в первом забеге (кампания, кольцо 1
— 3 волны новичков), без отдельной карты. 17 коротких шагов: лаборатория
(валюта, старт) → фаза подготовки (первая аномалия перед камерой, первый
мутант, зачем строить до боя) → СТАРТ → волна (кража = минус, килл = плюс) →
выброс за 1000 → условия победы → итоги → первая крутка гачи. Плюс разовые
пассивные подсказки «в моменте» (первая кража, первая полная энергия).

**Зачем:** игра не объясняет себя: энергия/биомасса, «аномалия ставится
точкой перед камерой», выброс, три исхода, гача — новичок всего этого не
знает и уходит после первого забега.

**Как встраивать (кратко):**
1. Новые `data/tutorial_data.gd` (шаги/тайминги — блок готов) и
   `ui/tutorial/tutorial.gd` (оверлей-наставник кодом: затемнение из
   4 ColorRect вокруг подсвеченного узла + плашка текста, слой 20).
2. Триггеры шагов — глобальная шина `Signals` (wave_started/stalker_died/
   anomaly_created/mutant_spawned/energy_changed/run_ended/stalker_picked_
   up_artifact) — игровую логику НЕ трогаем, кроме спавна узла наставника.
3. Состояние — в сейв: `tutorial_done: bool`, `tutorial_step: String`,
   `tutorial_passive: Dictionary` (+кнопка «Повторить обучение» в настройках).
4. Автозапуск: флаг false И `statistics.total_runs == 0` И кольцо 1 —
   лаборатория создаёт узел наставника; дальше он ходит за игроком
   (создаётся и в сцене забега).
5. Правила: скип в один клик всегда; таймаут шага → мягко отпускаем
   (мини-плашка в углу, игра не блокируется); паузу НЕ ставим.

**Трогает:** новые 2 файла, `data/save_data.gd` (+3 поля), `ui/lab/
lab_controller.gd` + `zones/zone_controller.gd` (спавн узла, по 3-5 строк),
`core/localization.gd` (ключи), настройки. Попутный фикс: объявить сигнал
`artifact_stolen` в `core/signals.gd` — он эмитится в `zone_controller.gd:831`
без объявления.
