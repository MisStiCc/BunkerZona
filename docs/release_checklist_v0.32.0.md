# Смоук-чек-лист релиза v0.32.0 «ТРИУМФ ЗОНЫ»

Прогон перед сборкой (30–40 минут). Отмечать ✔/✘; любой ✘ — фикс до релиза.
Собран по чек-листам спек: церемонии, NG+, сезон, доступность, радиация,
врата, Выброс, юраудит (design_inbox/legal_audit/ §4).

## 1. Церемонии финала (все режимы)
- [ ] Башня: обычный этаж 1★/2★/3★ — баннер/звёзды/конфетти/лестница/титр; скип мышью, Enter и тапом (~1.2 с до лабы, курсор виден).
- [ ] Башня: этаж 5 (Прорыв, темп ×0.85), этаж 10 (Хранитель: пре-ролл с рыком, портал, «ЯРУС»), этаж 100 («БАШНЯ ПОКОРЕНА» + список).
- [ ] Кампания: победа — «КОЛЬЦО N ЗАХВАЧЕНО», доход, «КОЛЬЦО N+1»; поражение — баннер + боевой доход.
- [ ] Выживание: 30+ волн — «НОВЫЙ РЕКОРД ВЫЖИВАНИЯ» + «ИТОГ: N ВОЛН»; гибель раньше — баннер поражения + «N волн · +X биомассы».
- [ ] Выброс в момент победы: эффект гаснет плавно под затемнением, без обрыва кадром.

## 2. NG+ (D12)
- [ ] Победа на 100-м: церемония, цикл 1→2, бейдж «ЦИКЛ 2» в селекторе.
- [ ] Цикл 2, кольцо 1: враги заметно крепче, награда ×1.25 в итогах.
- [ ] Свободный выбор любого уровня в цикле 2; старый сейв не сломан.

## 3. Сезон (D13)
- [ ] Закрыть 30-ю ступень трека: «СЕЗОН N ЗАКРЫТ» поверх лабы, сводка, +5/+3 круток; СП не обнулились, сундуки цикла жирнее.

## 4. Доступность (D14)
- [ ] Настройки (меню и лаба): масштаб 0.8/1.0/1.3 — лаборатория и меню масштабируются, HUD боя нет; тряска 0 — слэм Хранителя без тряски; мерцание 0 — зерно/мерцание ушли, виньетка на месте.
- [ ] Дальтоник ПРОТАНОП/ДЕЙТЕРАНОП: рамки редкостей перекрасились, пиктограммы ▢△◇★ на карточках; ВЫКЛ — как было. Настройки живут после перезапуска.

## 5. Припять
- [ ] Кампания гл. 5+ : плашка фона, «☢ N мкЗв/ч» у энергии, аномалии дороже, новички тают; гл. 9–10 — воронка 210, мастера живучи, награда ×1.5. Процедурная карта — ничего этого нет.
- [ ] Выживание на Припяти: волны приходят от врат (1→4 по волнам), треугольники врат на миникарте в передышке.
- [ ] Выброс: багровое небо, волна от Монолита, столбы света; повторный выброс играет заново.
- [ ] Эксклюзивы ЧЯ (Пепельный вихрь/Багровая жара/Пустотная петля): собственные FX-сцены, не перекрашенная база.
