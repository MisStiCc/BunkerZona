# Лицензии — mode_ui

Все 19 файлов — оригинальная процедурная генерация (Python/PIL),
выполнена специально для проекта StalkerRevert по ЗАДАЧЕ 4 из
COMMANDS.md. Сторонних ассетов не используется; шрифты не задействованы
(тексты баннеров рисует игровой оверлей).

Лицензия: **CC0 1.0** (общественное достояние) — любое использование,
включая коммерческое, указание авторства не требуется.

Состав: banner_floor_cleared / floor_up / keeper / break / ring_captured /
record (1920x360), banner_victory / defeat (1280x512), star_gold /
star_silver / star_empty (256x256), icon_mode_campaign / tower / survival
(256x256), glyph_stairs_up (128x256), spark_star (128x128),
confetti_01..03 (128x128).
