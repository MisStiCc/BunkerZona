# fonts — лицензии шрифтов

Все три шрифта — SIL Open Font License 1.1; полные канонические тексты
лицензий лежат рядом (`OFL-*.txt`, скачаны из репозитория google/fonts)
и обязаны распространяться вместе с шрифтами — включены в билд.

| Файл | Шрифт | Автор | Лицензия | Текст лицензии |
|---|---|---|---|---|
| JetBrainsMono-Variable.ttf | JetBrains Mono | The JetBrains Mono Project Authors | SIL OFL 1.1 | OFL-JetBrainsMono.txt |
| Oswald-Variable.ttf | Oswald | The Oswald Project Authors | SIL OFL 1.1 | OFL-Oswald.txt |
| RussoOne-Regular.ttf | Russo One | Jovanny Lemonad (jovanny.ru) | SIL OFL 1.1 | OFL-RussoOne.txt |

Условия OFL, которые мы соблюдаем: шрифты не продаются отдельно (идут в
составе бесплатной игры); копирайт-заголовок и текст лицензии
распространяются вместе с ними; «Reserved Font Name» (Russo) не
используется для производных — мы используем оригинал без модификаций.
