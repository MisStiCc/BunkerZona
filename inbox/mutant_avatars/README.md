# Аватарки 8 мутантов v2 (256px)

## Что это

Портретные аватарки 256×256 из новых Meshy-моделей (крупный план «лица»
или ядра), фон — градиент роли (те же цвета, что у карточек v2), мягкое
свечение и виньетка. Под аватарки профиля/гильдии, косметику, список
друзей — куда решит main.

## Как встроить (рекомендация, не делал сам)

1. Перенести в `assets/ui/avatars/` (или косметический путь по вкусу).
2. Имена = `avatar_` + id из блока NEW_ORIGINALS (README new_mutants) —
   удобно грузить по `id`: `"res://assets/ui/avatars/avatar_%s.png" % id`.
3. Рамки не рисовал — под рамки есть поставка profile_frames (_done).

Источник рендеров: `inbox/new_mutants/models_anim/` (GLB → Cycles).
