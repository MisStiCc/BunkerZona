# UI-звуки лабы (ЗАДАЧА 23)

## Что это

Четыре звука интерфейса лаборатории/гачи, которых не было. Процедурный
синтез, CC0. Ключ = имя файла.

| Файл | Длина | Момент |
|---|---|---|
| `ui_deny.ogg` | 0.30 с | нельзя купить/не хватает биомассы: глухой двойной тук + бузз-отказ |
| `ui_build.ogg` | 0.60 с | установка постройки/апгрейда станции: кланг + шип оседания + тук |
| `ui_research.ogg` | 0.90 с | исследование/прокачка завершены: три восходящих бипа + мажорный аккорд |
| `gacha_spin.ogg` | 1.60 с | прокрутка рулетки гачи: тики ускоряются, питч ползёт вверх. Проигрывать поверх, при необходимости зациклить до остановки |

## Как встраивать (рекомендация, не делал сам)

- `ui_deny` — в `_update_affordability`-подобных местах при неудачной
  попытке покупки (вместо молчания).
- `ui_build` — подтверждение апгрейда станции/покупки мутанта.
- `ui_research` — завершение таймеров исследований, если появятся.
- `gacha_spin` — на время анимации прокрутки, `reveal_<rarity>` из
  соседнего пака — на момент вскрытия.

Генератор: `gen_lab_ui_sfx.py` (numpy + soundfile, OGG порциями).
