# Логотип «БУНКЕР: ЗОНА» (ЗАДАЧА 30)

## Что это

Прозрачный PNG-логотип: Impact, вертикальный золотой градиент с верхним
бликом, толстая тёмная обводка, зерно-потёртости и рваная нижняя кромка
(сколы по фактическому низу букв). Стиль mode_ui. CC0.

| Файл | Размер | Применение |
|---|---|---|
| `logo_wide.png` | 909×203 | одна строка — шапки, сплэш, широкие баннеры |
| `logo_stack.png` | 663×540 | «БУНКЕР» / «ЗОНА» в два этажа — капсула 920×430, вертикаль 640×960, itch |

## Как применять

Наложить в зарезервированные зоны постеров (см. ЗАДАЧА 31 — там уже
вшитые версии). Логотип самодостаточен: тёмная обводка даёт читаемость
на любом фоне.

Генератор: `gen_logo.py` (PIL + системный Impact; детерминированный).
