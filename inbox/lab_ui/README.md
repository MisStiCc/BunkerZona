# Арт-пак лаборатории и главного меню (lab_ui)

## Что это

Фирменный 2D-арт интерфейса под стиль зоны: тёмный графит, болотная зелень,
жёлтые акценты — ровно как `UiTheme` (`ui/ui_theme.gd`: фон #0E1217, окантовка
#576B4F) и баннеры `inbox/mode_ui`. Всё процедурное (генератор
`gen_lab_ui.py` в корне пака, воспроизводимо: `python gen_lab_ui.py`),
лицензия CC0. Визуально выверено по контрольным листам (2 итерации правок).

## Как встроить (рекомендация, не делал сам)

1. Фоны — `TextureRect` на весь экран (`.stretch_mode = STRETCH_KEEP_ASPECT_COVERED`)
   под корнем лаборатории/меню, панель UI поверх.
2. `panel_frame_9patch.png` — в `StyleBoxTexture` (панели по спеке
   непрозрачные: рамка поверх тёмной заливки; окантовка совпадает с UiTheme).
   Nine-patch: углы 28 px, tile выключен.
3. Кнопки — `StyleBoxTexture` для `normal`/`hover` (focus/pressed можно
   переиспользовать hover с modulate).
4. Иконки станций — `TextureRect` в шапках станций/кнопках навигации.
5. Генератор правится под себя: палитра — константы наверху `gen_lab_ui.py`
   (GRAPHITE/PANEL/SWAMP/GOLD/CREAM — те же значения, что в UiTheme).

## Технические заметки

- 2K (2560x1440) вместо 4K: задания разрешают «или 2k»; вес фонов ~2-3 МБ
  вместо ~8, для UI-фонов разницы на экране нет. Если нужен 4K — поменять
  W/H в `lab_background()`/`menu_background()` и перегенерировать.
- В фон меню не пытался впихнуть текст/логотип — место под заголовок игры
  верхняя треть, там небо спокойное.
- Seed зафиксирован (20261018) — перегенерация даёт тот же результат.
