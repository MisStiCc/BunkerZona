# Стингеры событий (ЗАДАЧА 24)

## Что это

Три коротких джингла под баннеры mode_ui и события башни. Процедурный
синтез, CC0, пики ≤ 0.66. Ключ = имя файла.

| Файл | Длина | Настроение и момент |
|---|---|---|
| `record_new.ogg` | 1.10 с | «НОВЫЙ РЕКОРД ВЫЖИВАНИЯ»: светлое арпеджио D-мажор вверх + органная подложка + блеск |
| `gates_open.ogg` | 1.20 с | «врата яруса открыты»: рунные колокола (квинта) + каменный толчок |
| `keeper_awake.ogg` | 1.20 с | «Хранитель пробуждается»: диссонирующий низкий рёв (65/69 Гц биения) + скрежет, тёмный |

## Как встраивать (рекомендация, не делал сам)

- `record_new` — вместе с banner_record (выживание, новый рекорд).
- `gates_open` — при первом входе на новый ярус башни (врата открылись).
- `keeper_awake` — на интро Хранителя (banner_keeper) перед боем.

Генератор: `gen_event_stingers.py` (numpy + soundfile, OGG порциями).
