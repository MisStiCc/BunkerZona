# HUD-иконки 8 новых мутантов (продолжение ЗАДАЧИ 23)

## Что это

8 иконок 96px под кнопки забега (`ui/hud/hud.gd`) для мутантов v2
(поставка new_mutants). Стиль повторяет `_done/ability_icons` (з.23):
та же тёмная плашка со срезанными углами, нейтральная окантовка,
цветной глиф, зерно — генератор импортирует `plate()` прямо из
`gen_ability_icons.py`, лист `_review_icons.png` лежит рядом со старой
восьмёркой неотличимо.

## Файлы (`mutant/<id>.png`, имена = id вида из блока NEW_ORIGINALS)

| id | Глиф |
|---|---|
| kremen | купол-панцирь + голова-таран, янтарные глаза |
| rzhavnik | краб-сборщик: клешни-ковши, линза-глаз, антенна |
| sporonosets | шляпка-купол, светящиеся лозы, споры |
| chrevo | багровый курган, янтарное соцветие, щупальца |
| iskropluy | S-изгиб угря, рога-разрядники, искра |
| kosar | капюшон, белая маска-щель, скрещённые косы |
| mayak | колпак-прожектор с янтарным лучом, каменное тело |
| horovod | три призрачные фигуры по кругу, фиолетовый венец |

## Как встроить (рекомендация, не делал сам)

1. Папку `mutant/` слить с `assets/ui/abilities/mutant/` (там уже 10
   старых) — имена не конфликтуют.
2. В hud.gd подключение то же, что у старых: по type=id
   (`kremen`, `rzhavnik`, ... — это значения id из блока NEW_ORIGINALS
   в README new_mutants).
3. Серых/тусклых версий не нужно — старые 10 их тоже не имеют.
