# Рамки аватара профиля по рангу (ЗАДАЧА 24)

## Что это

4 рамки 256×256 RGBA (прозрачный центр 132×132 — под аватар) в стиле зоны.
Накладываются поверх аватара профиля (`ui/profile`), растягиваются на
квадрат.

| Файл | Ранг | Отличия |
|---|---|---|
| `frame_novice.png` | новичок | сталь + болотная окантовка, заклёпки |
| `frame_veteran.png` | ветеран | тёмная сталь + золотая линия, золотые заклёпки |
| `frame_master.png` | мастер | золото + рунические метки сверху/снизу |
| `frame_legend.png` | легенда | золото + красные самоцветы + руны |

Генератор: `frame_gen` внутри журнала подготовщика (PIL, детерминированный);
перегенерация — параметры в `make()`.

## Как встраивать (рекомендация, не делал сам)

1. Папку перенести в `assets/ui/profile/`.
2. В профиле поверх аватара: `TextureRect` с рамкой (PERSIST при смене
   ранга). Ранг = функция статистики игрока (например, лучший этаж башни:
   1–25 новичок, 26–50 ветеран, 51–75 мастер, 76+ легенда — решить
   основному агенту).
