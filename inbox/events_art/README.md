# Арт-пак циклических событий (ЗАДАЧА 37, live-ops D24)

## Что это

23 процедурных арта под 6 ивентов-мини-игр (спека `design_inbox/liveops_events/`).
Стиль mode_ui: графит + болотная зелень + жёлтый акцент, зерно. CC0
(CREDITS.md). Текст НЕ запечён — слева в каждом баннере затемнённая зона
~760 px под название.

## Иконки 256×256 (кнопки) — `<имя>_icon.png`

Та же сцена в глифе на плитке со срезанными углами, окантовка в цвете
ивента (zharva — оранж, uley — красный, labyrinth/chain — синие, vault —
золотой, bolts — фиолет).

## Тайлы Жатвы 128×128 (прозрачный фон, HUD-стиль)

`tile_fire / tile_bolt / tile_drop / tile_vortex / tile_gas / tile_radiation`
(6 аномалий) + `tile_funnel` (воронка), `tile_sarcophagus` (саркофаг),
`tile_electra` (электра) — 3 особых.

## Виньетки 256×256

`shard_zone.png` — «осколок Зоны» (валюта: светящийся фиолетовый кристалл);
`milestone_chest.png` — «веха» (сундук с золотом).

## Как встраивать (рекомендация)

Таблица EventArt (аналог CeremonyData.ART): ключ = имя файла без
расширения; баннеры — `TextureRect` STRETCH_KEEP_ASPECT_COVERED с текстом
поверх слева; иконки — в кнопки событий; тайлы — на игровой сетке Жатвы;
виньетки — в HUD событий (валюта/веха).

Генератор: `gen_events_art.py` (PIL/numpy, детерминированный).
