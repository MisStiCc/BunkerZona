# inbox — входящие материалы от агента-подготовщика

Сюда второй агент кладёт готовые материалы по заданиям из `COMMANDS.md`
(одна папка на задание, внутри — README и CREDITS).

Основной агент после встраивания материалов в игру переносит папку задания
в `inbox/_done/` и обновляет `STATUS.md`. До этого содержимое `inbox/`
менять нельзя — это зона обмена.
