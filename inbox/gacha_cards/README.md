# Арт-пак карточек гачи и эффектов вскрытия (gacha_cards)

## Что это

Процедурный набор под церемонию раскрытия круток. Стиль проекта: графит +
болотная зелень + золото (как `mode_ui` / `UiTheme`), цвета редкостей — из
`RARITY_COLORS` (`data/gacha_data.gd`). Генератор: `gen_gacha_cards.py`
(seed фиксирован, перегенерация детерминирована). Всё CC0 (см. CREDITS.md).

**Спека архитектора D6 не была готова** — делал по RARITY_COLORS, как
разрешало задание.

## Важно о цветах редкостей

В игре редкости: common (серый), uncommon (зелёный), rare (синий), legendary
(золотой). В задании названы рамки common/rare/**epic**/legendary — редкости
«epic» в данных нет, её рамка сделана **фиолетовым** (#B48CFF, конвенция
common<rare<epic<legendary) на вырост. Если пригодится зелёная uncommon —
одна строка в `RARITY` генератора.

## Координаты для игры

- **Окно иконки в рамках** (одинаковое у всех редкостей): прямоугольник
  `(58, 118) - (198, 258)` — прозрачная дыра в альфа-канале; иконку кладите
  ПОД рамку (TextureRect иконки ниже по z, рамка поверх).
- **Ниша под имя**: `(26, 60) - (230, 96)` — затемнённая зона поверх рамки,
  текст рисует игра. **Полоса статуса**: `(26, 272) - (230, 296)`.
- **Текст на плашках НЕ запечён** (принцип mode_ui — текст рисует игра):
  зона под текст `24..168 x 20..44`.

## Как встроить (рекомендация)

- Рубашка — закрытая карта в стопке/рулете; рамка + иконка + ореол по
  редкости собираются в стопку Control'ов; вспышка и искры — на момент
  вскрытия; плашки — уголком поверх карты.
- Искры тонировать `modulate` под нужный цвет события.
