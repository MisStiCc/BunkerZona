# Иконки задач (ЗАДАЧА 40)

## Что это

6 глифов 48px для панели ЗАДАЧИ (`Prog.tasks`, виджет в шапке лабы) —
панель станет читаться с полувзгляда. Процедурные, CC0.

| Файл | Тип задачи | Глиф |
|---|---|---|
| task_win.png | победа в забеге | звезда в лаврах (золото) |
| task_artifact.png | собрать/уронить артефакты | кристалл (болотный) |
| task_boss.png | убить босса/Хранителя | череп (красный) |
| task_guild.png | гильдейские (D21) | щит (фиолетовый) |
| task_survive.png | выживание N волн | три волны (синий) |
| task_floor.png | пройти этаж N | лестница вверх (золото) |

## Как встраивать (рекомендация)

В `_build_tasks_ui`/`_tw_refresh`: иконка слева от текста задачи
(`TextureRect`, 24-28 px, `task.get("icon")` — маппинг тип→файл задаёт
основной агент по своим ключам задач).

Генератор — в журнале подготовщика (PIL, детерминированный).
