# Colormap-палитра пропсов Припяти (ЗАДАЧА 10)

## Что это

`models/props/Textures/colormap.png` (512x512) — настоящая палитра вместо
нейтральной заглушки 4x4: пропсы Kenney перестают быть серыми. Положено
ровно по пути из задания (заглушка заменена, больше ничего не трогал).

## Как устроено

Kenney-модели (машины ×3, грузовик — Car Kit; лавка, фонарь, ограда —
Graveyard Kit) ссылаются на внешний `Textures/colormap.png` — атлас-палитру
8x8 ячеек по 64 px. У китов палитры РАЗНЫЕ (одни цвета, разные позиции
ячеек), поэтому:

1. Из UV пропсов (версии из коммита `3db9523`) декодированы фактически
   сэмплируемые ячейки: 20 ячеек Car Kit + 4 ячейки Graveyard Kit.
2. Палитра собрана из обеих: ячейки Car Kit взяты из палитры Car Kit,
   Graveyard — из Graveyard. Пересечение нашлось ровно в 3 ячейках
   ((4,5), (5,5), (5,6): стекло машин у Car Kit / фонарь у Graveyard) —
   туда положен тёплый янтарный компромисс (тёмное янтарное стекло машин =
   фонарь фонаря).
3. Все цвета приглушены под пост-советскую Припять: десатурация 35%,
   затемнение 22%, лёгкий тёплый сдвиг. Белые кузова стали грязно-белыми,
   зелёные — болотными, оранжевые — ржавыми. Неиспользуемые ячейки тёмные.
4. В каждой ячейке лёгкий вертикальный градиент + зерно — против бандинга
   на стыках ячеек.

Генератор: `gen_colormap.py` (пути к исходным палитрам китов — временные
файлы скачивания; повторная генерация требует перекачать car-kit и
graveyard-kit с kenney.nl, ячейки перечислены в скрипте константами).
