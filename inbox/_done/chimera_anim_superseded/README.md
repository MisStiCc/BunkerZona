# Анимированная химера (rig → 5 клипов)

## Что это

`chimera_rig_anim.glb` — риг из `models/chimera_rig.glb` (SmartRig, 72 кости,
307k трис) с 5 процедурными анимациями. Имена клипов = точные совпадения с
`base_mutant._match_clip` (idle / walk / gallop / attack / death) —
`use_builtin_clip_player` подхватит без правок кода. Сделано в Blender 4.5
(`--background --python`, скрипт у подготовщика), CC0.

## Клипы (проверены рендерами и загрузкой в Godot 4.6.1)

| Клип | Длина | Что |
|---|---|---|
| idle | 3.2 с | дыхание груди, покачивание голов в противофазе, ленивый хвост |
| walk | 1.2 с | диагональный шаг 4 лап (колени в противофазе), покачивание корпуса, хвост |
| gallop | 0.8 с | широкие махи, прыжковый подъём корпуса, качание |
| attack | 1.0 с | замах головами назад → бросок вперёд с ударом передних лап |
| death | 1.4 с | оседание, подкашивание лап, падение с наклоном, финальная судорога |

## Как встроить (рекомендация)

Заменить источник химеры на этот файл (перенести в `models/` и поправить
путь в `entities/mutants/chimera.tscn`/загрузке — или просто перезаписать
`models/chimera_rig.glb` этим файлом). Скин/кости идентичны исходному ригу
(72 кости, те же имена) — tint и вся логика игры работают как раньше.
Скрытая Icosphere-мусорка исходника удалена.

⚠️ Риг тяжёлый (307k трис, 18 МБ) — как и был; оптимизация отдельная задача.

## Проверка

- Blender: рендеры середины каждого клипа — деформация чистая, death не
  проваливается под пол (после правки оседания -0.30).
- Godot 4.6.1: сцена грузится, AnimationPlayer видит 5 клипов
  (attack, death, gallop, idle, walk).


## Синхронизация с перемещением (v2, 01.11.2026)

Игровая скорость мутанта — `speed = 5.0` м/с (×множители), а клипы имеют
собственную «подразумеваемую» скорость (длина шага ÷ цикл). Были в разы
медленнее — лапы скользили. Пересобраны: walk — каденция 0.9 с, мах 20°
(≈0.5 м/с), gallop — каденция 0.47 с, мах 30° (≈1.0 м/с).

**Системное решение** — масштабировать проигрывание по скорости (в
`base_mutant` при выборе клипа движения):

```gdscript
# REF_SPEED: walk ≈ 0.5 м/с, gallop ≈ 1.0 м/с (для chimera_rig_anim)
if want == _clip_run:
        _anim.speed_scale = clampf(vel / 1.0, 1.0, 3.5)
elif want == _clip_move:
        _anim.speed_scale = clampf(vel / 0.5, 1.0, 3.5)
else:
        _anim.speed_scale = 1.0
```

Тогда каденция всегда совпадает с фактической скоростью (скольжение
минимально; идеально — Motion Matching, вне скоупа). Аналогичные ref-скорости
для остальных моих ригов вычисляются как (2·длина_ноги·sin(мах) + дрейф) / цикл
— параметры в gen-скриптах.
