# Иконки 10 ярусов башни (ЗАДАЧА 46б)

## Что это

10 иконок 128px `tier_1.png ... tier_10.png` — продолжение pack_icons
(з.37): та же стальная плита со срезанными углами и заклёпками, глиф —
символ яруса, внизу планка с римской цифрой. Окантовка = палитра
`TowerData.TIER_COLORS` (согласована со штандартами ярусов в игре).

## Глифы (имена по TowerData.TIERS)

| Файл | Ярус | Глиф |
|---|---|---|
| tier_1 | Корни | ветвистые корни |
| tier_2 | Трубы | колено трубы с фланцами |
| tier_3 | Свалка | куча хлама |
| tier_4 | Глухая падь | впадина между холмами в тумане |
| tier_5 | Ржавый лес | дерево из ржавых балок |
| tier_6 | Буерак | зигзаг-овраг |
| tier_7 | Саркофаг | саркофаг с печатью |
| tier_8 | Полигон | мишень |
| tier_9 | Рубеж | тройной шеврон коменданта |
| tier_10 | Сердце Зоны | золотое сердце с пульсом |

## Как встроить (рекомендация, не делал сам)

1. Перенести в `assets/ui/` (рядом с pack_icons).
2. Подключение по индексу яруса: `tier_%d.png % (tier_index + 1)` —
   например в списке этажей, на вратах яруса, в церемонии.
3. Окантовки уже в TIER_COLORS — если палитра ярусов поменяется,
   генератор пересобирает: `python compose_portraits.py` в
   `inbox/karavan_bosses/` (общий скрипт с портретами караванов).
