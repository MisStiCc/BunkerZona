# Иконки пачек I-IV (ЗАДАЧА 37)

## Что это

4 иконки 64px для вкладок пачек мультипачки D20 (подготовка забега):
римская цифра на стальной плите со срезанными углами и заклёпками.

| Файл | Пачка | Рамка |
|---|---|---|
| pack_1.png | I | болотная |
| pack_2.png | II | стальная светлее |
| pack_3.png | III | золотая |
| pack_4.png | IV | золотая + красная метка (элитная) |

Генератор — в журнале подготовщика (PIL, детерминированный). CC0.

## Как встраивать (рекомендация)

Вкладки пачек (`_pack_tabs` hud.gd): `btn.icon = load(...)` +
`icon_max_width` ~20; текст-номер можно оставить как подпись или убрать
(римская цифра уже на иконке).
