# Хранитель Башни (ЗАДАЧА 42)

## Что это

`keeper_anim.glb` — страж-монолит (каждый 10-й этаж, x3 босс): призматическое
тело из тёмных ярусов, лицо-щель и ядро груди с эхо-эмиссией, 5 парящих
обломков-плеч. Высота ~5.2 м (парит, origin на уровне парения), 3 клипа.
Процедурный Blender, CC0.

## Клипы

| Клип | Длина | Что |
|---|---|---|
| idle | 4.0 с | парение (боб+наклон), пульс ядра, обломки на орбитах (полный круг за клип — бесшовно) |
| attack | ~1.1 с | разлом груди: ядро выпирает вперёд, обломки взлетают, рывок к жертве |
| death | 1.6 с | рассыпание: обломки разлетаются и падают, тело валится и оседает, ядро гаснет |

## Как встроить (рекомендация)

Файл → `models/keeper/keeper_anim.glb`; подключение в церемонию этажа и бой
(прецедент — Эхо-обелиск, задача 35). Масштаб 1:1. Эмиссия (щель, ядро)
уже в материалах glb — код Эха может добавить своё свечение поверх.

## Проверка

Godot 4.6.1: сцена грузится, AnimationPlayer видит 3 клипа (attack, death,
idle). Рендеры всех трёх — структура целая, обломки на местах.
Генератор: `build_keeper.py` (фреймворк boss_kit, детерминированный).
