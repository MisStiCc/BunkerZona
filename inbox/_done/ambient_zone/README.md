# Эмбиент-пак Зоны (ЗАДАЧА 15)

## Что это

7 звуков под пустующий Ambient-канал SoundManager (шина Ambient есть,
`ambient_sounds` есть, файлов не было). Процедурный синтез — прецедент
`sound_pack` (весь базовый пак проекта синтезирован, а не скачан):
гарантированная CC0, точная длина, бесшовные лупы, тихая громкость
(эмбиент RMS ≈ −30 дБ, пики < 0.6). Генератор `gen_ambient.py`
(numpy + soundfile; OGG пишется порциями по 1 с — цельный большой буфер
валит libsndfile).

## Файлы

| Файл | Длина | Тип | Настроение и куда звать |
|---|---|---|---|
| wind_open_01.ogg | 22.0 | ЛУП | низкий гул ветра с редким свистом — фон забега в чистой зоне, глобально |
| wind_forest_01.ogg | 16.0 | ЛУП | шелест сухостоя — лесные/парковые зоны (Припять-парк) |
| geiger_loop.ogg | 10.0 | ЛУП | мягкий треск дозиметра с фоном сети 50 Гц — позиционно у радиационных аномалий/Саркофага |
| night_insects_01.ogg | 16.0 | ЛУП | стрекот + тёплый ночной фон — ночь (день/ночь уже в игре) |
| rain_medium_01.ogg | 20.0 | ЛУП | плотный средний дождь — погодное событие |
| thunder_far_01.ogg | 7.5 | одиночный | дальний гром с двойным раскатом — редкое событие/гроза |
| howl_distant_01.ogg | 4.0 | одиночный | приглушённый вой вдали — сигналы мутантов, атмосфера |

Все лупы бесшовны: хвост кроссфейдится в голову (2 с), LFO периодичны
относительно длины. Одиночные — с естественными огибающими.

## Как встроить (рекомендация, не делал сам)

1. Папку перенести в `assets/audio/ambient/`.
2. В SoundManager грузить по ключам (имя файла = ключ без .ogg):
   `ambient_sounds["wind_open"]` и т.д.; лупы — `loop = true` (или
   `AudioStreamOggVorbis.loop_mode = FORWARD`), одиночные — без лупа.
3. На текущий момент вызовов `play_ambient` в коде нет — основной агент
   заводит: ветер лупом на старте забега (микс 2 ветров random),
   гейгер — позиционно у радиационных источников, ночь/дождь — по
   состоянию мира, гром/вой — редкие случайные события (раз в 30-90 с).

## Проверка

Все 7 файлов прочитаны обратно: длительности точны, пики ≤ 0.6, клиппинга
нет, тишина конца/начала отсутствует (лупы). Первый прослушивающий запуск
за основным агентом.
