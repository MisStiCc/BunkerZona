# Капсул-арт для страницы игры (ЗАДАЧА 28)

## Что это

Два постера на базе живописной карточки Монолита (ИИ-арт проекта):

| Файл | Размер | Композиция |
|---|---|---|
| `capsule_920x430.png` | 920×430 | горизонтальная капсула: арт справа со скруглением, слева затемнённая зона под название/логотип (градиент) |
| `vertical_640x960.png` | 640×960 | вертикальный баннер: арт сверху, нижняя треть затемнена под текст |

Размытый растянутый арт как фон + чёткая вставка + виньетка — всё в одной
гамме. Название НЕ запечено (добавит издатель/сторе или текстом в Godot).

## Как использовать

- Steam/Google Play/ itch — загрузить как капсулу; название положить
  поверх в тёмную зону (слева для капсулы, снизу для вертикали).
- Исходник: `ui/cards/Монолит.png`; пересборка — скрипт в журнале
  подготовщика (poster(): фон-блюр + вставка + виньетка).
