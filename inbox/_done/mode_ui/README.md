# UI-арт презентаций режимов (ЗАДАЧА 4)

Процедурный набор в стиле HUD зоны (графит + болотная зелень + жёлтый
акцент), прозрачные PNG. Арт свёрстан под спеку церемонии
`design_inbox/_done/tower_ceremony/tower_ceremony.md` — имена файлов
совпадают с `CeremonyData.ART`, тексты баннеров рисует игровой оверлей:
**текст в арт не запечён**, центральная зона каждого баннера оставлена
чистой (тёмная вставка 300..W-300 px — туда ложится label).

Все баннеры: срезанные углы «под трафарет», двойная рамка (акцент + тёмный
контур), угловые скобки, нижняя хазард-полоска в цвет акцента, потёртости/
царапины/пыль (как у декалей карты). Панель непрозрачна на ~93%, фон вокруг
прозрачный — можно вешать на ColorRect затемнения из спеки.

## Звёзды башни (256x256)

- `star_gold.png` — заработанная (объёмная золотая с бликом, под поп-анимацию)
- `star_silver.png` — прошлая из сейва (металлик, проявляется тихо)
- `star_empty.png` — пустой слот (тёмный контур)

## Иконки режимов (256x256)

- `icon_mode_campaign.png` — кольца Зоны с маршрутом-точками
- `icon_mode_tower.png` — башня Монолита с лучом
- `icon_mode_survival.png` — три волны наступления со стрелкой

## Частицы и глиф

- `glyph_stairs_up.png` (128x256) — ступени со стрелкой: 2D-подложка баннера
  подъёма и фолбэк-версия перехода без 3D
- `spark_star.png` (128x128) — твинкл-искра за gold-звездой (по 6 на звезду)
- `confetti_01..03.png` (128x128) — лента/круг/треугольник; тонируются
  modulate, количество по узлам частиц из §3 спеки (30/20/10 и 70/45/25)

## Что где использовать

Соответствие шагам церемонии — таблица §8 спеки (слэм баннера, поп звёзд,
волна конфетти, свап на «ПОДЪЁМ»). Баннеры keeper/break также годятся как
интро-версии (Приложение Б спеки): тот же слэм, вход без затемнения.
