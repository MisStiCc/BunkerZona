# Знамя гильдии (ЗАДАЧА 38, D21)

## Что это

Ткань-флаг 512×512 (зубчатый низ, складки, потёртости) в трёх цветах +
щит-эмблема 256×256 с золотым трефойлом. Стиль зоны, CC0.

| Файл | Цвет | Глиф |
|---|---|---|
| guild_banner_green.png | болотный | три когтя |
| guild_banner_gold.png | золото/умбра | череп |
| guild_banner_crimson.png | багровый | молния (война) |
| guild_emblem_256.png | — | щит с трефойлом (иконка гильдии в UI) |

## Как встраивать (рекомендация)

- Экран гильдии: флаг слева/фоном, эмблема — в шапке и в списке гильдий
  (иконка строки). Цвет знамени = цвет гильдии из D21 (если есть
  раскраска по гильдиям — три варианта уже под это).
- Логотип гильдии поверх эмблемы не нужен: трефойл уже фирменный.

Генератор — в журнале подготовщика (PIL, детерминированный).
