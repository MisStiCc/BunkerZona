# Звуки церемоний финала (ЗАДАЧА 20)

## Что это

Три собственных сэмпла для церемоний финала (сейчас играют чужие
upgrade/exchange). Процедурный синтез (прецедент sound_pack/gen_ambient),
CC0, пики < 0.7. Ключ = имя файла; основной агент регистрирует в
sound_manager и подключает в CeremonyData.

| Файл | Длина | Настроение и момент |
|---|---|---|
| `ceremony_win.ogg` | 1.90 с | торжественный стингер на слэм баннера победы: глухой удар → тёмный органный аккорд D с подъёмом на A («хор Зоны»), мягкий хвост. Одиночный |
| `ceremony_star.ogg` | 0.30 с | «дзынь» звезды: чистый синус G6 + слабая октава, атака 12 мс БЕЗ щелчка — сэмпл питчится 1.00/1.15/1.30, резкая атака при питче звенит грязно. Одиночный |
| `portal_woosh.ogg` | 2.00 с | гул перехода между этажами: фильтр открывается 1.2 с (нарастание) → спад с «хлопком». Одиночный |

## Как встраивать (рекомендация, не делал сам)

- `ceremony_win` — в момент слэма баннера победы/поражения (поражение —
  можно питчить ×0.8 и глушить верха).
- `ceremony_star` — на каждую звезду церемонии; питчи 1.00/1.15/1.30 для
  1★/2★/3★ (pitch_scale у AudioStreamPlayer).
- `portal_woosh` — на старте 3D-перехода между этажами (стелы/портал).
- Музыку лабы не глушить: стингеры поверх (штанга -6 дБ у них уже учтена
  пиками < 0.7).

Генератор: `gen_ceremony_sfx.py` (numpy + soundfile, OGG порциями).
