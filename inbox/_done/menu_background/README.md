# Фон главного меню «ЗОНА ДЫШИТ» (ЗАДАЧА 39)

## Что это

Две кадки одной сцены: грозовая Зона на рассвете — ржавые ЛЭП-вышки
с провисшими проводами, туман, вдали саркофаг ЧАЭС с тёплым окном и
молнией, вороньё, мёртвые деревья. Процедурно (та же серия, что
lab_ui/menu_background), CC0.

| Файл | Размер | Композиция |
|---|---|---|
| menu_bg.png | 1920×1080 | десктоп: ЛЭП слева (спокойная зона под кнопки), саркофаг+молния справа, нижняя треть — глухая тёмная земля |
| menu_bg_v.png | 1080×1920 | мобилки: небо выше, саркофаг в верхней трети, низ спокойный |

## Безопасные зоны под UI

- Десктоп: кнопки — левая/центральная область и нижняя треть (детали
  сознательно справа и вверху).
- Мобилки: нижние ~55% спокойные, текст — над туманом.

## Как применить

`main_menu.tscn`: ColorRect/Dim заменить/дополнить `TextureRect` с фоном
(STRETCH_KEEP_ASPECT_COVERED). Сгенератор `gen_menu_bg.py` — seed на кадку,
палитра константами.
