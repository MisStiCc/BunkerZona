# Эхо-обелиск (ЗАДАЧА 35)

## Что это

`echo_obelisk.glb` — стела Эха Монолита (рубеж обороны D20) вместо
процедурного цилиндра-заглушки. 7.45 м, 578 трис, статика. Origin в
основании (Y=0), +Z фронт. Процедурная геометрия, CC0.

## Конструкция

- Тёмный камень (мат 0 `dark_stone`): трёхступенчатое основание 3.2 м +
  сужающийся 8-ярусный ствол + пирамидальный наконечник. Фасетные
  вершинные цвета (COLOR_0) — стилистика Quaternius.
- Руны (мат 1 `rune_echo`): пластины на всех четырёх гранях ствола —
  вертикальная черта + точка, **emissiveFactor [0.62, 0.36, 1.0]** —
  светятся сами; поверх ляжет собственное свечение кода Эха
  (`zones/echo_monolith.gd` — свет/частицы не трогать, только заменить
  меш).

## Как встроить (рекомендация, не делал сам)

В `zones/echo_monolith.gd` вместо `CylinderMesh` — `load("res://.../echo_obelisk.glb")`
инстансом (или перенос файла в models/ и смена меша). Масштаб 1:1 (7.45 м),
низ уже в Y=0. Цветовые uniform-ы кода на руны не действуют (они в
материале glb) — тонировать весь обелиск целиком при нужде через
`material_override` НЕ стоит (убьёт эмиссию рун).
