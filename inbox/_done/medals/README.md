# Иконки 18 медалей Зоны (ЗАДАЧА 40)

## Что это

Единая серия: латунная штампованная медаль (ржавчина, зерно), лента
сверху (двухцветная), на аверсе — глиф подвига. Прозрачный фон 256×256.
Серые дубли не делались по заданию (гасятся модуляцией в коде).

## Пути

- Канонично: `inbox/medals/*.png` + генератор `gen_medals.py` (CC0).
- Положено прямо в `ui/icons/medals/<id>.png` (путь из задания) — можно
  подключать сразу: `load("res://ui/icons/medals/%s.png" % medal_id)`.
