# Карточки вариантов мутантов (ЗАДАЧА 11)

## Что это

14 новых карточек `ui/cards/mut_<type>.svg` для эксклюзивных вариантов мутантов
из `EXCLUSIVE_MUTANTS` (`data/gacha_data.gd`) + ревизия моделей баз. Игра
подхватывает карточки сама по имени (`card_icon_path: ui/cards/mut_<type>.svg`).
Имена файлов взяты из `type` в данных — это авторитет (в задании была опечатка
`beshenij_pes`, в данных `besheniy_pes`; файл создан по данным).

## Метод (по заданию)

Копия SVG базы, все основные цвета умножаются на `tint` варианта (из данных —
он же красит 3D-модель), glow-ореол (halo, рамка, заклёпки, глаз) перекрашивается
в `accent` варианта. Два уточнения подачи после визуальной приёмки:

- фон карточки тонирован мягче (tint×0.45+0.55), чтобы силуэт читался на фоне;
- у тела нижний порог яркости 28/255 — тёмные масти («Тень», «Обсидиановый
  титан») не тонут в чёрном.

Генератор: `gen_variant_cards.py` (повторный запуск не трогает существующие
файлы; перегенерация — удалить нужные svg и запустить). Превью-инструмент:
`gen_card_previews.gd` (растеризация карточек Godot'ом в C:/tmp/card_previews).

## Созданные карточки (14)

dvoroviy_pes, tuhlaya_plot, gniloy_zombie, brodyashiy_snork, besheniy_pes,
tolstaya_plot, lutiy_pseudodog, mercayushiy_poltergeist, nochnoy_krovosos,
psi_controller, krovaviy_snork, ten_pseudodog, crimson_chimera, obsidian_titan —
все с `.import` (проект импортирован headless-запуском Godot 4.6.1).

**Не тронуты (были сделаны параллельной сессией раньше):** alpha_pseudodog,
ash_snork, obsidian_controller — у них авторская ручная перекраска. Замечание
приёмки: у ash_snork тело местами сливается с фоном; при желании перегенерировать
единым методом — удалить его svg и запустить генератор.

Аномалии (часть Б задания) — art_ash_tornado, art_crimson_heat, art_void_loop —
уже лежали в ui/cards (та же параллельная сессия), не тронуты.

## Часть В: ревизия моделей

Все 17 баз из `EXCLUSIVE_MUTANTS` (pseudodog, snork_mutant, controller_mutant,
dog_mutant, flesh, zombie, poltergeist, bloodsucker, chimera, pseudogiant)
существуют в `models/` и импортированы (`.import` на месте). Пропущенных нет.
Свои glb-модели вариантов (бонус) не делались — варианты по архитектуре
используют модель базы + tint из кода.

## Визуальная приёмка

Два прогона моделью-зрением по контрольным листам (27 карточек с базами, затем
15 новых крупно): первая итерация нашла утонувшие тёмные карты — после правки
подачи все 15 читаются, рамки/ореолы консистентны. Контрольные листы удалены.
