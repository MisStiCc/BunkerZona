# Сплэш-экран загрузки (ЗАДАЧА 26)

## Что это

`boot_splash_1920x1080.png` — загрузочный экран в стиле игры: живописный
фон меню (ЧАЭС, туман, луна — из принятой поставки lab_ui), притемнён на
82% с мягкой тёмной полосой под название (центр) и тонкой золотой линией.
Название игры рисует Godot текстом поверх (шрифт игры, локализация —
бесплатно).

## Как применить (рекомендация, не делал сам)

1. Файл перенести в `assets/ui/boot_splash/`.
2. project.godot → `application/boot_splash`:
   - `image="res://assets/ui/boot_splash/boot_splash_1920x1080.png"`
   - `bg_color=Color(0.04, 0.045, 0.035, 1)` (тон в тон фону, чтобы без
     рваных краёв на любых окнах)
   - `fullsize=true` (растяжка на любые окна), `use_filter=true`.
3. Название игры поверх — Label в главной сцене первые секунды (или
   оставить чистый фон — название уже в шапке лабы).

База: `menu_background_2k.png` (lab_ui, CC0). Производная работа, CC0.
