# Звуки гачи и вскрытия карт (ЗАДАЧА 18)

## Что это

8 звуков под церемонию раскрытия круток (арт — `inbox/gacha_cards`,
сцены — в разработке основного агента). Процедурный синтез, CC0.

| Файл | Длина | Момент церемонии |
|---|---|---|
| `card_whoosh.ogg` | 0.6 с | карта вылетает из рулетки/колоды |
| `card_flip.ogg` | 0.25 с | переворот рубашки → лицо |
| `reveal_common.ogg` | 0.7 с | звон вскрытия: C5-E5, короткий |
| `reveal_rare.ogg` | 1.0 с | C5-E5-G5, посветлее |
| `reveal_epic.ogg` | 1.3 с | D5-F#5-A5 с вибрато |
| `reveal_legendary.ogg` | 1.8 с | мажорный аккорд + 4 колокольчика-блеска |
| `ribbon_pop.ogg` | 0.3 с | плашка «НОВЫЙ»/«ДУБЛЬ» |
| `burst_sparks.ogg` | 1.2 с | взрыв искр легендарки (россыпь тиков + бас) |

Звоны вскрытия растут по длительности и богатству — игрок слышит редкость
до того, как прочитал название. Ключи = имена файлов.

## Как встроить (рекомендация)

1. Папку перенести в `assets/audio/sfx/` (SoundManager сам подхватит по
   схеме «имя файла = ключ»).
2. Моменты: рулетка остановилась → whoosh; клик по карте → flip; по
   редкости результата → reveal_<rarity>; плашка → ribbon_pop; легендарка →
   burst_sparks поверх reveal_legendary.

Генератор: `gen_gacha_sounds.py` (numpy + soundfile, OGG порциями).
