# pripyat_props — low-poly пропсы для 3D-карты Припяти

## Что это

23 `.glb`-модели уличных пропсов для наполнения карты Припяти (дворы, дороги,
промзона, парки). Стилистика Kenney / Quaternius: фасетная заливка, лёгкие
модели (60–2500 треугольников). Текстур почти нет: у машин, лавки, фонаря и
ограды Kenney встроена одна текстура-палитра, остальные — чистые материалы.

## Нормализация (все файлы уже готовы к расстановке)

- **Масштаб реальный, метры**: автобус 11.5 м, сосны 4.5–7.5 м, бочка 1.2 м.
- **Origin в основании** (Y=0 в земле) — ставятся на высоту террейна как есть.
- **Машины вытянуты по Z** (длина по оси Z). Где именно перед (нос/кабина) —
  не гарантируется: при расстановке просто крутить `rotation.y`.
- Нормализация сделана узлом-обёрткой `normalized` (scale + translation
  внутри glTF) — геометрия источников не тронута.

## Как встраивать (подсказки основному агенту)

- Инстанцировать как обычные сцены из glb (грузить через `AnimCache`-подобный
  кэш при массовой расстановке — моделей много одинаковых).
- Ориентация «лицом»: у всех пропсов произвольный угол по Y — при расстановке
  добавлять случайный `rotation.y`, кроме машин вдоль дорог (ось длины уже Z).
- `concrete_block_02` (шлакоблок) задуман для баррикад россыпью по 3–6 шт.
- `barrel_radioactive` — серо-красная («опасная»). Чисто жёлтой CC0-бочки в
  источниках не нашлось; при желании тинтовать через `material_override`
  (материал тела бочки — первый в файле).
- Тяжелее всех `bush_dead` (451 КБ, текстура) — ставить умеренно.

## Что не вошло (не нашлось под требования)

- Жёлтая радиоактивная бочка с маркировкой — заменена красно-серой Quaternius.
- Третий вариант сухого дерева — два достаточно разных есть, третий
  (Quaternius "Dead Trees") тянул 2.5 МБ текстур и 6.5k полигонов — выкинут
  по требованию «текстуры не нужны или лёгкие».

   В поставке имена по заданию: `car_body`, `tree_dead` (без `_01`).
   Правится одной строкой в `pripyat_props.gd` (строки 253 и 297/542) —
   или переименуйте файлы при копировании.
2. **`tree_dead_03.glb` в поставке нет** (см. выше) — после замены файл
   в `models/props/` станет лишним, ссылки на него убрать (d = 1..2).
   Взамен появился `crate_02.glb` — раскладчик его не знает, при желании
