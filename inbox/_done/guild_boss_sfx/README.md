# Рык Гильд-босса (ЗАДАЧА 39)

## Что это

`mutant_guildboss.ogg` — 1.5 с процедурный рык пробуждённого гибрида
(D21: «скиллы двух боссов»): два голоса с расстройкой (82 Гц + 98 Гц,
разные форманты и вибрато — звучит как «два босса в одном»), нарастание
0.25 с, плато, обрыв в хрип. Пик 0.65. CC0.

## Как встраивать (рекомендация)

Регистрация в sound_manager (ключ = имя файла); звать на пробуждении
гильд-босса (перед боем, там же где баннер/портрет). Голоса базовых
боссов не дублируются — рык уникальный.

Генератор — в журнале подготовщика (numpy + soundfile).
