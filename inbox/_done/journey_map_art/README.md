# Арт для топо-карты Зоны (ui/lab/journey_map.gd)

Сейчас карта рисуется целиком кодом (_draw). Пак даёт фон и спрайты:
- map_background.png (1600x900) — тёмная топография: контуры рельефа,
  лес, река, пунктирные дороги, сетка, знак радиации, виньетка;
- биконы 96px: bicon_boss (караван-босс), bicon_keeper (Хранитель),
  bicon_break (Прорыв), bicon_anomaly, bicon_location, bicon_you (маркер).

Палитра согласована с константами COL_* journey_map.gd (GOLD e8b93c,
BREAK ff8d5c, GREEN 49ff80). Код рисует маршрут/гало поверх фона;
биконы можно ставить в точки _special вместо кружков.
