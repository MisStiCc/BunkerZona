# Химера FF10 — опознанные и переименованные клипы (ЗАДАЧА 44)

## Что это

`chimera_ff10_anim.glb` — фан-модель химеры (Final Fantasy X, из архива
пользователя) с 132-костным ригом: 6 безымянных клипов `[Action Stash]`
опознаны покадровыми рендерами и переименованы в игровые имена.
Godot 4.6.1 совместим (проверено на импорте семейства).

## Клипы (опознание по рендерам начала/конца — clips_preview.png)

| Клип | Кадры | Что |
|---|---|---|
| idle | 74 | двуногая боевая стойка с покачиванием |
| attack | 15 | короткий выпад-укус |
| pounce | 39 | четвероногий прыжок-бросок (в игра: бонус-атака) |
| walk | 197 | ход на четырёх лапах |
| run | 221 | локомоция на четырёх (быстрая) |
| idle_battle | 169 | сгорбленный вариант стойки |

death-клипа в исходнике нет — при смерти модель застынет (или использовать
как альтернативный скин поверх chimera_rig_anim с полным набором).

## ⚠️ Лицензия (важно для публикаций)

Модель — фан-работа по существу из Final Fantasy X (Square Enix IP).
Для личных/dev-сборок — свободно; для коммерческих площадок (Steam/Google
Play) заменить или согласовать. В disclaim.credits не включать без решения
владельца.

## Как встроить (рекомендация)

Как альтернативный скин химеры: перенести в `models/`, менять источник в
`chimera.tscn` или через вариант-систему.
