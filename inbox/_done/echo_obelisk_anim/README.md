# Анимации Эхо-обелиска (ЗАДАЧА 45)

## Что это

Два клипа на СУЩЕСТВУЮЩЕЙ геометрии `models/echo_obelisk.glb` (замена
скриптового scale-твина падения). Меш расщеплён по материалам на два
объекта (dark_stone 294 vert + rune_echo 1440 vert — суммарно та же
геометрия), риг: root + по 3 ярусные кости на материал
(b0/b1/b2 — камень, r0/r1/r2 — руны), жёсткая привязка по Z-ярусам.

## Файл

`echo_obelisk_anim.glb` — 2 клипа:

| клип | длина (30 fps) | содержимое |
|---|---|---|
| idle | 4.0 с (120) | парение ±4.5 см (2 цикла), медленный дрейф по Y ±2°, пульс рун масштабом ±2%, лёгкое колыхание верха |
| death | 1.6 с (48) | дрожь (0.4 с) → оседание −14 см с наклоном 3.5° → трещина: верх переламывается на −8° с рывком, руны уходят вниз |

Проверка: Godot 4.6.1 — AnimationPlayer видит оба клипа; кадры в
`check/_review_obelisk.png` (перелом верха в death_end читается).

## Что доделать движком (рекомендация, не делал сам)

1. **Пульс эмиссии рун**: в клипе руны «дышат» масштабом; для настоящего
   свечения твинь `rune_echo` material `emission_strength` 0.7↔1.3
   синхронно с idle (4 с loop).
2. **Частицы у основания** (спека idle): парение пылинок/искр у подножия —
   движком (GPUParticles у root), в GLB их не возить.
3. **Затухание рун при death «волной снизу вверх»**: руны на одном
   материале — простое решение: твин `emission_strength` 1→0 за death;
   волна — шейдером по мировой Z (рунные вершины разбиты по 3 костям
   r0/r1/r2 — при желании можно отдельно гасить ярусы через 3 материала
   в будущей версии модели).

## Как встроить

1. Заменить `models/echo_obelisk.glb` → `echo_obelisk_anim.glb`
   (геометрия та же, материалы те же, имена: dark_stone, rune_echo).
2. idle — сразу при постановке; death — вместо scale-твина при падении.
