# Бейджи ролей пачек D20 (ТАНК/ЛЕЧ/ДД/БАФ)

## Что это

4 иконки 64px в стиле `_done/pack_icons` (з.37): та же стальная плита
со срезанными углами и заклёпками, но вместо римской цифры — глиф роли,
окантовка — цвет роли (согласован с градиентами карточек v2 new_mutants).
Закрывают UI пачек: вкладки I–IV закрывает з.37, роли внутри карточек —
этот пак.

## Файлы

| Файл | Роль | Окантовка | Глиф |
|---|---|---|---|
| role_tank.png | TANK | сталь | щит с крестом |
| role_heal.png | HEAL | болотный #7ec850 | лист-побег + спора |
| role_dmg.png | DMG | угольно-огненный #f06e3c | скрещённые клинки |
| role_buff.png | BUFF | фиолет #b078f0 | аура-спираль + стрелка вверх |

## Как встроить (рекомендация, не делал сам)

1. Перенести в `assets/ui/icons/` (или рядом с pack_icons).
2. Подключить по значению `role` из блока NEW_ORIGINALS
   (`TANK`/`HEAL`/`DMG`/`BUFF`): бейдж на карточке мутанта в пачке и/или
   в заголовке слота пачки. Имена файлов в нижнем регистре:
   `role_%s.png % role.to_lower()`.
