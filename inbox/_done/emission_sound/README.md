# Звук Выброса (ЗАДАЧА 17)

## Что это

Два звука катастрофы под emission_fx (визуал уже встроен). Процедурный
синтез (прецедент sound_pack/ambient_zone), CC0, нормализованы.

| Файл | Длина | Что |
|---|---|---|
| `emission_rumble.ogg` | 7.0 с | гул катастрофы: нарастание 1.5 с → дрожащее плато → спад 2 с. Три слоя низкого рокота (90/45 Гц шум) + тон 38 Гц с биениями + «воздух» на пике |
| `emission_burst.ogg` | 0.8 с | резкий удар-всплеск на старт волны: щелчок + глухой тук 55 Гц + шумовой хвост |

## Как стыковать с кривой эффекта (рекомендация)

- `fx.start()` → сразу `play(emission_burst)` (удар волны).
- Параллельно `play(emission_rumble)`; его огибающая совпадает с формой
  кривой set_intensity (рост 1.5 с, плато, спад 2 с + хвост) — можно звать
  один раз и не вести громкость вручную; при раннем `stop()` эффекта
  звук заглушить fade 0.3 с.
- pulse_warning остаётся сигналом ДО нажатия кнопки (не дублируется).

Генератор: `gen_emission_sound.py` (numpy + soundfile; OGG пишется
порциями — цельный буфер валит libsndfile).
