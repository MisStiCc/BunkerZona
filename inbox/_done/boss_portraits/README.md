# Портреты 6 боссов ОХОТЫ (ЗАДАЧА 36)

## Что это

6 портретов ~620px для календаря недели ОХОТЫ (D19) и карточки гильд-босса.
Единая серия с карточками: драматичный крупный план живописной карточки-родни
+ колорайз + эффекты стихии + виньетка. CC0 (производные артов проекта).

| Файл | Босс | Родня-база | Эффекты |
|---|---|---|---|
| kostolom.png | Костолом (костяной колосс) | псевдогигант | костяные обломки, кости-грудь |
| tumannitsa.png | Туманница (призрак в тумане) | полтергейст | слои тумана |
| pozhiratel.png | Пожиратель (массивная пасть) | плоть | нарисованная пасть: клыки, слюна, янтарные глаза-щели |
| stolp.png | Столп Грозы (громовой столп) | арт «Гроза» | зигзаги-молнии |
| hromets.png | Хромец (быстрый хищник) | псевдопёс | скоростные штрихи, охра |
| mat_bolota.png | Мать-в-болоте (болотная матрона) | снорк | болотные кляксы, пузыри |

Генератор — в журнале подготовщика (colorize + dramatic_crop + fx;
детерминированный seed на босса). Контрольный лист проверен: Пожиратель
пересобран отдельно (был слаб) — теперь пасть с клыками.

## Как встроить (рекомендация)

Календарь недели: `TextureRect` портрета + имя/дни; карточка гильд-босса:
портрет как фон/аватар события. Серые версии при необходимости —
`tools/make_gray_pngs.py`.
