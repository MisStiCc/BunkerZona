# Звук двери бункера (ЗАДАЧА 27)

## Что это

Два звука переходов «лаба ⇄ Забег» — сейчас смена сцены беззвучна.
Процедурный синтез, CC0. Ключ = имя файла.

| Файл | Длина | Момент |
|---|---|---|
| `bunker_door_open.ogg` | 1.30 с | старт забега: лязг замка → гидравлический гул → стравленное шипение |
| `bunker_door_close.ogg` | 0.90 с | возврат в лабу: скрежет уплотнения → захлоп → скоба |

## Как встраивать (рекомендация, не делал сам)

Звать в момент смены сцены (до/вместо загрузочного фейда):
`play("bunker_door_open")` при выходе из лабы, `play("bunker_door_close")`
при возвращении. Если сцена грузится дольше 0.5 с — звук с_MI,
перекрывающий паузу.

Генератор: `gen`-скрипт в журнале подготовщика (numpy + soundfile).
