# Лицензии — tower_transition

Все три модели — оригинальная процедурная генерация (Python/trimesh),
выполнена специально для StalkerRevert по ЗАДАЧЕ 5 из COMMANDS.md.
Сторонних ассетов и текстур не используется (заливка вершинными цветами,
у флага — UV под материал игры).

Лицензия: **CC0 1.0** (общественное достояние) — любое использование,
включая коммерческое, указание авторства не требуется.

| Файл | Источник | Лицензия |
|---|---|---|
| models/tower_staircase.glb | оригинальная процедурная генерация | CC0 |
| models/portal_ring.glb | оригинальная процедурная генерация | CC0 |
| models/banner_pole.glb | оригинальная процедурная генерация | CC0 |

Примечание: готовых CC0-моделей «лестница/портал/штандарт» с прямыми
скачиваниями у рекомендованных источников (Kenney/Quaternius/KayKit/
poly.pizza) на момент выполнения не отдавалось (сайты-кандидаты отдают
архивы только через JS-загрузчик без прямых ссылок), поэтому ассеты
сделаны процедурно в заданной стилистике Quaternius.
