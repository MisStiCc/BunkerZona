# Ориентиры ЧАЭС (ЗАДАЧА 29)

## Что это

Три узнаваемых силуэта Чернобыльской АЭС для карты Припяти. Все —
**процедурная геометрия** (готовых CC0 моделей НБК/Прометея не существует —
специфичные сооружения; задача разрешала процедурный вариант). Фасетная
вершинная заливка (COLOR_0, стиль Quaternius, без текстур — Godot
импортер сам включает vertex_color_use_as_albedo). Origin в основании
(Y=0), +Z фронт, реальные метры. CC0.

| Файл | Трис | Габариты (факт.) | Конструкция |
|---|---|---|---|
| `models/nbc_arch.glb` | 64 | 250 × 108 × 150 м | эллиптический свод (16 сегментов) + вертикальные торцы (темнее); серебристо-серый металл. Длина — по Z, фронтом к +Z |
| `models/prometheus.glb` | 110 | 3.6 × 8.9 × 3.6 м | двухступенчатый постамент + абстрактная фигура с поднятой рукой и факелом (вершина ~8.95 м ≈ 9 м); тёмная бронза, камень |
| `models/cooling_tower.glb` | 108 | 110 × 150 × 108 м | усечённый конус (низ Ø110, верх Ø70), двойная стена 1.8 м — просвет сверху виден; бетон, внутренняя стена темнее |

## Как встроить (рекомендация, не делал сам)

1. Папку `models/` перенести в проект (или брать из inbox).
2. Арку ставить над контуром «Укриття-2» из OSM: origin в центре основания,
   фронт +Z — при необходимости развернуть по азимуту контура.
3. Материал импортируется сам (вершинные цвета); масштаб 1:1 карты —
   проверять на месте: арка 250 м шириной.
4. Триангуляция крошечная (64/110/108) — можно ставить все три без
   влияния на производительность.
