# Звуковой пакет Гильдии (ЗАДАЧА 33, под спеку D21)

## Что это

Четыре звука UI гильдии (спека архитектора D21 — казна/знамя/война/магазин,
в очереди на внедрение). Процедурный синтез, CC0. Ключ = имя файла.

| Файл | Длина | Момент (по D21) |
|---|---|---|
| `guild_coin.ogg` | 0.50 с | вклад в казну: россыпь монет с металлическим звоном |
| `guild_banner.ogg` | 1.10 с | подъём/смена знамени: шелест ткани на ветру + торжественный тон |
| `guild_war.ogg` | 1.60 с | объявление войны: низкая сирена-гул (72/76.5 Гц биения) + боевые барабаны |
| `guild_buy.ogg` | 0.40 с | покупка в гильд-магазине: мягкий двойной клик + подтверждающий звон |

## Как встраивать (рекомендация, не делал сам)

Регистрация в sound_manager (ключ = имя файла); вызовы — по событиям UI
гильдии из D21, когда основной агент дойдёт до интеграции спеки.
`guild_war` — поверх баннера войны (если появится), с музыкой не
конфликтует (пики < 0.6).

Генератор: `gen`-скрипт в журнале подготовщика (numpy + soundfile).
