# Карточки 8 новых видов D20 (ЗАДАЧА 34)

## Что это

Самостоятельные портреты видов поддержки D20 (`NEW_SPECIES` из
`data/mutant_roles_data.gd`) — до этого они показывали перекрашенный арт
базы. Единая серия с существующими 28: живописная основа, тот же свет,
тёмный фон, ~612-631px. PNG + CREDITS.

## Как сделано

Колорайз арта базы (замена ОТТЕНКА с сохранением светимости и фактуры —
мультипликативный тинт не умеет green→lilac, поэтому цвет стихии умножается
на яркость, а высокочастотный остаток исходника возвращает живописную
фактуру) + процедурные акценты стихии поверх + зерно. Рамка/глубокие тени
не красятся (сохранён тёмный контур карточки).

|---|---|---|---|
| mohovik.png | Моховик | Плоть | кляксы болотного мха |
| tsveten.png | Цветень | Полтергейст | сиреневые лепестки-хлопья |
| zhivitsa.png | Живица | Кровосос | янтарные натёки смолы + изумрудные брызги |

| vikhor.png | Вихорь | Псевдопёс | серебристые потоки ветра |
| shorokh.png | Шорох | Снорк | пепельная пыль |

| guden.png | Гудень | Зомби | гудящая аура-кольца, тёмный сине-фиолетовый |

Генератор: `gen_species_cards.py` (tint = значения из NEW_SPECIES,
детерминированный seed на вид).

## Как встроить (рекомендация)

Игра берёт карточки по имени (`ui/cards/<type>.png` приоритетнее svg) —
основному агенту достаточно перенести 8 PNG в `ui/cards/` (и убрать/заменить
перекрашенные заглушки, если он успел их создать), серые версии — через
`tools/make_gray_pngs.py`, как сказано в задании. `card_base_of()` можно
не трогать: файл варианта теперь существует и перебьёт арт базы.

## Проверка

Контрольный лист 8 шт: оттенки соответствуют описаниям задания (мох/
лиловый/янтарь/охра/серебро/пепел/лёд/сине-фиолет), фактура баз сохранена,
рамки целы.
