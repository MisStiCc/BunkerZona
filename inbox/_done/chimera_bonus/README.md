# ЗАДАЧА 45 — Химера: бонусные клипы pounce + rage

## Что это

`chimera_rig_anim_bonus.glb` — ИГРОВАЯ химера (`models/chimera_rig_anim.glb`,
оптимизированная: 92k трис, ~10.9 МБ) + два новых бонусных клипа. Риг не
тронут (72 кости, те же имена), базовые 5 клипов НЕ пересобраны — перенесены
из исходника как есть.

Путь решения выбран №1 из задания (доработка игрового рига): риг легален
(ассет проекта + процедурные анимации CC0), конвейер отлажен на нём,
претензии отклонённой задачи 44 (чужой IP, отсутствие death) здесь
отсутствуют — death на месте.

## Клипы — 7 шт

| Клип | Длина | Статус |
|---|---|---|
| idle | 3.2 с | база, без изменений |
| walk | 0.9 с | база, без изменений |
| gallop | 0.47 с | база, без изменений |
| attack | 1.0 с | база, без изменений |
| death | 1.4 с | база, без изменений |
| **pounce** | 1.1 с (33 кадра) | НОВЫЙ — прыжок-бросок |
| **rage** | 1.6 с (48 кадров) | НОВЫЙ — ярость |

### pounce (прыжок-бросок)
Приседание (корпус вниз, задние лапы сгружаются) → отрыв и полёт по дуге
(тело вытянуто, задние отталкиваются, передние тянутся вперёд) → удар-укус
обеими головами на приземлении → гашение и возврат в rest. Одноразовый клип,
корень возвращается в исходную точку — модель не уезжает, боевое перемещение
делает движок. Хорош для рывка-атаки с пролетом над препятствием/врагом.

### rage (ярость)
Корпус приподнимается, две головы расходятся в стороны и трясутся в
противофазе (2 цикла рыка), хвост хлещет с большой амплитудой, передние лапы
царапают воздух попеременно → спуск и возврат в rest. Хорош для баф-фазы
(ускорение атаки/урона) или пробуждения элиты.

## Имена и подключение

Имена клипов — `pounce` и `rage` (латиница, без суффиксов), по образцу
`base_mutant._match_clip`. ВАЖНО: сейчас игра НЕ играет эти клипы (в
`_match_clip` их нет) — это бонусные анимации; код-агенту нужно добавить
триггеры (например, в chimera.gd: pounce — рывок-атака с кулдауном,
rage — баф-фаза). До подключения файл безопасен: при загрузке лишние
клипы просто лежат в AnimationPlayer неиспользуемыми.

## Как встроить

Заменить `models/chimera_rig_anim.glb` файлом
`chimera_rig_anim_bonus.glb` (перенести и переименовать). Скин/кости
идентичны (1 skin, 72 joints) — tint, нормализация размера, клип-плеер
работают как раньше. Прежний файл с 5 клипами можно не хранить: базовые
клипы в новом файле байт-в-байт те же по построению (имена/длины совпадают).

## Проверка

- JSON GLB: `animations` = 7 (attack, death, gallop, idle, pounce, rage,
  walk), skins=1, joints=72.
- Blender: рендеры фаз — pounce 5/9/18/25/33, rage 10/22/34/48: деформация
  чистая, под пол не проваливается, возвраты в rest точные (контрольные
  кадры в папке: check_pounce_apex.png, check_rage_shake.png).
- Длины клипов подтверждены повторной загрузкой GLB в Blender 4.5.9.
- Godot CLI на машине недоступен — загрузку в Godot 4.6 проверить при
  первом запуске (ожидание: AnimationPlayer видит 7 клипов; риг тот же,
  что уже в игре, риск минимальный).

## Воспроизводимость

`add_bonus.py` — полный gen-скрипт (Blender 4.5 headless):
`blender --background --python add_bonus.py`. Источник и выход прописаны
константами SRC/OUT вверху. Примечание: `move()` здесь пишет АБСОЛЮТНУЮ
позицию корня от rest, в отличие от инкрементального move() в старом
`animate.py` — с абсолютной траекторией старый вариант уезжал в наклейку
(накопление дельт через интерполяцию ключей).
