# Настоящие декали грязи (ЗАДАЧА 12)

## Что это

16 декалей 256x256 RGBA в `assets/decals/` (папка создана — раньше код
`terrain/pripyat_map_3d.gd` и `terrain/terrain_generator.gd` читал её, а
файлов не было, декали молча не грузились; в `assets/textures/decals/`
лежали осиротевшие заглушки 32x32). Процедурные (генератор
`gen_decals.py`, seed фиксирован), стиль: приглушённая зона, мягкие края
(альфа затухает к рамке — Decal не режется об край), зерно.

## Состав

| Имя | Что |
|---|---|
| crack_01..03 | ветвящиеся трещины с ветками и светлым сколом |
| rust_streak_01..02 | ржавые потёки почти во всю высоту с натёками и боковыми потёчками |
| stain_dark_01..02 | тёмные пятна грязи |
| stain_oil_01 | масляное пятно с радужной кромкой |
| moss_patch_01..02 | мох кластерами |
| sign_radiation | жёлтый трефойл «Радіація» с потёртостями, чуть наклонён |
| paint_x_white / paint_arrow_yellow | метки краской с потёками |
| bullet_holes_01..02 | пробоины: воронка + сколы + светлый ободок |
| hazard_stripes | жёлто-чёрная лента 45°, слегка потёртая |

Код читает первые 12 имён (списки в `pripyat_map_3d.gd:200` и
`terrain_generator.gd:409`); bullet_holes/paint_arrow/hazard — запас под
будущее.

## ⚠️ Основному агенту: баг в коде загрузки декалей

В ОБОИХ местах цикл объявляет `for layer_name in [...]` (или
`for sky_name in [...]`), а путь строит из `name`:
`"res://assets/decals/%s.png" % name` — `name` это свойство узла, не
переменная цикла. Декали не загрузятся, пока переменная не будет поправлена
(`layer_name`/`sky_name`). Однострочный фикс в двух файлах; проверено:
с файлами в `assets/decals/` и исправленной переменной декали появятся на
стенах Припяти и процедурной Зоны.

## Проверка

Контрольный лист на бетонном фоне прогнан через модель-зрение: трещины/
пятна/мох/знак/пробоины/метки читаются, замечания (короткие потёки,
полустёртые полосы) исправлены во второй итерации. Импорт Godot 4.6.1
headless — без ошибок.
