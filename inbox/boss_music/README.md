# Музыкальные лупы босс-боёв (ЗАДАЧА 22)

## Что это

Два процедурных боевых лупа ~43 с, бесшовные (wrap-кроссфейд, перепад на
стыке ~0). CC0. Ключ = имя файла; основной агент регистрирует в
sound_manager и переключает музыку на бою Хранителя/финале.

| Файл | Длина | Характер |
|---|---|---|
| `keeper_loop.ogg` | 42.9 с | Хранитель: пульс-бас-«сердцебиение» на 100 BPM, тревожные верхние вспышки, перкуссия на 2 и 4, гул-дрон раз в два такта. Тональность A-минор с ляганием в Bb — тревожно |
| `monolith_finale.ogg` | 42.9 с | Монолит: держащиеся органные слои (A2/E3/A3/B3/E4 — зависший диссонанс), предупреждающий колокол каждый такт (нота съезжает по кругу), свип-шум. «Глас Монолита» |

## Как встраивать (рекомендация, не делал сам)

- На входе в бой Хранителя: `play_music("keeper_loop")` c кроссфейдом ~1 с
  (музыкальные лупы — ставить `loop = true` у AudioStreamOggVorbis).
- На финальном ярусе (91–100) или бое Монолита: `monolith_finale`.
- После боя — кроссфейд обратно в `music_run`.
- Громкость: RMS ~ −20 дБ, под голос/эффекты не лезут.

Генератор: `gen_boss_music.py` (numpy + soundfile; луп из 18 тактов 100 BPM
с кроссфейдом хвоста и wrap-фейдом микса).
