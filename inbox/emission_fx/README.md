# Визуал Выброса Зоны (emission_fx)

## Что это

Эффект катастрофы на 5 секунд Выброса: небо наливается багровым, от Монолита
по земле расходится ударная волна (фронт + эхо), над ареной пепел и искры,
5–8 мерцающих столбов света. Управление — три метода из игры, интенсивность
ведёт сама игра (нарастание/плато/спад).

**Код игры не тронут.** Всё содержимое — оригинальные процедурные ассеты
(CC0, см. CREDITS.md). Проверено headless-запуском Godot 4.6.1 (10 секунд
полного цикла демо — без ошибок скриптов/сцен).

## Почему процедурно (поиск CC0 закрыт честно)

Готовых CC0 материалов под такой эффект не существует:
- сток-видео с альфа-каналом ([Videezy](https://www.videezy.com/free-video/explosion-alpha),
  [Vecteezy](https://www.vecteezy.com/free-videos/explosion-alpha),
  [ProductionCrate](https://www.productioncrate.com/vfx/visual-graphics/dust-smoke/shockwaves),
  [Pixabay](https://pixabay.com/videos/search/explosion%20green%20screen/)) —
  «free» лицензии этих сайтов с условиями, не CC0, и это видео, не игровой формат;
- у Kenney/Quaternius/poly.pizza VFX-паков катастроф нет.
Поэтому всё сделано GDShader + GPUParticles3D — прецедент `res://anomaly_fx/`.

## Состав

| Путь | Что |
|---|---|
| `scenes/emission_fx.tscn` | корень-эффект + контроллер (инстансить в игру) |
| `scripts/emission_controller.gd` | `start()`, `set_intensity(x)`, `stop()` |
| `shaders/emission_sky.gdshader` | багровое небо (сфера 600 м, blend_add изнутри) |
| `shaders/shockwave_ring.gdshader` | кольцо волны: фронт с рябью + затухающий след |
| `shaders/light_pillar.gdshader` | мерцающий столб света (градиент, полосы, дрожь) |
| `textures/spark_soft.png`, `textures/ash_flake.png` | спрайты частиц (процедурные) |
| `demo/emission_demo.tscn` + `demo_cycle.gd` | демо-автоцикл: пол, заглушка Монолита, камера |

## API контроллера

```gdscript
fx.start()               # волна пошла от Монолита; столбы встали случайно
fx.set_intensity(0.0)    # 0..1 — небо/волна/столбы/свет/пепел
fx.stop()                # всё погасить, столбы убрать
```

Кольцо волны едет САМО по времени от `start()` (не зависит от set_intensity):
фронт до края арены за `wave_time` (2.4 с, ~170 м), следом эхо слабее.
Интенсивность — отдельная ось: игра делает «нарастание 1.5 с → плато →
спад 2 с» кривой вызовов `set_intensity` (готовый образец кривой —
`demo_cycle.gd`, фазы 0–2).

Параметры в инспекторе корня: `wave_time`, `echo_delay`, `pillars_count`
(5–8 по заданию, по умолчанию 6), `pillar_radius_min/max` (45–140 м),
`pillar_min/max_height` (55–95 м), `ash_spread_time`, `sky_gain`.

## Как встроить (рекомендация, не делал сам)

1. Папку `emission_fx/` перенести из `inbox/` в корень проекта
   (`res://emission_fx/`) — или взять прямо из inbox, пути внутри относительные.
2. В сцену забега добавить instance `scenes/emission_fx.tscn` на позицию
   Монолита (origin сцены = центр волны, y = уровень земли).
3. По кнопке Выброса (1000 энергии): `fx.start()`, дальше кривой
   `set_intensity` (1.5 с рост → плато → 2 с спад), в конце `fx.stop()`.
4. Звук уже есть в игре (`pulse_warning`) — дублировать не нужно.

## Технические заметки

- Небо — сфера cull_front + blend_add + depth_draw_never: террейн/строения
  перекрывают её по глубине, багровым заливается только панорама неба.
- Волна — quad 360×360 м на земле; `ring_pos` 1.0 = 170 м от центра (арена
  150 м + запас). Яркость фронта падает с расстоянием внутри шейдера и
  контроллером.
- Пепел: GPUParticles3D в local_coords, «ветер от Монолита» сделан
  масштабом узла (0.3 → 1.0 за `ash_spread_time`) — облако разъезжается
  наружу. Turbulence не используется (совместимость, как в anomaly_fx).
- Столбы: клонятся из шаблона в `start()`, у каждого свой `seed` и случайные
  высота/радиус/позиция на кольце 45–140 м; мерцание — в шейдере по TIME.
- Партиклы — billboard_mode 3 (particles) в StandardMaterial3D, как в
  anomaly_fx; шейдерных billboard-карт тут нет (не нужны).
- В headless шейдеры GPU-компилятором не проверяются — первый визуальный
  запуск за основным агентом (демо-сцена открывается как обычная сцена).
