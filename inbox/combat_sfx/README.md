# Боевые SFX (ЗАДАЧА 21)

## Что это

Пять звуков боевого цикла, которых не было (волны и смерти шли молча).
Процедурный синтез (прецедент ceremony_sfx), CC0, пики ≤ 0.65.
Ключ = имя файла; основной агент регистрирует в sound_manager и вешает
на события (смерти — случайный выбор из трёх).

| Файл | Длина | Момент |
|---|---|---|
| `stalker_death_01.ogg` | 0.90 с | смерть сталкера, вариант 1: крик 320→140 Гц с обрывом в хрип |
| `stalker_death_02.ogg` | 0.90 с | вариант 2 (ниже и короче обрыв) |
| `stalker_death_03.ogg` | 0.90 с | вариант 3 |
| `anomaly_hit.ogg` | 0.45 с | аномалия накрыла цель: треск-разряд + звон 2.1/3.3 кГц + низкий тук |
| `wave_horn.ogg` | 1.50 с | спавн волны: зловещий рог (98/103.5 Гц с биениями) + рык-подложка |

## Как встраивать (рекомендация, не делал сам)

- Смерть: `play("stalker_death_0%d" % (randi() % 3 + 1))` в момент hp <= 0
  сталкера; у группы ограничить одновременность (не более 2-3 в кадр).
- `anomaly_hit` — на первый тик урона аномалии по цели (не каждый тик —
  с кулдауном ~0.4 с на цель).
- `wave_horn` — на старте волны (там же, где сейчас только баннер/текст).

Генератор: `gen_combat_sfx.py` (numpy + soundfile, OGG порциями).
